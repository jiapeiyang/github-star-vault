## 它是什么
learnVue 将 Vue 生态源码注释与主题文章放在同一仓库。README 明确注明注释版本为 Vue 2.3.0、Vuex 2.4.0、Vue-router 3.0.1，对应 vue-src、vuex-src、vue-router-src 目录。文章涵盖响应式、依赖收集、VNode、diff、模板编译、nextTick 和 keep-alive，帮助把外部 API 与内部过程对应起来。

## 适合什么场景
适合维护 Vue 2 程序时理解数据更新、组件缓存或状态管理，也适合按一个问题追到相关源码。基础组件用法不是它的重点，Vue 3 的 Proxy 响应式也不能用这套旧源码直接解释。

## 如何开始
先查自己项目依赖，再按 README 主题进入 docs。建议从“从 template 到 DOM”建立整体流程，然后分别阅读响应式和依赖收集，最后在对应注释目录定位函数。没有必要为只读源码分析安装整个旧框架。

## 注意事项与相关项目
这是作者对上游源码的解释，可能有理解偏差，README 也邀请读者指出问题。版本号是重要边界，不能用“Vue 源码”泛指现代版本。与 ygs-code/vue 相比，本仓库按专题文章与三个生态库划分，后者更强调逐行注释和整条流程。
