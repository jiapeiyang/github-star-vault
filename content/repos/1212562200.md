## 它是什么
YouMind 的 awesome-gpt-image-2 是提示词案例集，条目包含描述、完整提示词、生成图与来源详情。分类覆盖头像、社交图片、信息图、商品营销、漫画和游戏资产，网页图库增加搜索与筛选。

它适合观察“哪些约束写进提示词会影响画面结构”，不需要把所有案例视作可直接套用的产品模板。社区图片体现的是特定输入与生成结果。

## 适合什么场景
找海报或信息图构图参考；比较同一用途的不同提示组织方式；根据已有案例整理自己的输入变量。只查资料时在 GitHub 或图库浏览即可。

## 如何开始
在 README 按用途进入图库，挑选条目后同时阅读图片、提示词与来源。确认是否需要参考图，把占位变量替换为自己的资料，再到有权限的图像工具生成。原始案例和自己修改的要求应分开保存，便于分析差异。
