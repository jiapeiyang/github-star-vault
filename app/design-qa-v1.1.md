# Star Vault v1.1 验收记录

日期：2026-09-05。当前状态：本地功能与视觉检查通过，等待本版线上发布核对。

## 视觉基线与适用范围

延续方案 E“开发者杂志”，本次为既有产品的局部扩展：纸白、近黑、单一洋红、编辑分栏、真实头像及 Phosphor 图标。未重画首页或替换品牌。表单增加可读字号与黑底主操作按钮，保持输入、聚焦和错误提示可辨认。

已参考 design-taste-frontend；该技能声明密集产品表单不在范围，本次只应用既有视觉连续性检查。新功能采用原生表单和既有组件，无新设计系统。局部参数为布局差异 3、动效 1、信息密度 7；不加入装饰动画。保留上游真实描述，即使包含技能对营销文案禁用的标点，也不改写事实。

Sites 兼容配置和打包流程保留；正式托管继续采用开发计划指定的 GitHub Pages。React 检查覆盖组件职责、稳定回调、列表 key、effect 清理、表单标签和状态回填；未做无关重构。

## 功能与数据验证

- 65 条 fixture 覆盖三页，页码边界、直接定位第 45 条、空结果和 URL 往返由 Node 测试验证。
- 真实目录直接打开第三页定位 tt-a1i/archify；下一页、浏览器返回、刷新后恢复正确项目；队列搜索空结果不残留旧表单。
- 个人备注、Markdown 正文、标签和关联回填。真实下载修改过的 anthropics/skills 文件，经生产 Python 解析器确认正文与 related 保留、标签修改生效。
- 新建一个明确标为测试的文件，真实下载后放入隔离内容目录；verify_data 与 build_catalog 成功。浏览器读取该生成目录后可用正文唯一词搜索，详情显示新分类、learned 阶段和完整笔记。
- “返回详情”与浏览器后退的离开确认均可取消，草稿保留；发起下载后可正常离开。刷新产生 beforeunload，取消后输入仍在。
- 实际剪贴板复制结果包含 related 和实践正文。
- 未填写分类、价值说明或 learned 结论时阻止导出；超限、重复、语言重复标签由领域测试覆盖。
- 特殊字符导出经过 Node → Python tomllib → 正式合并目录的交叉校验；包含引号、反斜线、换行、TAB、控制字符、DEL 和中文。
- unknown metadata 与非字符串日期在生成目录中标记为不可安全编辑，不公开未知字段值、不生成丢字段替代文件。
- 原始 HTML 不执行；危险协议和相对链接不可点击；远程图片不自动加载；围栏代码内的 HTML 以文本展示；中文标题锚点有效。
- 学习页的待学习、最近已学习查看全部入口跳转到正确筛选；missing 项目编辑入口可打开。
- Chromium 浏览器检查期间无页面脚本错误。浏览器没有 agent-browser 可执行文件，实际使用已可用的 Playwright CLI 完成同等页面、控制台和截图验证。

## 验证边界

- 没有修改用户的正式个人内容，未把测试 learned 结论写入生产站。
- 个人归档路径由领域测试覆盖；线上没有为测试而新增归档笔记。
- 本轮测试浏览器为 Chromium，Safari/Firefox 的下载与退出提醒未单独实测。
- 前端复制的成功仅表示剪贴板写入，下载状态仅表示下载已发起；均不表示 GitHub 已提交。
- 草稿不做崩溃恢复和多设备合并。
