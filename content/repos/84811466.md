## 它是什么
“冴羽的博客”用 README 按系列整理文章，许多正文存放在 GitHub Issues。既有 JavaScript 原型、作用域、闭包和模拟实现等基础专题，也有 Next.js、Svelte、Astro 与技术单篇入口。仓库是一张通向系列文章的索引，而不是需要启动的博客服务源码。

## 适合什么场景
适合忘记具体文章标题时按概念找回解释，或沿一个问题继续查相邻概念。它也包含作者活动、社群和付费内容入口，技术文章与这些入口的访问条件并不相同。

## 如何开始
先选择 README 中的系列，而非只从最新动态往下翻。基础 JavaScript 问题可定位“JavaScript 深入”，工具函数实现可定位“JavaScript 专题”。打开对应 Issue 后检查文章日期、示例与讨论中的修正；若涉及新框架版本，再回到框架官方文档核对。

## 注意事项与相关项目
文章跨越多个年代，规范与框架 API 会变化。README 个别标题存在相同 Issue 链接，应以实际打开的正文标题为准。标题中的性能倍数或趋势判断属于文章主张，不能仅据目录当成已验证事实。与 underscore-analysis 可按需对照同类工具函数的源码视角。
