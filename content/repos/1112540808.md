## 它是什么
vercel-labs/agent-skills 将工程建议打包成 Agent Skills。React 规则按请求瀑布、包体、服务端与重渲染等影响排序；网页规则覆盖语义、焦点、表单、动画、图片和 URL 状态；Vercel 优化技能先收集指标再定位代码。

它是专项知识和操作指南，不是 React 库，也不需要项目部署在 Vercel 才能阅读通用前端规则。

## 适合什么场景
审查 React 页面性能；检查表单与键盘交互；优化真实 Vercel 成本；统一技术文案。选择具体技能比把所有规则同时用于每个改动更合适。

## 如何开始
用 `npx skills add vercel-labs/agent-skills` 选择所需技能和宿主，检查 SKILL.md 及其 references 是否完整。输入明确文件或问题；需要平台指标时再建立相应只读访问，不从源码猜费用。

规则随框架和平台更新，应核对适用版本。安装指南中的 Deploy 请求只是能力示例，不替代发布授权。vercel-labs/skills 是安装分发 CLI，本仓库是被安装的内容。
