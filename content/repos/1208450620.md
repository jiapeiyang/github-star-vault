## 它是什么
cursor-byok 在 Cursor 与配置的 OpenAI/Anthropic 兼容模型之间运行本地服务，处理协议适配、请求转发、工具调用协调与对话状态。用户可填写端点、模型 ID、Key 和参数，并查看连接延迟与使用统计。

API Key 与设置留在本机，但模型请求仍会发往所选服务商。这是独立项目，并非 Cursor 官方功能或官方背书。

## 适合什么场景
已持有模型 API 额度，希望接入 Cursor 工作流；需要比较多个兼容端点；想自行控制模型渠道与上下文、输出等参数。

## 如何开始
从 Releases 下载对应 macOS、Windows 或 Linux 版本。打开 Model Settings，输入端点、模型 ID 和 Key，先进行模型测试，再回到仪表盘启动本地服务。首次配置或升级 Cursor 后，按 README 完全退出并重启 Cursor，新建会话选择配置模型；完整系统连接细节查 User Guide。

## 注意事项与相关项目
端点协议、模型工具调用和 Cursor 版本变化都可能影响适配。免费网关不代表上游 API 免费；不要把 Key 配给未经核实的渠道。Antigravity-Manager、sub2api 也属于接入管理方向，但面向的客户端与上游授权方式不同。
