## 它是什么
esbuild 是以构建速度为主要目标的 JavaScript 与 CSS 打包工具，内置 TypeScript、JSX、ESM/CommonJS、压缩、Tree shaking 和 sourcemap 等处理能力，提供 CLI、JavaScript 与 Go API。它可以独立处理入口文件，也经常成为其他前端构建工具的一部分；打包与完整应用框架是不同职责。

## 适合什么场景
适合给小工具或库建立直接的构建流程、转换 JSX/TypeScript 语法，或按浏览器与 Node 目标生成产物。它不意味着所有 npm 包都能放进浏览器，运行环境相关能力仍需明确。

## 如何开始
官方 Getting Started 先用 npm install --save-exact --save-dev esbuild 安装本地版本，再准备入口文件。简单构建可用 CLI，选项多时使用 .mjs 构建脚本调用 build。Node 产物应设置 platform: 'node'，浏览器是默认方向。

## 一个使用示例
官方示例节选，未执行：已有 app.jsx 及所需依赖时，在构建脚本中写：
```js
import * as esbuild from 'esbuild';
await esbuild.build({
  entryPoints: ['app.jsx'],
  bundle: true,
  outfile: 'out.js',
});
```
预期解析入口及依赖并输出 out.js。实际页面行为、类型正确性和性能收益需另行验证，这里只核对配置来源。

## 注意事项与相关项目
esbuild 使用平台相关原生可执行文件，不能把 macOS 的 node_modules 直接复制到 Linux 使用；目标平台通常需要重新安装依赖。官方指南也指出 Node 的原生模块及文件路径等特性存在打包边界，必要时保留依赖为 external。宣传中的速度倍数不是本项目实测结果。
