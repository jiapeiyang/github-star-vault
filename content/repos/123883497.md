## 它是什么
didact-explain 是 Didact 系列的中文翻译与说明，展示如何从 DOM 渲染开始，加入元素创建、JSX、更新与组件等机制。它通过小代码、在线例子和提交 diff 解释一个 React 式库如何逐步形成，便于理解框架抽象背后的基本操作。

## 适合什么场景
适合想从 createElement、属性设置和 DOM 节点关系理解 UI 库，而觉得大型框架源码过于庞大的人。它是教学用简化实现，不是 React 的完整功能清单，也不应用于替换现代生产框架。

## 如何开始
本次 README 标明翻译对应 2018-03-07 的上游提交。先读“渲染 DOM 元素”，再按表格进入元素创建、JSX 和后续章节。每行提供原文、中文、CodePen 或 diff；选择同一阶段的解释与代码配对阅读，避免混用上游后来的重写版本。

## 一个使用示例
官方阅读流程归纳，未执行：从“渲染 DOM 元素”的示例开始，追踪对象描述如何变成真实节点、属性怎样附加、子节点如何插入容器。再比较下一章 JSX 如何变成元素创建调用。预期看清声明式描述与 DOM 操作之间的转换，不必一次理解调度器全部细节。

## 注意事项与相关项目
文中旧 API、构建方式和调和算法有明确历史背景，不能当作当前 React 内部实现的逐行说明。中文译文有可能与后续原文产生差异，引用技术结论时保留提交边界。big-react 提供更接近 React 18 的逐步实现，可用于进一步对照。
