## 它是什么
SortableJS 是给列表增加拖拽排序的 JavaScript 库，支持同列表重排、跨列表移动、拖拽手柄、滚动与插件扩展，不依赖 jQuery。它处理的是元素拖放行为和相关事件；最终顺序如何保存、怎样与框架状态同步，需要应用接入。

## 适合什么场景
适合可调整顺序的菜单、看板列或文件列表，也可用于自定义布局编辑器中的简单排序。若使用 Vue 或 React，应同时考虑框架对数据与 DOM 的管理，避免只有视觉顺序改变。

## 如何开始
按 README 安装 npm install sortablejs --save，导入 Sortable，准备包含条目的容器，再创建实例。通过 handle 限定拖动区域，通过 group 控制跨列表关系；高级 MultiDrag 或 Swap 需要明确挂载相应插件，不是每种导入都包含所有插件。

## 一个使用示例
官方最小示例改写，未执行：
```js
import Sortable from 'sortablejs';
const el = document.getElementById('items');
Sortable.create(el, { animation: 150 });
```
前提是页面已有 id 为 items 且包含多个条目的容器。预期条目可拖动重排；要保存结果，还需处理事件或按数据 ID 读取顺序，本例未持久化。

## 注意事项与相关项目
oldIndex 与 oldDraggableIndex 等索引含义不同，混有非拖动元素时需按文档选择。README 包含 IE9 等历史兼容描述，目标设备仍需实测。拖拽支持不自动等于键盘无障碍体验，实际产品可增加明确的移动操作；本条没有验证触屏或跨框架行为。
