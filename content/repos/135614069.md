## 它是什么
reactjs-interview-questions 将 React 问题和解释放在长 README 中，用目录锚点定位基础概念、JSX、元素与组件、状态和生态用法。它另链接 JavaScript 与数据结构题库，明确本仓库聚焦 React，而非完整前端知识体系。

## 适合什么场景
适合想确认一个 React 术语、寻找英文解释，或围绕框架机制查相邻问题的人。大文件更适合按关键词和目录使用，不必从头读到尾；面试问答也不能替代当前 React 官方 API 说明。

## 如何开始
从 Table of Contents 选择问题，检查答案中版本、代码和延伸链接。遇到 JSX、组件与元素等基础主题，可把术语与一段自己熟悉的组件代码对应；涉及生命周期、并发或框架集成时，先确认示例适用于哪个版本。

## 一个使用示例
真实目录导航示例，未执行代码：先查“What is JSX?”，再查“What is the difference between an Element and a Component?”，把组件定义、调用结果与渲染描述分别标出来。预期得到清晰术语关系，避免把 JSX 标签、组件函数和真实 DOM 节点当成同一个对象。

## 注意事项与相关项目
README 同时包含历史说明、现代内容和第三方课程推广，推广效果不是技术证据。JSX 示例中传统 createElement 转换与现代自动 JSX runtime 也要区分。问题答案会持续修订；本次获取了完整 README 并校验 blob，但只核查所用介绍和示例范围，没有复验数百条答案或运行所有片段。
