## 它是什么

哪吒监控是自托管的服务器与网站监控工具。README 将系统状态采集、HTTP/TCP/Ping 检测、证书状态和推送告警列为主要能力，同时包含定时任务及 Web 终端。面板仓库与采集 Agent 分开维护。

## 适合什么场景

- 在一个页面查看多台 VPS 或自有服务器的运行情况。
- 区分主机运行正常、网站无法访问及证书即将到期等不同问题。
- 希望自己掌握监控数据及告警配置，并愿意维护面板和 Agent。

## 如何开始

1. 从 README 的中文文档进入部署说明。2026-10-13 核查时旧入口已跳转至 `nezha.wiki`，当前文档面向 V2；分别阅读 Dashboard 和 Agent 的 Release 与安装说明。
2. 先准备面板和一台获授权的测试服务器，再在管理界面确认通信入口，按对应系统说明接入该设备的 Agent。
3. 核对服务器是否出现及数据是否更新，再逐项配置网站检测和通知；远程终端与定时任务另行确认权限。

## 一个使用示例

说明性示例，未执行：监控一台自己的测试 VPS 和一个 HTTPS 测试站点。目标输出包含主机状态、HTTP 检测和证书提醒。面板可访问、Agent 上报和通知送达是三个独立检查点，不能只凭看到面板就认为告警有效。

## 注意事项与相关项目

监控面板还提供管理能力，其权限范围高于纯展示页。应核对访问控制、Agent 凭据和终端授权。本条核对 README 的能力范围及官方入口，未部署面板、连接机器或发送通知；完整安装参数以对应版本官方文档为准。Komari 可用于比较另一套轻量监控界面。

官方版本说明将产品代际、组件版本和 API 路径分开：Dashboard 与 Agent 独立发布，版本号不必完全相同，但不能推断任意组合兼容；`/api/v1` 路径也不能作为当前产品仍为 V1 的依据。先用一台机器验证连接和上报，再考虑扩大接入范围。本次文档核查没有验证具体版本组合。
