## 它是什么
Sub2API 在兼容客户端与上游模型服务之间管理鉴权、请求转发、账号选择、并发和用量。管理界面可分配 API Key、设置账户限制和模型分组，当前代码以 Go、Vue、PostgreSQL 和 Redis 组成。

仓库也提供计费与支付功能，但软件有此模块不代表取得上游订阅额度再销售的授权。接入能力与服务使用权需分别判断。

## 适合什么场景
在授权范围统一配置多个模型入口；观察调用量和限流；研究网关账号与用户并发控制。只需个人调用单个 API 时可能不需要完整平台。

## 如何开始
先读 README 的使用边界，选择二进制或 Docker Compose 部署。单独安装需要 PostgreSQL 15 以上与 Redis 7 以上；Compose 可同时提供这些服务。通过 Setup Wizard 完成数据库、Redis 和管理员配置，再以一个测试 Key 验证路由。

## 一个使用示例
说明性示例，未执行：在本机隔离环境接入一组合法模型配置，为测试客户端创建独立 Key，发出简短请求，然后核对日志中的模型、用户和 Token 记录。预期能区分是谁调用了哪个上游，不把仪表盘估算视为供应商最终账单。

## 注意事项与相关项目
上游服务条款与账号限制仍适用；不应通过调度规避访问禁令。公开管理面板需单独检查鉴权，备份包含凭证与用量数据。codex2api 也有兼容接口与账号管理，可按上游类型和部署结构比较。
