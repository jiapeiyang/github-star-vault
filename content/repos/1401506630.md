## 它是什么

XGift 是第三方 X Premium 礼品兑换项目，包含用户兑换页、管理后台、兑换码批次及订单处理。前端示例预览和真实 Go 服务是两种不同运行方式；真实流程可能使用账户凭据并产生付款。

## 适合什么场景

- 阅读兑换码、订单状态与管理界面的产品结构。
- 在不提供真实凭据的前提下查看项目自带的内存示例界面。
- 评估真实交易系统前，先区分预览、查询与付款动作。

## 如何开始

1. 先阅读 README 的“本地预览”说明，准备 Node.js 22+。
2. 在独立项目副本安装依赖并构建，采用预览入口查看兑换页和 `/admin`。
3. 真实部署另有 Go、Linux、域名及凭据要求，不能将预览完成当成已具备交易条件。

## 一个使用示例

官方预览命令摘录，未执行：

```sh
npm ci
npm run build
npm run preview
```

README 说明预览使用内存示例数据，可用 `XG-` 后接 48 个字母 `A` 演示成功状态。预期只是本地界面流转，不代表 X 账户获得订阅。本文没有安装依赖、导入 Cookie、保存支付资料或执行付款。

## 注意事项与相关项目

README 的加密、金额校验和重复付款防护属于上游实现说明，未经过本站安全审计。真实服务的管理补单会产生付款，和公开入口开关并非同一动作；凭据、数据库和密钥文件也需分别保护。任何交易用途都应先独立确认服务条款、授权和实际资金路径。
