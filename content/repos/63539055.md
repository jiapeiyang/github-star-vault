## 它是什么
Awesome Mac 是按用途收录 macOS 软件与相关工具的目录。它提供的主要价值是分类导航和项目入口，而不是一个可以安装后管理全部软件的应用。条目通常包含简短介绍、官网链接，并用图标区分开源、免费或 App Store 等信息。

浏览时应把“被收录”与“适合自己的机器和需求”分开：目录帮助发现候选，具体兼容性、当前价格和功能仍需到软件的上游页面核对。

## 适合什么场景
- 刚配置一台 Mac，需要按开发、终端、文件处理、窗口管理等用途寻找软件。
- 想替换某个现有工具，但记不起同类项目的名称。
- 对比多个候选的定位，先建立一个小范围清单，再去看官方网站。

如果你已经知道准确的软件名，直接查该软件的官方文档通常更快；这个目录更适合从需求反推候选。

## 如何开始
1. 从 Contents 选择用途分类，避免从几千行内容的第一行一直向下翻。
2. 在分类里阅读条目描述和许可/分发方式标识。
3. 打开候选官网或源码仓库，核对系统版本、芯片支持、定价及维护状态。
4. 确认适合后，再通过官方推荐渠道获取软件。

阅读目录不需要 clone、npm install 或启动开发服务器。

## 一个使用示例
假设你需要“在 Mac 上查看和处理压缩文件”：

1. 在目录中进入 Utilities 下的 File Organization Tools。
2. 找到 Keka 条目。当前目录将它介绍为支持多种格式的开源压缩与解压工具。
3. 通过条目链接进入 Keka 官网，核对当前版本和分发方式，再决定是否安装。

如果需求改成终端，可以进入 Terminal Apps，找到 iTerm2 等候选。这个示例核对了目录中的真实条目和链接，没有下载或运行软件，也不代表对这些工具做了独立性能比较。

## 注意事项与相关项目
目录同时包含开源、闭源、免费与付费软件。不能把 Awesome 列表的仓库许可套用到被收录的软件上，也不能把旧描述当成实时价格。条目失效时应回到目标软件的官网或仓库确认，目录本身不提供软件更新服务。
