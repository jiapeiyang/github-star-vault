## 性能证据与决定

[可复现测量](audits/v1.4/catalog-performance.json) 使用真实新目录，Node 单进程各项预热 10 次、测 50 次；冻结检索 20/20 达标。运行：

```shell
node app/scripts/measure-catalog.mjs docs/audits/v1.4/catalog-performance.json
```

- 目录原始 1,332,167 字节，本地 gzip 估算 365,555 字节；后者不是线上压缩承诺。
- JSON 解析 p95 1.218ms；313 项默认过滤排序 p95 0.307ms。
- 20 个查询中最慢 p95 4.527ms；无结果建议 p95 6.541ms。这里只测业务计算，不包含 DOM。
- 本机回环网络、禁用 HTTP 缓存，首页每种模式各 3 次：桌面 DOM 就绪 38.1～39.4ms，FCP 52～68ms；390px/CPU 4 倍降速 DOM 就绪 86.7～112.2ms，FCP 72～100ms。
- 完整 313 行列表各测 1 次：桌面 DOM 就绪 57.1ms，降速窄屏 168.3ms；后者观察到 91ms 与 54ms 长任务，不能写成完全无卡顿。
- 本地预览实际传输 catalog 为 365,855 字节（含响应头观察），解码为 1,332,167；没有测量线上 Pages 或真实移动网络。

当前过滤与解析没有显示需要引入缓存、分库或搜索重写。降速列表的两个长任务和单个样本保留为后续真实设备观察项；本轮不据此扩大为虚拟列表、分页或 Worker 重构。它也不是 LCP、INP 或真实手机的性能保证。慢网络下完整目录仍须下载，这个边界不被本机数字掩盖。
