## 它是什么
FE-Interview-Questions 是前端面试资料库，README 按主题链接到独立 Markdown，另有精简版、综合问题版和问答版。题目覆盖 HTML/CSS、JavaScript、网络、存储、跨域、Vue/React、性能、安全与手写代码，适合作为检索入口。

## 适合什么场景
适合不记得题目出处但记得主题，或想围绕一个问题寻找相邻概念时回查。它不提供统一运行环境，也不是对当前所有浏览器和框架版本逐项验证的规范文档。

## 如何开始
直接在 GitHub 阅读分类文件，或进入 README 的在线阅读站。先用问题版定位薄弱或感兴趣的点，再看问答版与原始参考；需要验证代码时，明确使用浏览器还是 Node，以及具体版本。

## 注意事项与相关项目
目录同时保留 jQuery、JSON/XML 等历史主题与现代框架，阅读时要按项目年代选择。问题答案可能是简化归纳，实际业务边界与异常路径需要自行补充。本站只核查索引结构和阅读入口，不把全部答案标为已独立验证。
