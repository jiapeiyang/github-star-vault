## 它是什么
PPT Master 在具有文件和命令能力的代理中运行，将来源文档整理成演示并导出原生 PPTX。其重点是保留文字、形状、连接线、图表等对象的编辑能力，而不是把每页压成一张图。

除了新建演示，项目也有从参考中提炼模板、填充已有 PPTX、添加动画与旁白等路径，每种路径有不同保留契约。

## 适合什么场景
从 PDF、Word 或网页做汇报；最终还需在 PowerPoint 修改数据和排版；想复用现有品牌模板，并让代理承担大部分机械制作。

## 如何开始
准备 Python 3.10 以上和能读写文件、执行命令的代理，取得项目后安装 `requirements.txt`。把材料与目标受众、页数交给代理，按 Getting Started 选择新建或模板路线。旧格式可能另需 Pandoc，常见 DOCX 等已有 Python 处理入口。

## 一个使用示例
官方工作流改写，未执行：给出项目报告，要求生成一份包含原生图表和可编辑表格的演示。先确认叙事结构，再生成并在 PowerPoint 中选中标题、图表和连接线检查编辑性。预期是可继续工作的 PPTX，不承诺一次生成即免精修。

## 注意事项与相关项目
PowerPoint 与 SVG 映射并非无限覆盖，README 明确 SmartArt 是刻意未实现项。材料除模型通信外在本机处理，但模型请求仍有数据边界。Dashi 更强调网页控制台，本项目强调 PowerPoint 原生对象。
