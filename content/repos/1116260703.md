## 它是什么
这是曾承载 GSD 开发的仓库。当前 README 已替换为迁移公告，明确说明此处不再是活跃开发主仓库，源代码、问题反馈、发行版本和贡献工作继续在 open-gsd/gsd-core 进行。因此这条收藏目前最主要的价值是保留历史地址，并帮助找回项目的新入口。

## 适合什么场景
适合回顾当时收藏的 Get Shit Done、确认旧教程或链接为什么与当前代码不同，以及定位新的 GSD Core。若要使用最新流程，应从新仓库出发；若复核某次历史实现，需要明确当时的提交或标签，不能直接把新仓库说明当作旧版本行为。

## 如何开始
打开当前 README 的迁移链接，进入 open-gsd/gsd-core；在那里阅读安装器、宿主支持和命令参考。已有旧安装的用户，应先记录安装来源和当前版本，再根据新仓库说明处理迁移。本站没有在旧仓库 README 中找到仍有效的安装步骤，因此不继续推荐旧包名或旧斜杠命令。

## 一个使用示例
导航示例，未执行安装：从收藏条目进入旧仓库，看到“GSD Has Moved”，点击 GSD Core 链接，随后查看新仓库 Quickstart 和已有项目 onboarding 文档。预期是找到维护中的项目入口，而不是在旧仓库提交问题后等待维护者处理。

## 注意事项与相关项目
迁移公告能证明开发入口变化，不能证明所有旧配置都能原地兼容。历史 Release、文章和本地技能可能仍保留旧名称；再次使用前应核对实际目录、命令及版本。相关项目就是 open-gsd/gsd-core，本站另有解读；本条不为旧版本编造运行示例，也不把迁移说明算作当前工具的完整功能文档。
