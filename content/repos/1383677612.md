## 它是什么
BaoCode 是使用 Flutter 构建的 Claude Code 桌面界面，包含编辑器、终端、Git、变更审阅和插件管理。它本身没有独立编码代理，实际工具执行由已有 Claude Code 承担；检查点放在应用自己的数据目录。

## 适合什么场景
希望用桌面窗口阅读长会话、逐文件保留或撤销修改，或将终端代理和 IDE 放在一起。还提供 SSH 项目入口，远程模式的文件与命令在远端主机执行。

## 如何开始
先安装并配置 Claude Code，再从官网下载适合系统和架构的包。README 列出 macOS 12+、Windows 10+ 和相关 Linux 发行要求。源码开发需要 Flutter 与对应 Dart SDK，普通使用无需先自行编译。
