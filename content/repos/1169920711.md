## 它是什么
Excalidraw Diagram Skill 是给支持 Skills 的编码代理使用的绘图流程。输入是文字说明及必要的代码、数据例子，产物是 Excalidraw JSON 文件和供检查的渲染图。设计规则要求图形关系对应真实概念，例如用分支表示一对多，用汇合表示聚合，用时间线表达顺序。

仓库同时提供元素模板、JSON 格式参考、配色文件和基于 Playwright 的渲染脚本。代理可以查看生成结果，修正文字重叠、箭头错位和间距问题；这套流程的存在不代表每次生成都能自动通过验收。

## 适合什么场景
- 把一个协议、请求流程或系统关系解释给同事，并保留可继续编辑的图。
- 图里需要真实代码片段或 JSON 样本，而不仅是几个抽象方框。
- 团队希望统一图表配色，通过一个配色文件维护视觉约定。

## 如何开始
先准备能加载 Skills、读写文件的代理。README 的安装示例把仓库复制到项目的 `.claude/skills/excalidraw-diagram`；使用其他宿主时应确认其技能目录。

```bash
git clone https://github.com/coleam00/excalidraw-diagram-skill.git
mkdir -p .claude/skills
cp -r excalidraw-diagram-skill .claude/skills/excalidraw-diagram
```

如需渲染验收，还要有 `uv`，并按上游说明在技能的 `references` 目录运行 `uv sync` 和 `uv run playwright install chromium`。这一步会安装依赖与浏览器。之后提供图的目标、关系和证据；配色可在 `references/color-palette.md` 调整。

## 注意事项与相关项目
它需要宿主模型和本地渲染工具配合，并非独立在线绘图网站。技术事实由输入证据决定，截图检查主要覆盖视觉问题。本站未安装渲染依赖，也未验证不同宿主的自动加载和最终绘图质量。
