## 它是什么
Taro 是跨端、跨框架应用开发方案，让开发者用 React、Vue 等框架组织界面，再面向小程序、H5 或 React Native 等目标构建。它试图减少为每种终端完全重写业务代码的成本。理解它时需要同时考虑所用框架、Taro 主版本和目标平台，而不是把所有浏览器代码直接搬到小程序。

## 适合什么场景
适合一项业务要覆盖微信小程序和 H5，或已有 React/Vue 团队希望复用部分开发方式的场景。单端项目也能使用，但跨端收益应与平台差异、构建配置和组件兼容成本一起评估。

## 如何开始
从 README 的“5 分钟上手 Taro 开发”进入官方 guide，按当前主版本准备 Node 与 CLI 环境，创建最小工程并选择框架、模板和目标端。先编译默认页面，在相应开发工具中打开输出，再逐步加入业务组件。当前 README 没列完整安装命令，具体命令应以该 guide 为准。
