## 它是什么
wechat-app-demo 保存微信小程序早期组件与 API 演示。app.json 将页面分为“组件”和“接口”两个 tab，包括表单、媒体、导航、存储、网络、位置等示例；app.js 展示基本应用生命周期。README 指向后续 wiki 和旧官方文档，fix.md 留有 2016 年修正记录，因此应按历史示例理解。

## 适合什么场景
适合找回原生小程序 WXML、WXSS、Page 与 App 的组织方式，或查看某个 API 的最小操作页面。它不是当前完整业务模板，涉及登录、支付、位置与网络的能力仍有当前平台条件。

## 如何开始
只读可从 app.json 找目标页面，再打开同路径的 js、wxml、wxss。需要运行时应使用当前官方开发工具导入自己的测试项目，并先核对项目配置、基础库与旧 API 的兼容性；仓库根目录没有现代 project.config.json 的完整入门配置。
