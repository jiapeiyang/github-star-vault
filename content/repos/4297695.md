## 它是什么
zemirco/json2csv 是 JSON 转 CSV 库截至 v5 的历史仓库，README 明确标记已弃用，并指向 juanjoDiaz/json2csv。v6 起功能拆为独立包：plainjs、Node 流、WHATWG 流、CLI、transforms 和 formatters。因此找回这条收藏时，首先要确认要维护旧 v5 代码，还是使用迁移后的新包。

## 适合什么场景
适合把结构化记录输出为表格文本，或者检查旧导出代码的迁移方向。CSV 不包含 XLSX 工作簿样式；大数据导出还要区分一次性内存转换和流式处理。

## 如何开始
新用法应进入 README 指定的新仓库，按运行环境选包。小数据可安装 @json2csv/plainjs 并使用 Parser；Node 流任务则查看 @json2csv/node。先明确字段顺序、缺省值、分隔符和换行需求，再核对解析器选项，不能直接沿用所有旧包导入方式。

## 一个使用示例
新上游官方 API 改写，未执行：
```js
import { Parser } from '@json2csv/plainjs';
const parser = new Parser({ fields: ['name', 'count'] });
const csv = parser.parse([{ name: 'demo', count: 2 }]);
console.log(csv);
```
预期生成带 name、count 表头的一条 CSV 记录。本例属于迁移后包的接口，不宣称适用于旧 v5。

## 注意事项与相关项目
同步 Parser 会把输入和输出放进内存，并在处理时阻塞事件循环，适合小数据；流式版本也需调用方正确消费输出。CSV 的引号转义不等于防止电子表格将内容解释为公式，面向外部输入导出时需按消费端处理。本文未生成文件或核对 Excel 打开效果。
