## 它是什么
learning-rxjs 是配合系列文章逐步实现应用的示例仓库。README 指向 Hello RxJS、用 RxJS 连接世界和掌控异步等文章，package.json 将项目描述为用 RxJS 实现 TodoMVC，并包含 TypeScript、webpack 与 Koa 服务端。它让事件和异步逻辑在一个小应用中汇合，适合理解早期 RxJS 用法。

## 适合什么场景
适合通过具体应用观察响应式流、前端与服务端的协作，或维护使用 RxJS 5 的旧代码。它不是现代 RxJS 的通用模板，依赖版本和文章对应分支是阅读时的关键前提。

## 如何开始
README 要求取得仓库后切到 seed 分支，再跟随文章实现，并建议使用 Yarn。当前 package.json 的 start 同时运行 serve 与 dev，dev 使用 3000 端口；serve 先编译 server TypeScript，再运行输出文件。实际复现应先核对所用分支与锁文件。
