## 它是什么
AI Website Cloner Template 为代理提供网站复刻工作流和现成 Next.js 工程。用户给 URL，代理浏览参考、重建界面，再在独立项目中继续定制。它更偏快速形成新的前端实现，不应默认等同完整源代码恢复。

## 适合什么场景
为获授权的页面做可修改原型；从明确参考建立新项目；希望模板中已经有代理入口和工程命令。依赖复杂后端的行为不能只靠页面外观还原。

## 如何开始
当前 README 要求 Node.js 24 以上，可从 GitHub 的 Use this template 创建自己的仓库，也可让代理在新目录建立独立副本。安装依赖后先运行 `npm run check`，它组合 lint、类型检查与构建。再启动具有浏览器能力的代理，在支持的客户端调用 `/clone-website` 并提供 URL；其他宿主可明确要求使用该工作流。

工作流依次映射路由、观察桌面与移动页面、实现、同尺寸对照。共享技能位于 `.agents/skills/clone-website/`，Claude Code 使用薄命令桥接；不要在同一工程中维护多份重复技能。
