## 它是什么
draw-ui 是给 Agent 使用的 UI 设计 Skill。它先澄清页面目标、真实内容、已有参考和不能改动的区域，再生成设计稿。另一条路径是把已确认的设计稿还原为 HTML/CSS、现有前端项目或微信小程序，并对照真实页面进行测量和检查。

设计稿只是视觉产物；可运行页面还要实现布局、文字、控件和交互。仓库强调将可编辑代码与摄影、插画等图片素材拆开，避免用整张截图替代网页。

## 适合什么场景
- 为产品后台、App 页面或完整落地页探索视觉方向。
- 保留既有导航和侧边栏，重新设计某个业务内容区。
- 已有明确设计稿，需要按现有项目技术栈还原和校准。

## 如何开始
README 提供 `npx skills add oil-oil/draw-ui`，也可把仓库地址交给支持 Skills 的代理安装。准备页面目标、真实文案、参考截图以及允许修改的范围。

设计流程需要宿主能生成和查看图片；默认复用宿主现有能力。外部服务脚本是可选路径，使用时另行配置凭据和额度。本地脚本需要 Python 3.10+，图片处理使用 Pillow。需要真实网页或小程序验收时，还须具备对应运行和检查环境。

## 一个使用示例
官方流程改写，未执行：给出已有后台截图，要求“保留侧边栏，为创作者增加 30 天趋势、热门内容和收入页面，先生成设计稿”。确认稿件后，再要求按项目现有框架实现，并说明哪些素材需要单独准备。

第一步预期是设计稿和实现说明；第二步才是可运行界面及相同视口下的对照结果。应分别检查数字和文字可编辑、筛选器能工作、移动端布局合理，不能把生成图当成这些检查已通过。
