## 它是什么
Understand Anything 用 Tree-sitter 提取定义、导入、调用等结构信息，再由模型补充摘要、层次与业务解释，生成可搜索的交互图。结构视图帮助定位文件和依赖，domain 视图表达业务过程；还可对知识库文档生成概念关系。两类关系的证据强度应分别理解。

## 适合什么场景
适合接手陌生代码库、找模块入口和观察修改影响范围。图上的自然语言解释能减少初读成本，但审查具体行为仍需回到源码和运行证据；动态调用或模型推断的业务关系不能只凭图形认定。

## 如何开始
Claude Code 可按 README 添加 Egonex-AI/Understand-Anything marketplace 并安装插件，然后在项目中调用 `/understand`。Codex 等宿主使用对应安装脚本与调用语法，Codex 为 `$understand`。希望中文说明可按宿主传递 language zh。图数据默认写入 .ua/knowledge-graph.json，已有旧目录时继续沿用。

## 注意事项与相关项目
首次全仓分析可能消耗大量 token，之后默认增量更新。多代理流水线、语义搜索与图形页面承担不同职责，部署前应确认各自依赖和成本。资料导出、图缓存和外部模型处理的范围应在分析私有项目之前核对。
