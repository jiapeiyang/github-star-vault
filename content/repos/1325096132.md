## 它是什么
shuohao-skills 是围绕 AI 短剧制作组织的五个 Skills：改编大纲、角色设定、美术设定、剧本和分镜。它把一本小说逐步转成更明确的制作资料，而不是只给视频模型输入一条宽泛提示词。

当前 README 强调先让改编大纲收敛结构，再让剧本、场景和角色同步迭代，分镜阶段负责输出既定决定。各 Skill 有自己的 JSON、Markdown 和 HTML 报告，也能按需要单独使用。

## 适合什么场景
需要把故事拆成分集、角色和场景资产，或希望不同生成阶段共享一致设定时，可以查看这套流程。只需要人物设定时不必跑完整五段；如果目标是直接剪辑成片，则还需要另外的视频生成、配音或编辑工具。

## 如何开始
1. 阅读五个 Skill 的职责，确定已有输入属于哪一阶段。
2. 准备 Node.js 18+ 和可用的宿主会话；README 说明确定性脚本不依赖 npm 包。
3. 获取仓库后阅读安装脚本，再按需要安装单个 Skill。
4. 给任务指定独立的输出目录，按阶段保存 JSON 与报告，避免素材相互覆盖。

```shell
./scripts/install.sh novel-characters
```

这是仓库目录中的脚本。它通过软链接安装，更新仓库可能同时改变实际生效的 Skill。

## 一个使用示例
已有一个短剧大纲时，可以先让 novel-characters 读取其中的角色清单，生成角色画像及形象/音色提示词，再检查人物是否与剧情一致。完成多个阶段后，上游提供报告组装命令：

```shell
node scripts/report.mjs --from demo --out report.html
```

其中 demo 应是遵循工作目录约定的真实产物目录。预期报告按已存在阶段显示面板，不能把一个空目录当成完整影片输入。本示例来自 README，未安装 Skill、生成图片或制作视频。

## 注意事项与相关项目
文字报告与实际生成素材是不同交付；图片生成需要相应宿主能力。README 中的测试数量、质量门和跨平台支持属于上游自述，本站未复验。仓库还链接独立的视频工作台与付费社群，这些服务不等同于开源 Skill 本身。
