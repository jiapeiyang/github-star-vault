## 它是什么
underscore-analysis 围绕 Underscore 1.8.3 提供原始源码、全文注释版和按方法组织的文章。主题包括类型判断、createAssigner、相等比较、数组去重与展开、group、bind、防抖节流、memoize 和 template。它的价值是透过一个体量适中的工具库理解函数设计、复用和旧浏览器兼容处理。

## 适合什么场景
适合维护依赖 Underscore 的旧项目，或对某个常用工具函数为什么这样实现感兴趣。它不是当前 Underscore 发布包，也不保证所有示例都适用于最新 JavaScript 环境。

## 如何开始
从 README Source 选择原版与注释版对照，再按 Article 目录找专题。先看方法对外用途与输入，再读内部辅助函数；遇到历史兼容分支应保留原版本背景，不急于判断为多余代码。单纯阅读无需安装整个库。
