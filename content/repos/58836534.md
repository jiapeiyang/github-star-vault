## 它是什么
Algorithm Visualizer 是把算法代码转成可视过程的交互平台。这个仓库主要负责 React 界面及把可视化命令解释成图形；算法样例在 algorithms 仓库，不同语言的 tracers 库负责从代码中产出可视化命令，server 负责运行时所需 API。这几部分共同组成体验，不能把当前仓库当成所有算法与执行环境的总包。

## 适合什么场景
适合看排序、图搜索等算法的中间状态，制作讲解时也可借它解释“某一步为什么这样变化”。如果只要生产可用的算法函数，应回到具体实现和数据约束；动画不是性能基准。

## 如何开始
普通使用从 README 的在线演示进入，在侧边菜单选择算法并阅读关联代码，观察每个步骤对应的状态。修改可视化内容时先查 algorithms，修改界面时查本仓库贡献指南，新增语言追踪能力时查 tracers。README 没有给出完整本地部署流程，不应假造一个单仓启动命令。

## 一个使用示例
说明性操作示例，未执行：目标是观察一个排序过程。选取平台已有排序样例，先标记初始数组，再跟随代码与图形查看比较或交换发生的位置。预期理解数组怎样逐步变有序；本文没有打开在线演示或编译用户代码，也不保证任意自写程序可直接可视化。

## 注意事项与相关项目
代码要通过相应 tracer 表达可视化步骤，通常不是把任意源文件上传就自动理解。线上编译、登录等功能属于 server 边界，主界面能加载不代表全部服务可用。与静态算法书相比，它侧重动态过程，推导、复杂度和正确性仍需另行说明。
