## 它是什么
DevSpace 将本地项目的读取、搜索、修改、运行命令与 worktree 能力作为 MCP 工具提供给 ChatGPT 等客户端。服务在自己的机器上运行，远端客户端通过用户配置的 HTTPS 隧道连接并经过 Owner 密码批准。

它是本地机器远程访问入口，不是把项目复制到另一个 IDE。允许项目根目录与强大的 shell 能力需要一起理解，不能仅凭路径白名单推断完整系统隔离。

## 适合什么场景
在聊天客户端操作实际本地工程；希望复用本机工具和项目指令；需要用标准 MCP 接口连接自有开发环境。

## 如何开始
当前要求 Node `>=22.19 <27` 和 Bash 兼容环境。安装 `@waishnav/devspace` 后运行 `devspace init`，选择客户端与允许目录。ChatGPT 模式另填公网 HTTPS origin，启动 `devspace serve` 后将客户端接到 `/mcp`。用 doctor 核对环境，再批准连接。

## 注意事项与相关项目
Owner 密码与 `~/.devspace/auth.json` 需保密。Windows 仅有 PowerShell/cmd 不够，还需要 Git Bash 或 WSL 等。文件片段可能通过 MCP 返回远端模型，因此“本机运行”不等于内容完全不出机。
