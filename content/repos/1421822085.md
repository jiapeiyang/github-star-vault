## 它是什么
Purge Community 是 DeepSeek Harness 的社区附加组件，提供提示词与预设管理、补丁状态检查、操作记录和恢复能力。它改变本机宿主交互与配置，不改变远端模型权重。社区索引和安装器由该仓库维护，并非 DeepSeek 官方脚本。

## 适合什么场景
在自己的本机环境研究提示词、预设与宿主行为，希望明确哪些修改已经应用、如何恢复。它会触及宿主文件和运行策略，应先确认实验目标与现有安装版本。

## 如何开始
先初始化 Harness，核对 README 的兼容表，再选官方插件界面或适合实际 profile 的 CLI 入口。已有旧插件时按迁移说明操作；安装、应用补丁和重启是独立步骤。社区安装器的 `dry-run` 只代表前置检查和下载校验，并非完整迁移或启动通过。

## 一个使用示例
只读诊断示例，未执行：在已自行安装的环境查看面板状态，或按 README 运行 `purge-community selfcheck --json`，区分安装、补丁与注入是否就绪。先保存诊断结果，再决定是否需要改变预设或恢复。

## 注意事项与相关项目
本轮 README 标注的已验证宿主是 DSH Desktop 0.2.1-rc.1／rc.2，不能外推到所有版本。备份与回滚的有效性需要目标环境验证；不要因“减少确认”就扩大任务权限。它与 YuJunZhiXue/dsh-purge 名称相近，但包名、安装器和兼容说明需分别核对。
