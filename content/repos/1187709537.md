## 它是什么
DingTalk Workspace CLI 的命令名是 `dws`，把钉钉工作空间服务暴露为适合人和代理使用的命令。输出支持表格和 JSON，`--dry-run` 可预览请求，schema 描述参数、风险和约束。

项目当前处于共创阶段，访问企业数据需要管理员授权。安装程序和获得企业服务权限是不同步骤；schema 查询只是了解命令契约，不会读取业务数据。

## 适合什么场景
查找文档和日历；按条件查询多维表；将已授权的工作任务纳入脚本或代理。跨产品流程可按需加载技能，默认 multi 布局减少无关上下文。

## 如何开始
按系统安装官方 CLI，完成 Getting Started 的企业授权。先用目标命令 `--help` 确认当前二进制支持的参数，再看窄范围 schema，最后执行实际产品查询。需要写操作时先预览具体对象与请求，避免把安装授权推断为业务写入授权。

## 一个使用示例
官方只读命令改写，未执行：

```shell
dws doc search --query "quarterly"
```

目标是找季度相关文档，预期返回当前身份有权访问的匹配结果。继续读取应使用结果中的真实文档标识，而非猜测 ID。

## 注意事项与相关项目
Help 与 Schema 不一致时属于契约漂移，应以二进制接受参数为界。企业权限、账号登录和对象访问缺一不可。botmux 桥接飞书与本机 CLI，本项目直接封装钉钉产品 API。
