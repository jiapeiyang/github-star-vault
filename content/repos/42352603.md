## 它是什么
这是偏后端视角的 Node 面试问答库，README 本身包含问题、简短答案和代码片段。主题从 ES6、作用域和继承延伸到事件、流、网络、异步、部署、调优，以及数据库和 Web 服务器。它试图把 Node 核心知识与后端工作联系起来，不是官方语言规范或一套可直接运行的服务。

## 适合什么场景
适合根据问题快速找概念范围，或整理面试讨论的起点。对排查实际 Node 行为也能提供关键词，但简短参考答案不能替代版本明确的文档与代码验证。

## 如何开始
从大纲选择核心模块或高级话题，先读问题再判断它关注语言机制、运行时还是部署。需要复现片段时，先分清浏览器与 Node 环境；README 的部分 JavaScript 例子使用 alert，不能原样当作 Node 脚本运行。对内部架构细节应继续查当前 Node 文档。

## 注意事项与相关项目
资料保留“ES6 新特性”等历史表述，个别 API 名称与简化代码需要重新核对。例如 console.warning 并非应直接采用的标准 Node 写法。与 deep-into-node 相比，这里覆盖广而解释短；底层调用路径需要另读版本匹配的源码分析。
