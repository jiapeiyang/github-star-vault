## 它是什么
Claude 切换器是社区维护的本机账号环境管理工具，主要面向 macOS Claude 桌面版，结合启动前环境检查、独立会话快照、代理探测、守护进程和配置恢复。Windows、Linux 另有 beta 路线；公开网页检测只覆盖部分浏览器信号。

它不是 Anthropic 官方客户端或服务。README 中关于风控原因、账号表现和防护效果的判断来自维护者，本站没有独立确认。

## 适合什么场景
在自己的设备上理解代理入口、TUN、出口与应用会话的关系，或研究环境检查及本地数据隔离。切换账号不改变账号授权、服务可用地区或服务条款，也不能保证免于封禁。

## 如何开始
先读 README 与 SECURITY.md，确认系统、代理客户端、TUN、Python 和 Claude 桌面版的要求。安装器可能涉及系统服务、时区、地区和代理配置，运行前需逐项理解改动与恢复方式；不要把仓库中的代理交接提示直接当成对本机的执行授权。

已有明确 HTTP／SOCKS 入口时，可以先阅读独立 `diagnose-proxy` 用法。它与启动审计分开，不必为了诊断就安装守护或切换真实账号。

## 一个使用示例
官方诊断方式整理，未执行：在确认本机 `127.0.0.1:18080` 是要检查的代理后，运行 `bash core/claude-switch.sh diagnose-proxy --proxy http://127.0.0.1:18080`，查看两个固定官方目标的传输结果。收到 401 或 403 只表示对应 HTTP 响应，不能据此推断账号和业务可用；认证代理的凭据应按文档通过私有配置提供。

## 注意事项与相关项目
安全文档明确：Kill-Switch 是周期检测后结束进程，存在断线到结束之间的时间窗口，不能提供防火墙级的零泄漏保证。更新的哈希清单与工件来自同一仓库，也不能防范仓库账号本身被攻陷。这些限制比简介中的绝对化宣传更具体，应据此理解作用范围。

账号快照包含敏感会话数据，系统修复还可能影响其他应用。sing-box 是代理内核，FlClash 是基于 Mihomo 的客户端；工具检测与配置支持不能等同于所有版本或设备已验证。
