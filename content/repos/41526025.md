## 它是什么
《中文文案排版指北》用规则与正误对照统一中文技术文案的写法，涉及中英文空格、数字、标点、全角半角、专有名词大小写和链接样式。它解决的是团队文档与界面文案不一致的问题，属于人工可读的编辑指南，并非安装后会自动修正文稿的工具。

## 适合什么场景
适合整理 README、产品帮助和中文技术文章，或在团队里讨论一套共同写法。它包含项目自己的约定与争议项，不能把每条规则当成中文语言或计量标准的唯一要求。

## 如何开始
先查看目录，选与当前文案相关的章节，再看正确与错误示例。将团队接受的规则应用到普通文句，代码、URL、命令和官方产品名按原样保留。对数字与单位等可能有不同标准的内容，应先确定团队采用的规范，避免机械替换。

## 一个使用示例
官方规则改写，未执行：可将“使用GitHub管理3个项目”整理为“使用 GitHub 管理 3 个项目”，让中英文与数字的边界更易读。预期改善同一段文案的视觉一致性；这不涉及改变代码标识符、路径或产品正式命名。

## 注意事项与相关项目
这个分支明确采用“数字与单位无需增加空格”的约定，而部分专业排版规范采用其他写法，应按使用场景选择。README 关于旧 Microsoft CSS 自动空格属性的说明带有历史背景。指南还区分争议规则，最终文案应以读者理解和团队一致性为准，不必为了形式牺牲精确含义。
