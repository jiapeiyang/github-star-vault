## 它是什么

233boy/Xray 是 Xray 安装与管理脚本，不是 Xray 核心本身。README 以多配置同时运行和常用增删改查为中心，列出 TLS、常见协议和快捷参数等能力。

## 适合什么场景

- 在自己管理的服务器上了解 Xray 的安装与配置管理方式。
- 已有配置，需要查询脚本提供的管理命令。
- 希望明确服务端管理脚本与桌面客户端的职责差异。

## 如何开始

1. 打开 README 指向的安装文档，确认系统要求、端口、权限和已有服务冲突。
2. 执行安装前阅读对应版本的脚本，并保留现有配置；不要将“一键”理解成没有系统变更。
3. 已完成安装时，先使用文档中的帮助入口了解可用管理动作，再按实际需求操作。

README 中“零学习成本”和速度描述属于作者宣传，不作为使用保证。本条未运行安装、修改防火墙或连接远端服务。配置包含身份参数时需按凭据保护；服务端安装完成后仍要独立验证客户端与网络链路。
