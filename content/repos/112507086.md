## 它是什么
30 seconds of code 目前定位为编程文章与短代码片段站点，README 把阅读入口集中到 30secondsofcode.org。站点按文章和集合组织内容，可通过名称、标签、语言和描述寻找主题，每张卡片通向包含代码、解释和示例的完整文章。它是用于按需查阅的资料库，不是一个把所有片段一次安装进项目的 npm 包。

## 适合什么场景
适合处理一个小型编程问题时寻找短例子，或通过同一主题集合浏览相关写法。若要直接用于业务，应先看输入类型、边界和代码许可，不能只复制搜索卡片上的标题。

## 如何开始
按 README 进入网站，使用具体功能词和语言筛选；找不到精确词时再看 collections 的主题分组。打开文章后先读说明，再查看片段和示例。当前 README 没有提供本地站点启动步骤，普通浏览无需克隆源码。
