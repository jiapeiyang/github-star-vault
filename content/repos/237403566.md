## 它是什么
awesome-books 按书籍类别整理书名、豆瓣评分及获取入口，README 声称按评分 7 以上筛选。已见 Java 目录包括 Effective Java、设计模式、Java 8、性能、Maven、Netty 和 Spring Boot 等不同主题。它是一份选书清单，评分和下载图标只是目录信息，不是内容质量或授权的认证。

## 适合什么场景
适合想起大概主题却忘记书名时查找，或者比较同一语言不同方向的书籍。它不提供统一课程，也不要求读完全部书目；面向某个版本的需求应优先看版次和出版时间。

## 如何开始
先在目录中找到技术主题，核对书名、版次与评分链接，再前往作者、出版社或正规阅读渠道了解目录和获取方式。仓库中的文件链接不必作为首选下载途径，尤其当没有核实转载授权时。浏览索引本身无需安装任何工具。

## 一个使用示例
说明性导航示例，未执行：准备了解 Java 8 的函数式特性，可在 Java 分类比较“Java 8 函数式编程”和“Java 8 实战”，通过书目页看章节覆盖，再选择符合问题的版本。预期确定书籍候选，而不是仅靠一个评分断言哪本适合所有人。

## 注意事项与相关项目
README 保留 guanpengchn/awesome-books 的资源链接，说明索引与文件可能来自不同仓库位置，实际访问以目标为准。豆瓣分数会变化，旧版书的 API 也可能过时。本站未下载或审阅书籍全文，公开可访问的 PDF 不等于可自由复制传播；若需要免费计算机书目，可另看 ruanyf/free-books 的在线资源目录。
