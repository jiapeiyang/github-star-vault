## 它是什么
wshobson/agents 以 plugins 目录为单一内容来源，把 Python、架构、安全、文档等领域能力打包为独立插件。每个插件可包含 agents、commands 和 skills；不同宿主通过原生注册表或生成的适配文件读取。它是工作流与提示资料集合，实际执行仍由所选编码宿主完成。

## 适合什么场景
适合为一个明确领域补充代理角色或技能，例如 Python 测试、后端 API 或文档维护。只需要一项技能时不必安装整个市场；README 的 skills-only 路线也明确不包含代理、命令或 Hooks。

## 如何开始
Claude Code 可先 `/plugin marketplace add wshobson/agents`，再安装如 python-development 的插件。需要单技能时，官方示例是 `npx skills add wshobson/agents --skill python-testing-patterns`。其他宿主应先读 docs/harnesses.md，确认是原生 marketplace 安装还是 clone 后生成，避免混用路径。

## 注意事项与相关项目
README 的插件与代理数量随版本变化，不代表它们全都在一次安装中加载。宿主的权限字段、模型映射和命令能力不同，适配表比笼统“支持”徽章更有用。模型层级是仓库配置策略，不能替用户决定实际可用模型、费用或未经授权的并行任务。
