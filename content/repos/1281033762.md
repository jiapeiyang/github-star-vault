## 它是什么
EdgeEver 是开源笔记与知识库，保留“目录树、笔记列表、编辑器”三栏布局，支持富文本与 Markdown、标签、附件、修订历史和网页剪藏。它还提供桌面、移动端与浏览器扩展，以及供代理管理资料的 Remote MCP。

Cloudflare 路线使用 Workers、D1、R2；Docker 路线使用同一套业务应用，搭配 SQLite 和本地文件或兼容 S3 的附件存储。它是完整知识库应用，不是单纯的 Markdown 文件夹或向量检索库。

## 适合什么场景
希望自行管理资料与同步服务，又需要网页剪藏、多端编辑和助手访问知识库。可先用少量非敏感笔记验证编辑、同步与导出，再考虑迁移现有资料。

## 如何开始
先读 Deployment，选择 Cloudflare 或 Docker。Cloudflare 需要自己的云资源和管理员 Secret；Docker 需要确认数据卷、附件存储、管理员密码与默认自动更新安排。开发预览按 README 使用 `bun install`、`bun run dev`，本地自动登录行为不能照搬到公开部署。

公开演示会定时重置，不适合存私人资料。接入 MCP 时在账号的 API／MCP 页面创建令牌，先明确允许代理访问的数据与读写范围。

## 注意事项与相关项目
上游“永久免费”“即时同步”和性能表述不代表本站验证或云平台承诺。README 具体说明网页等客户端在停止输入后延迟上传、可见时定期拉取，失去网络或客户端差异也应实际验证。云配额、附件费用、备份恢复与插件权限需要分别核查。

EverOS 面向 Agent 记忆运行时，XERJ 面向内容索引与检索；它们与 EdgeEver 的笔记应用、账号和同步职责不同。AGPL-3.0 及商标要求也应在再分发或提供服务前阅读。
