## 它是什么
Oil Motion 是一套从动作设计、关键画面、视频生成到网页运行时的 Agent Skill。它先确定开始、中间和结束状态，生成连续动作，再检查和压缩画面，最后把用户输入映射到动画进度或播放行为。

浏览器交互时使用的是准备好的图集或视频，不是每滚动一次就重新调用视频模型。生成模型负责结构和姿态变化，前端代码负责位移、速度、阻尼等可精确控制的参数。

## 适合什么场景
- 产品介绍页中随滚动逐步展开或拆解的动画。
- 角色随指针改变朝向、拖动进度可前后查看的展示。
- 需要同时考虑画面连续性、加载体积与手机表现的交互素材。

## 如何开始
README 提供 `npx skills add oil-oil/oil-motion`，安装后由宿主重新加载。准备主体参考图、动作目标、交互方式以及桌面和手机的展示尺寸。

素材处理需要 Python、FFmpeg；生成环节还依赖所选服务与额度。凭据复用现有环境或由用户通过本机配置页保存。先完成一小段动画并挂到真实页面检查，再继续完整制作。上游流程会按背景、时间轴和设备预算选择全关键帧视频或 Alpha WebP 图集等资源形式。

## 注意事项与相关项目
代码能修正轻微漂移或编码问题，无法可靠修复生成视频中的错误肢体和产品结构。生成素材会发送到所选服务；费用、支持尺寸和产物质量依服务而定。README 描述的批准文件与哈希检查属于上游流程，本站未运行其生成或浏览器验收链路。
