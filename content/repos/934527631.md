## 它是什么
AI Novel Production Engine 面向长篇小说，使用自动导演把一句灵感拆成方向、世界、角色、卷规划和章节任务，再把生成、审核、修复与新状态写回组成可恢复的生产链。

Creative Hub 汇集对话和任务状态；世界手册、角色资源账本、知识库和写法资产成为后续章节的上下文。系统解决的是长链任务组织与连续性管理，不能保证生成作品自动达到出版水平。

## 适合什么场景
希望从灵感推进到完整长篇；需要跨章节维护人物和伏笔；研究创作类 Agent Workflow、LangGraph 与检查点恢复。仅需改写一小段文字时，这套结构可能较重。

## 如何开始
Windows 使用者可从 Releases 选择 Setup 或 portable。源码运行需符合 README 的 Node 版本范围、pnpm 10.6 以上及可用模型；知识库完整体验另需 Qdrant。安装后先在模型配置中测试连接，再创建小说，检查项目设定、故事宏观规划和角色准备，最后推进章节。

## 一个使用示例
官方路径改写，未执行：输入“海岛上的邮差发现一封寄往未来的信”，先选择整本方向，明确读者感受与前段故事承诺，再拆成卷和章节。生成第一章后审查人物状态与时间线，修复后才继续下一章。预期沉淀的是相互连接的小说资产与正文。

## 注意事项与相关项目
服务端环境变量从 `server/.env` 读取，不能把根目录示例当成唯一配置入口。长任务会消耗模型配额，自动恢复不等于无限重试。若偏好直接在 Codex 本地文件中创作，README 另指向互补的 Ani Book Skill。
