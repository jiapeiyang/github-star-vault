## 它是什么
NocoBase 是 AI + 无代码业务系统平台，先提供数据库模型、页面、权限、审计和工作流基础，再让用户用配置界面或代理完成应用。数据与界面分离，业务资料保留在关系型结构中。

插件架构允许增加功能；AI 员工在系统内部参与问答、表单或任务流程。它不是仅凭一句话生成一次性网页，而是可持续维护的应用底座。

## 适合什么场景
搭建内部业务管理和审批系统；开发者与业务人员共同调整页面；已有数据需要表单、列表和权限控制。复杂业务规则仍需要明确建模。

## 如何开始
先用 README 的在线 Demo 验证配置方式。自建时按文档安装 CLI，通过 `nb init --ui` 创建应用；明确数据表、关联和角色后，再配置页面和工作流。AI 集成是可选协作入口，手动配置也能使用平台。

## 一个使用示例
说明性示例，未执行：建立设备借用系统，先定义设备、借用单和使用者关系，再给员工创建申请表、给管理员配置审批视图。预期页面和操作围绕同一数据模型，随后用不同角色检查读取和修改权限。

## 注意事项与相关项目
README 的平台能力不代表所有插件在每个版本都默认包含，部署与授权范围需看具体发行和插件文档。代理操作也必须遵守业务权限，不能凭生成页面成功判定数据安全。定制程度较高时要评估插件开发成本。
