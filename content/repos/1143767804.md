## 它是什么
Frontend Slides 是给编码助手使用的演示文稿技能，输出带内联 CSS 和 JavaScript 的 HTML。核心流程先收集内容，再生成三个视觉预览，让用户选择方向后展开完整幻灯片；它还包含 PowerPoint 文字、图片和备注的提取脚本。运行最终 HTML 通常不需要 npm 构建或前端框架。

## 适合什么场景
适合做浏览器演示、产品介绍、内部汇报，以及把已有 PPT 内容重新排成网页。它主要解决演示内容组织和视觉呈现，固定 16:9 画布适合投屏；如果交付必须继续在 PowerPoint 中编辑，应先确认 HTML 是否满足要求。

## 如何开始
Claude Code 可先单独运行 `/plugin marketplace add https://github.com/zarazhangrui/frontend-slides`，完成后再运行 `/plugin install frontend-slides@frontend-slides`，通过 `/frontend-slides:frontend-slides` 调用。其他代理可从 SKILL.md 读取核心规则，并按引用加载所需文件。开始时提供页数、受众、每页重点及图片；转换 PPT 时先核对提取内容，再选视觉方向。

## 一个使用示例
官方流程改写，未执行：提供一份 6 页产品发布提纲，让技能先生成三个标题页预览；选择其中一个方向，再扩展到其余页面。打开输出 HTML 后，逐页检查文字能否完整显示、图片是否清晰、键盘翻页是否正常。预期交付是可由浏览器打开的演示文件；不是仅有几张预览图。

## 注意事项与相关项目
仓库自带常规预设和按需加载的 bold-template-pack，选定后才读取完整设计文件，避免把所有模板都塞进上下文。PPT 转换目标是保留内容和素材，不应未经对照就声称复刻了原版动画与排版。需要 PDF 导出或部署时，再检查 scripts 中对应流程的依赖和授权。
