## 它是什么
木易杨的博客按“前端进阶系列”整理 JavaScript 主题，正文多以 GitHub Issues 承载。README 的八期目录依次覆盖调用堆栈、作用域闭包、this、深浅拷贝、原型、高阶函数、防抖节流和面试，还列有 Vue 响应式与插件等单篇。它适合沿一个语言问题阅读连续解释。

## 适合什么场景
适合查找某个基础机制的图解、比较几个看似相近的概念，或理解 lodash 等工具函数背后的实现。它不提供一个可安装的工具库，文章里的模拟实现也不自动等同于标准实现。

## 如何开始
从 README 的主题期次进入，先读同组的概念文章，再看模拟实现和源码对照。例如深浅拷贝一组先讲赋值区别，再讲 Object.assign，随后讨论深拷贝和 Lodash。进入 Issue 后查看上下文和讨论修正，运行代码前确认环境。
