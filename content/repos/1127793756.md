## 它是什么
CCG 根据任务类型与复杂度选择开发策略，用 Go 的 codeagent-wrapper 连接外部模型 CLI，配合 hooks 注入任务状态、计划和上下文。简单修复可以直接进行，较复杂任务进入分析、方案、实施与交叉审查。

完整安装和原生插件不同：插件路径仅装技能，包含桥接二进制和多模型命令的完整编排需要安装器。README 另提供 Codex-led 和 DeepSeek Harness 路径。

## 适合什么场景
希望多个模型独立分析同一问题；已有 Claude Code 工作流需要可回看的任务文件；跨模块改动要安排实现与审查分工。

## 如何开始
完整方案要求 Node.js 20 以上和 Claude Code CLI，其他 CLI 按所选模型启用。运行 `npx ccg-workflow` 的向导后，用 doctor 与 status 核对安装和可用提供商，再从小任务试验。先确认模型账号可用，不能把安装命令成功视为跨模型调用成功。
