## 它是什么
Maple Mono 是开源编程字体，包含可变字重、斜体字形、代码连字，以及带 Nerd Font 图标的版本。CN 版加入简繁中文与日文字形，强调中英文 2:1 对齐，便于混合文本和 Markdown 表格。字体更换只影响显示，并不改写源代码中的字符。

## 适合什么场景
适合为编辑器和终端统一等宽字体、显示 shell 提示符图标、改善中文注释与英文代码的排列。需要保持运算符逐字符显示时，可选无连字版本；需要终端图标时确认选择 NF，而不只是基础拉丁字体。

## 如何开始
本次读取的分支已冻结为 V7 快照，README 指向 v7.9 下载；V8 的最新功能与修复位于 variable 分支。先在 Releases 或官网选择所需版本与字体格式，安装到系统，再在编辑器或终端字体设置中选择对应字体名称。macOS 的官方包管理示例包括 `brew install --cask font-maple-mono-nf-cn`，其实际安装版本以包管理器为准。

## 一个使用示例
说明性示例，未执行：在终端和编辑器打开包含 `=>`、`!=`、中文注释以及文件夹图标的文本，选择 NF CN 版本后比较运算符、图标和两列文字的对齐。如果连字影响辨认，在编辑器关闭连字或选用 No-Ligature 包。预期变化是字体显示与排版，而不是文件内容差异。

## 注意事项与相关项目
V7 README 明确说明 CN 版本不支持 variable 格式，中文字符间距也可能比其他中文字体大。不要将这一限制自动套到尚未核对的 V8。大量发行包分别控制格式、连字、图标及中文覆盖，应按需求选择，避免同时安装名称相近的版本后难以确认实际生效字体。
