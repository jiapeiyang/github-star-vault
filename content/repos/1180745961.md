## 它是什么
AI Website Cloner Template 为代理提供网站复刻工作流和现成 Next.js 工程。用户给 URL，代理浏览参考、重建界面，再在独立项目中继续定制。它更偏快速形成新的前端实现，不应默认等同完整源代码恢复。

## 适合什么场景
为获授权的页面做可修改原型；从明确参考建立新项目；希望模板中已经有代理入口和工程命令。依赖复杂后端的行为不能只靠页面外观还原。

## 如何开始
README 要求先用 GitHub 的 Use this template 创建自己的仓库，再打开自己的副本并 `npm install`。启动具有浏览器能力的代理，在支持的客户端调用 `/clone-website` 并提供 URL；自然语言触发的客户端可明确要求使用该工作流。
