## 它是什么
fe-hunter 把前端技术问题放在 Issues 中，社区通过回答和讨论补充解法，README 另提供已关闭问题与合订本入口。它的主要内容是问答记录，仓库首页不是完整题库，也没有需要启动的应用。

## 适合什么场景
适合围绕一个具体知识点查看他人的解释，或回忆以前遇到的前端面试问题。题目讨论通常能展现不同理解，但关闭状态和点赞数都不能替代对答案的技术核查。

## 如何开始
从 README 的“所有有最佳答案的问题”链接进入闭合 issue 列表，按关键词找目标题；也可打开合订本浏览。先读题干和限定环境，再读回答与后续修订。想提出新问题时应看 Wiki 的 How-to-ask，准备最小代码和观察结果。

## 一个使用示例
真实入口导航示例，未执行代码：打开 issue #68“为什么 Mocha 等测试库的 describe 和 it 函数没有导入却可以使用？”，把问题拆成测试运行器如何提供全局函数、编辑器类型声明如何识别它们两层，再查对应工具文档。该 issue 当前正文仍写“悬赏中”，因此不能把它因关闭就称为已含最佳答案。

## 注意事项与相关项目
README 中赏金与交流方式是项目当时的组织机制，当前是否仍活动应单独核实。本次核查了问题入口，没有把评论当成官方结论，也没有发言、报名或参与付费活动。big-react 与 just-react 是作者另外的 React 实现及源码资料。
