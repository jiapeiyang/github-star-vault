## 它是什么
bb 是围绕智能体任务组织的开发环境，提供桌面、Web、CLI 和 HTTP API 等入口。任务以 thread 形式运行，用户可以观察进度、追加要求或交接给其他智能体。它使用已经认证的模型提供方 CLI，而不是单独附带一个模型。

README 把它描述为能够控制和定制自身的 agentic IDE；这说明其目标是把工作界面与自动化入口连起来，并不表示所有开发操作都无需审阅。所查版本仍处于活跃开发中，工作流与不同平台的界面会继续变化。

## 适合什么场景
同时处理多个编码任务、希望在可见界面里跟踪和引导智能体时，可以考察 bb。需要程序化驱动开发任务时，CLI 与 HTTP API 也是项目的组成部分。若只想运行一个终端客户端，额外启动整套 IDE 可能没有必要。

## 如何开始
1. 阅读 README 的平台要求。桌面推荐入口支持 Apple Silicon Mac，Linux AppImage 被标为 alpha；Windows 指向 WSL2，原生 PowerShell/CMD 不在所述支持范围内。
2. 按需要下载桌面应用，或准备 Node/npm 环境使用 npx。
3. 确认所选提供方 CLI 已正常认证，再运行服务。
4. 打开上游给出的本地地址，创建一个范围明确的任务并观察输出。

```shell
npx bb-app@latest
```

README 对应的网页入口为 `http://localhost:38886`；npm 12 及以后版本的依赖脚本策略需按其安装说明处理。

## 一个使用示例
在本地项目中创建一个调查任务，要求解释路由入口、页面组件和数据读取位置，并给出具体文件。随后在同一 thread 中补充一个问题，观察上下文是否连续以及引用是否能在项目中核对。

预期得到可继续沟通的任务记录。此例依据 README 的 thread 操作方式设计；本站未运行应用、连接提供方或验证自动化 API。

## 注意事项与相关项目
README 明确说明生产运行带有可退出的匿名使用遥测，可通过 `BB_TELEMETRY=false` 关闭；具体事件字段以上游说明为准。远程开发模式会开放具有文件和命令能力的接口，不应直接将其暴露到不可信网络。firstmate 使用终端后端和目录约定组织团队，bb 则提供自己的应用界面和服务入口。
