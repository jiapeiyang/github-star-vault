## 它是什么

iPhone Use 是第三方本地插件，包含 MCP 服务、安装与操作技能以及屏幕预览。手机端 WebDriverAgent 执行动作，本机通过 USB 连接；代理根据控件树或实际截图选择点击、输入和滚动位置。

## 适合什么场景

- 在自己的 iPhone 上完成 App 导航、读取列表和草稿输入等手机自动化任务。
- 希望在聊天旁查看真实设备屏幕，并核对动作结果。
- 可以完成 Xcode 签名、设备信任和开发者模式等真机准备。

## 如何开始

1. 按 README 核对 macOS、完整 Xcode、Apple 开发团队、USB 真机、Python 与 Node.js 要求；仅安装 Command Line Tools 不够。
2. 按项目安装说明注册插件，并由自己的 Apple 账号签名、安装及启动 WDA Runner。安装手机 App 和让 WDA 服务运行是两个环节。
3. 使用项目的 setup/doctor 检查；只有 `pua_ready` 返回 `ready=true` 后才开始设备任务。

## 一个使用示例

官方示例改写，未执行：让代理打开自己的备忘录，新建一条“周末采购清单”草稿，输入两项测试内容，读取页面并核对，保留草稿。预期是文字与屏幕一致；此例不发送消息、支付或操作他人账户。

## 注意事项与相关项目

项目默认发送匿名使用统计，README 给出 `IPHONE_USE_ANALYTICS=0` 或 `DO_NOT_TRACK=1` 的关闭方式，需重启 MCP 生效。密码、验证码和系统认证应由用户完成。这里核对的是项目文档，未连接真机、完成签名或验证任何 App 兼容性。
