## 它是什么
nodejs-learning-guide 是以 Node 内置模块和进阶应用为骨架的中文资料库。README 将 fs、http、net、crypto、Buffer、Stream 等 API 与示例分组，同时收录字符编码、上传、会话认证、日志和调试等实践主题。它面向“怎样用某个模块完成任务”，与深入 C++ 运行时源码的书稿侧重点不同。

## 适合什么场景
适合查找某个核心模块的用法、理解请求与响应对象差异，或找到 Express 中间件相关说明。读者应有 JavaScript 基础；涉及服务器和身份认证的例子还需要理解网络请求与环境配置。

## 如何开始
先在“内置模块”确定模块，HTTP 被拆成请求、响应、客户端和服务端等章节，可按职责跳转。应用问题则到“进阶使用”找专题。进入正文后先核对示例依赖和 Node 版本，再单独运行需要的 demo；目录中的 ok 是作者标记，并非本站实测结果。

## 注意事项与相关项目
目录保留部分没有链接的待补主题，不能把所有列项当作完整教程。旧 Express、调试方式和 crypto 示例需按当前版本复核，MD5 介绍也不意味着可用于密码存储。README 的招聘内容属于历史公告，不是当前岗位信息。
