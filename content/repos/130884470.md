## 它是什么
Solid 使用声明式组件与 JSX 描述界面，编译阶段生成真实 DOM 操作，运行时通过响应式原语跟踪依赖。一个状态变化只触发依赖它的计算或 DOM 更新；组件函数主要用于初始化，而不是按 React 的方式反复执行组件体。

## 适合什么场景
适合想用 JavaScript/TypeScript 与 JSX 构建交互页面，同时研究细粒度状态更新的项目。已有 React 基础有助于读 JSX，但状态读取、解构和组件执行的心智模型需要重新确认，不能照搬 Hooks 经验。

## 如何开始
可直接打开 README 的 Playground 试例子。要建本地项目，官方示例用 solidjs/templates 的 js 或 ts 模板，安装依赖后 npm run dev；在已有构建中接入时需 solid-js 与对应 JSX 编译配置。先用一个独立组件确认 signal 的读取与更新。

## 一个使用示例
官方示例缩写，未执行：`const [count, setCount] = createSignal(0)` 创建状态，`const doubleCount = () => count() * 2` 声明派生计算；按钮点击执行 `setCount(c => c + 1)`，显示 `doubleCount()`。预期文本按 0、2、4 更新，组件体中的初始化日志不会因每次点击重复执行。

## 注意事项与相关项目
响应式依赖来自实际读取，过早读取为普通值可能失去所需更新关系。模板编译、DOM 更新与服务端渲染有不同前提，先从当前官方文档选对应路径。Svelte 也是编译式 UI 路线，但语言语法与响应式机制不同。
