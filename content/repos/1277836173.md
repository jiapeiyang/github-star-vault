## 它是什么
Casting-Workflow 把小说语料、提示模板、生成上下文和文本检查放在同一目录。脚本从某类语料中抽取人物、情节、句式等特征，形成给 LLM 的上下文，再由模型创作和后处理工具衔接后续步骤。

仓库包含九类题材目录和构思、人设、大纲、开篇、润色等模板。脚本负责资料准备与检查，不意味着只运行 Python 就会完成所有模型写作。

## 适合什么场景
整理自己有权使用的同类文本；比较题材惯例与叙事结构；研究文件式创作管道。若只改一段文案，不必准备完整语料库。

## 如何开始
阅读根 `SKILL.md` 和文件映射，安装 `requirements.txt` 中的 jieba。将合法文本放入对应 corpus 类别，再按 README 的阶段顺序生成上下文。管道会筛掉中文不足 500 字的文件，默认从健康文本中选取样本；输出保存在 `output/`。

## 注意事项与相关项目
仓库关于检测器和“爆款”的说法不是质量或原创性的保证，不能用检测分数证明版权清白。素材许可、事实与作品质量仍需独立判断。MuMuAINovel 提供图形管理界面，本项目主要基于本地文件与脚本。
