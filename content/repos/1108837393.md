## 它是什么
oh-my-openagent 将专家代理、生命周期 hooks、MCP 和团队模式组合成编码工作流。当前 README 区分 OpenCode Ultimate、Codex CLI Light，以及独立 Senpi beta，正在推进多宿主重构。

不同版本共享产品方向但能力并不完全相同：OpenCode 版包含完整编排工具，Codex Light 复用宿主的代理协作机制，不能把某版截图中的所有功能套到另一版。

## 适合什么场景
需要较完整的模型角色分工与工具组合；已有 OpenCode 使用习惯，希望增加长任务编排；研究相同工作流如何适配不同 harness。

## 如何开始
先按 Installation 的版本表选择自己的宿主，再阅读安装器会改哪些配置。OpenCode 入口是 `bunx oh-my-openagent install`，Codex Light 使用 `npx lazycodex-ai install`。核对提供商登录和权限选择，再用小范围任务检查实际工具，不必同时安装所有版本。
