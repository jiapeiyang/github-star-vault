## 它是什么
Dashi PPT Skill 把每页演示文稿组织成版式与文案字段，配套浏览器控制台调整模块、图表、配色和重点。输出本身可以编辑，再导出 HTML 离线包、PDF 或可编辑 PPTX。

README 提供多套主题与页面角色，适合复用结构完成汇报；它不是逐像素定制任意幻灯片的通用还原器。

## 适合什么场景
把报告和项目资料做成结构完整的演示；需要自己在浏览器改字换图；最终仍要交付可继续编辑的 PowerPoint 文件。

## 如何开始
准备 Node.js 20 以上与 npm，按 `npx dashi-ppt-skill@latest` 安装。PPTX/PDF 导出另需 Chrome、Chromium 或 Edge。提供主题、受众、页数和核心结论，选择预览风格后生成，再逐页通过控制台编辑，最后导出目标格式。

## 注意事项与相关项目
HTML 动画和浏览器效果不一定完全等价于 PPTX 表现，交付前需在目标格式检查。模板数量和可调控件是作者库存描述，不保证每种内容都适合。PPT Master 等项目也可按更偏 SVG 或生成流程的需求比较。
