## 它是什么
这个仓库以日期整理作者在 2018 至 2019 年间关注的前端资料与小示例，包含 Git、BrowserSync、json-server、rem、Vue、HTTP、算法和工程化等链接。README 混合外部阅读入口、短命令和作者当时的经历，因此更适合作为一份历史开发资料目录来理解，而非完整、连贯的课程。

## 适合什么场景
适合回忆某个早期前端工具或找回一篇当时流传的文章，也可以观察 Vue 2、Element UI 等技术的使用背景。需要当前项目模板时，应先检查对应子目录及版本，不能把日期列表当作成熟产品功能清单。

## 如何开始
从 README 按日期或关键词定位。第三方文章直接进入原文，小示例则通过作者的 GitHub Pages 链接查看。若要运行代码，先在仓库内找到实际文件与依赖，确认它是静态 HTML 还是需要构建；README 没有统一启动流程。
