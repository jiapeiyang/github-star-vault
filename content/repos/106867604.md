## 它是什么
cloudflared 是 Cloudflare Tunnel 的连接程序。它在源站主动建立与 Cloudflare 的连接，Cloudflare 再把访问流量送回该连接，因此源站通常无需为此开放公网入站端口。仓库同时提供用于访问受保护 TCP 服务的 access 命令；私网访问也可配合 WARP 客户端。

## 适合什么场景
适合让外部用户访问受控的内部 Web 服务、为源站减少直接公网暴露，或配置 SSH、RDP 等私网访问路径。它负责连接与代理流量；服务是否需要身份验证、允许哪些人访问，要由相应的访问策略和应用共同决定。

## 如何开始
从 README 的 Downloads 链接选择系统二进制、系统包或 Docker 镜像。持久 Tunnel 按官方文档准备 Cloudflare 账号和路由配置；公开域名与私网路由是不同路径，不应只照抄同一份 DNS 设置。安装后可运行 `cloudflared tunnel help` 查看隧道命令，用 `cloudflared access help` 查看访问端功能，再按 Create a Tunnel 文档创建连接并配置源站。

## 一个使用示例
官方流程归纳，未执行：目标是让一个测试 Web 服务经指定域名访问。先在本机确认源站正常，再建立 Tunnel、配置该服务对应的公开主机名与 DNS 路由，最后从另一网络验证响应与访问限制。预期是请求经过 Cloudflare 到达源站；连接成功并不证明应用登录或路径权限正确。本次未创建 Tunnel、改 DNS 或连接真实源站。

## 注意事项与相关项目
README 另给出 TryCloudflare 试用入口，适合先验证隧道概念；它与持久生产配置应分别阅读。上游只支持距离最新发行版一年内的版本，旧客户端可能遇到兼容变化。cftunnel 是围绕该客户端的管理工具，能简化操作，但底层连接仍受 Cloudflare 服务和网络条件约束。
