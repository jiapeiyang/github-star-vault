## 它是什么
Antigravity Tools 提供桌面仪表盘、账号管理与本地代理，将配置的上游会话和请求适配成不同客户端接口。请求经过鉴权、模型 ID 映射、账号调度和响应转换，因此它既不是模型本身，也不是官方 API 服务的同义词。

README 展示剩余额度、账号异常和多模态入口；这些状态来自上游接口与适配逻辑，实际可用性可能随上游变化。

## 适合什么场景
管理自己有权使用的多个连接配置；为兼容客户端集中设置模型映射；调试不同请求协议之间的差异。

## 如何开始
从 Releases 选择平台安装包，先阅读快速接入与鉴权说明。添加自己的合法账号或连接配置，核对仪表盘状态，再按客户端选择协议和本地端点。Docker 部署另有 API 鉴权与后台密码设置，不能把桌面本地默认直接暴露到公网。
