## 它是什么
Pi 将终端编码入口、agent core 和模型 API 分成不同包，也提供 TUI 与扩展机制。编码 harness 默认给模型 read、write、edit 和 bash，其他工作流通过技能、TypeScript 扩展、提示模板与主题补充。

它提供交互、print/JSON、RPC 和嵌入 SDK 模式，既能直接在终端使用，也可作为其他应用的代理底层。

## 适合什么场景
想用精简终端代理并自行决定工作流；需要跨模型提供商；构建自己的宿主或工具扩展。开箱默认不包含所有复杂编排功能。

## 如何开始
阅读 `packages/coding-agent/README.md`。当前 npm 包名为 `@earendil-works/pi-coding-agent`，安装后运行 `pi`，通过 `/login` 或提供商 Key 认证，再用 `/model` 选择模型。先在测试目录给只读任务，随后按实际需要增加 Pi Packages。

## 注意事项与相关项目
README 明确 Pi 没有内置文件、进程、网络和凭证权限限制，默认继承启动者权限；需要更强隔离时使用其容器化方案。分享会话是可选外部发布，不能自动执行。Codewhale 提供不同的内置权限交互，可按需求比较。
