## 它是什么
Daily-Question（“日问”）把前端面试问题、答案、讨论、代码示例与视频入口组织起来。README 特别列出 CodeSandbox 示例，集中覆盖 React.memo、useMemo、useCallback、cleanup、key、事件和状态更新等容易误解的行为。这里收藏的是问题到可观察示例的索引，不需要把它变成每日任务。

## 适合什么场景
适合忘记某个 React 行为的解释时快速找回例子，或在面试讨论中用小场景验证概念。它也链接面经和招聘信息，这些内容与代码示例的事实范围不同。

## 如何开始
先从 q.shanyue.tech 找问题，或在 README 的示例集按概念定位。打开沙盒前确认 React 版本和运行模式，先看源码中触发操作，再观察输出。涉及页面状态时不要只看文章一句结论，应检查示例中是否有 memo、引用变化或特殊 key。
