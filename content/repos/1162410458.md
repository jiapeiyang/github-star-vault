## 它是什么
Horizon 是可配置的个人资讯雷达，接入 RSS、Hacker News、Reddit、GitHub 等来源，按兴趣筛选并生成简报。除本地 Markdown 结果，还提供可选静态站、邮件、Webhook、微信与 MCP 接口；各来源和投递方式有独立前提。

## 适合什么场景
有固定关注主题，希望从分散来源整理每日阅读入口，或研究资讯抓取、排序与摘要管线。模型摘要和评分属于处理结果，不是原始新闻事实本身。

## 如何开始
克隆后使用 `uv sync`，运行 `uv run horizon-wizard` 配置兴趣、来源与模型；也可从示例文件手动配置。先只输出本地结果，确认数据、费用和来源质量。可选来源如 OpenBB 需要相应 extra，不必一次安装全部集成。

## 一个使用示例
官方参数整理，未执行：在已配置环境运行 `uv run horizon --hours 24`，检查 `data/summaries/` 中的简报，逐条核对原文链接与时间。先评估是否漏掉重要信息，再决定是否启用发布或通知。

## 注意事项与相关项目
外部平台可能需要凭据、接口额度或可用网络；抓取成功不代表摘要准确。README 的每日 Actions 模板默认禁用，需要自行配置后启用，克隆不会自动建立调度。lexfridman-cn 面向单一播客，本项目面向多来源；两者都需回到原文核对。
