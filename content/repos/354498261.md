## 它是什么
preferential-courses 是极客时间课程的渠道推广目录，以课程图片、二维码和文章链接汇集购买入口。README 按技术与非技术分类，技术部分出现前端、Vue、浏览器、React、webpack 4、TypeScript、V8、网络协议等课程。仓库提供的是选课与促销信息，不包含这些课程的完整教材或授课系统。

## 适合什么场景
适合回忆曾经关注的课程名称、比较主题，或检查某个推广入口对应什么内容。是否购买应先看官方当前大纲、讲师、更新日期和价格，不需要为了浏览目录创建额外开发环境。

## 如何开始
从技术或非技术分类查课程名称，进入课程平台核对当前版本与权益；若想使用 README 的二维码或文章入口，应先确认目标确实是课程购买页。仓库说某入口优惠长期有效，但当前活动和结算价仍以平台实际展示为准。

## 注意事项与相关项目
README 明确说作者与平台有渠道合作，因此推荐含商业利益关系；“最优惠”“长期有效”不能作为本站核实结论。旧课程如 webpack 4 应按版本理解。此仓库与免费书籍目录的用途不同，不应把推广链接描述成免费学习资源或自动购买工具。
