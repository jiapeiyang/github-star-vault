## 它是什么
tmux 是终端复用器。一个会话里可以放多个窗口，每个窗口又能分成多个运行 shell 的面板；客户端只是观看和操作这些终端的入口，断开客户端后，服务端中的会话仍可继续运行。

这个结构特别适合 SSH：连接断开不必同时丢失远端终端的上下文。但后台进程仍依赖那台机器运行，机器关机和程序自身退出不是“重新连接”能恢复的状态。

## 适合什么场景
- 同时查看服务日志、运行开发服务器和执行 Git 命令。
- 在远端服务器进行长时间任务，网络断开后重新进入原会话。
- 偏好键盘和现有终端，不需要额外桌面 IDE 的工作流。

## 如何开始
1. 按官方 Installing 页面选择系统包管理器的二进制包。源码构建另需 C 编译器、libevent 2.x、ncurses、make 等。
2. 在终端运行 `tmux`，默认会创建新会话。
3. 先按 `Ctrl+b`，松开后再按 `%`，可左右分屏；同一前缀加双引号可上下分屏。
4. 用官方 `tmux.1` 手册查会话切换和窗口操作，再逐步维护自己的配置。仓库的 `example_tmux.conf` 可作为配置参考。

## 一个使用示例
说明性操作示例，依据官方默认快捷键，未执行：在项目目录运行 `tmux`，左侧启动项目已有的开发命令，再用 `Ctrl+b`、`%` 分出右侧查看日志。预期是两项任务各占一个终端，互不覆盖输出；这里不替项目猜测启动脚本。

## 注意事项与相关项目
快捷键可能被个人配置更改；终端对颜色、鼠标和剪贴板的支持也有差异。应区分退出当前 shell、关闭窗口和脱离会话，避免误终止任务。Herdr 在类似的终端组织基础上增加代理状态与协作入口；tmux 本身不负责判断代理任务是否完成。
