## 它是什么
《深入理解 Node.js：核心思想与源码分析》是一部源码阅读书稿，明确以 Node v6.0.0 为分析基准。它沿着 JavaScript 核心模块、C++ 绑定、libuv 与 V8 的关系，解释异步 I/O 和事件循环如何落到实现。内容不是一份现代 Node API 速查表，而是观察早期运行时设计的入口。

## 适合什么场景
适合追溯事件循环、模块加载、Buffer、Stream、HTTP、文件系统和进程机制；阅读底层部分需要一定 C/C++ 基础。维护旧 Node 程序时可帮助理解历史行为，新服务选型应另查当前版本文档。

## 如何开始
直接从 README 目录进入章节，无需编译整个 Node。先读“架构一览”和“为啥是 libuv”，再按具体问题跳到事件循环、Timer 或文件 I/O。读到源码符号时，在与书稿相同的 v6.0.0 源码中定位，最后再与正在使用的版本对照。
