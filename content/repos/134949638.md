## 它是什么
fq-book 是《这本书能让你连接互联网》的源文件与 Docsify 阅读站，讲解上网方式、典型软件配置和部分网络原理。README 给出导读、目录、后记与本地阅读入口。
教程与客户端是不同资源；书中的历史截图和命令不等于当前软件仍采用相同流程。

## 适合什么场景
先理解代理、隧道与连接概念；沿目录寻找某种连接方式；将文档放到本地阅读环境。

## 如何开始
优先从在线阅读站和仓库的 docs 导读、目录进入，按概念而不是广告链接选择章节。需要本地运行时再核对 Git、Node.js 与 Docsify 的当前说明，保留已有文件。

资料导航示例，未执行：先读导读，定位代理与连接相关章节，整理客户端、配置和服务分别承担什么，再对照当前软件官方文档。预期得到概念和原始入口，不把旧配置照抄为当前方案。

## 注意事项与相关项目
README 含历史故障解释与部署命令，本站没有复验其正确性。不要直接采用强制覆盖 Git 历史的更新指令；文档阅读与修改仓库是不同操作。Mihomo 模板和 Clash Verge Rev 可作为具体配置与客户端的关联入口。
