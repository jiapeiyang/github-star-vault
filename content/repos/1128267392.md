## 它是什么
Huobao Drama 把文本改写、角色场景提取、分镜拆解、图片提示词和视频任务组织成短剧生产流程。当前 README 描述的是 TypeScript 全栈版本：前端 Nuxt/Vue，后端 Hono、Drizzle 与 Mastra，MySQL 保存结构化资料，生成文件保存到素材目录。

四类 Agent 各负责一个制作环节，因此可以回看角色与分镜再推进生成，而不是把全部任务混在一次聊天中。文本、图片和视频能力来自配置的模型服务。

## 适合什么场景
把已有小说片段改成短剧分镜；统一管理角色素材和批量视频任务；试验不同文本、生图与视频模型的组合。

## 如何开始
源码运行要求 Node.js 20 以上、npm 9 以上和 MySQL 8 以上；也可按官方 Docker Compose 方案启动。开发模式分别安装前后端依赖，运行各自的 `npm run dev`，前端默认在 3013，后端在 5679。打开设置页配置实际使用的模型与连通性，再建立剧集。当前版本通过 npm 包带入 FFmpeg 二进制。

## 一个使用示例
官方流程改写，未执行：输入一段两个人物对话，让系统改写剧本并提取角色、场景；先检查角色图，再生成分镜和单镜头视频，最后通过 FFmpeg 拼接整集。预期获得可追踪的素材与视频任务，角色一致性和剪辑质量仍需人工检查。

## 注意事项与相关项目
模型 Key 存在应用数据库，数据库和素材都需按部署方案维护。公网参考素材地址要能被上游模型读取；本地路径不是可直接传给云模型的 URL。当前 README 已发生技术栈迁移，旧 Go 版本教程不应直接套用。生成服务可能收费，广告套餐不是技术前提。
