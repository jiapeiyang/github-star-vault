## 它是什么
这是围绕开发者日常操作整理的 Mac 工具文章与资源目录。作者把工具按 Markdown 写作、桌面应用、终端、Chrome 扩展和 Alfred workflow 分组，并解释各项工具能减少什么操作。它的价值是把“想改善某项工作”映射到具体软件，而不是提供一个会自动装齐工具的套件。

## 适合什么场景
适合重新配置工作电脑、寻找录屏与截图工具、改善终端及键盘工作流。已有明确问题时按章节查找，比把目录中所有软件一次装上更有效；Windows 用户只能参考其中跨平台的部分。

## 如何开始
先打开 README 导读，选一个工作环节；例如录制演示可跳到“博主必备”，比较 ScreenFlow、Licecap、KeyCastr 的职责。随后通过软件官方站点核对当前系统支持与获取方式。Alfred 的 workflow 是另一类资源，需先确认已安装 Alfred，以及相应功能是否需要 Powerpack。

## 一个使用示例
说明性导航示例，未执行：目标是给同事展示一个快捷键操作过程。先在“博主必备”找到 KeyCastr，了解按键展示用途，再选择录屏或 GIF 工具。预期组合是视频里能看到操作画面和按键；两种工具各自承担一件事，仓库本身不会直接生成视频。

## 注意事项与相关项目
文章包含 Alfred 3 等历史版本，也出现软件“免费”等当时的判断，不能作为当前价格和兼容性的保证。部分下载链接来自第三方站点，应优先回到厂商入口。与 awesome-mac 相比，这份资料更偏作者使用场景和操作建议，覆盖面与更新方式不同。
