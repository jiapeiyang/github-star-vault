## 它是什么
cftunnel 是内网穿透管理层，负责下载引擎、生成配置和启动进程。Cloud 模式使用 cloudflared，面向 HTTP、HTTPS 与 WebSocket；Relay 模式使用 frpc/frps，经用户自己的公网服务器转发 TCP/UDP 等流量。两种模式有不同前提，不能因为同一条 quick 命令就把它们当成同一种连接。

## 适合什么场景
临时向他人展示本机 Web 页面时，可使用 Cloud 快速隧道；游戏服务、SSH 或其他非 HTTP 服务需要 Relay 等相应路径。自有域名场景还涉及 Cloudflare 账户、Token 和 DNS；临时 trycloudflare 地址不要求同样的准备。

## 如何开始
从 Releases 下载对应 macOS、Linux 或 Windows 二进制。确认本地服务先正常运行，再选择模式。临时 Web 入口是 `cftunnel quick 3000`；Relay 则先部署公网 frps，运行 relay init 配置服务器与 token，然后添加规则并 relay up。长期运行可按系统服务文档设置，先验证连通再启用自启动。

## 注意事项与相关项目
自有域名 add/remove 会创建或清理 DNS，destroy/reset 涉及更大范围删除；它们不是只读查看命令。Relay 需要自备服务器并配置鉴权及防火墙，服务器费用由实际供应商决定。cloudflared 是底层相关项目，cftunnel-app 则提供图形管理界面。
