## 它是什么
OpenChatCut 是独立开源视频编辑器，将代理指令落实到真实轨道、片段、字幕、转场和素材中。生成结果仍能手动编辑、撤销与保存版本，而不是只拿到一个无法再修改的成片。

内置代理与外部 MCP 代理共享编辑能力。时间线提供多轨音视频、特效和关键帧，转录驱动的编辑可把文字修改对应到视频片段。模型和素材生成服务按配置接入，本地编辑不要求每项外部服务都可用。

## 适合什么场景
需要让 AI 初剪访谈、调整字幕后继续手工精修；希望 Codex 或 Claude Code 操作已有视频工程；制作含配音、转场和多轨素材的短片。

## 如何开始
优先从 Releases 选择 macOS、Windows 或 Linux 安装包。源码方式要求 Node.js 24.x，复制 `.env.example` 为 `.env.local`，安装依赖后运行 `npm run dev`，默认访问 `http://localhost:5199`。在 Settings → Agent model 配置实际使用的模型，再导入素材建立项目。使用外部代理时按 README 的 MCP 连接章节配置访问。
