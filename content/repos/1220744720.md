## 它是什么
这个 awesome-gpt-image-2 更偏“案例拆解后复用”：除图片与提示词外，还提供按场景组织的模板、风格数据和 `gpt-image-2-style-library` 技能。网页与技能读取同一风格库，适合把视觉案例转成带业务变量的提示结构。

## 适合什么场景
找信息图、产品拆解图或插画的结构参考；把临时提示词整理为反复可用的模板；在代理中根据目标选择近似风格。资源库本身不是图像模型。

## 如何开始
从 README 的 Featured Cases 选择输出类型，进入图库看完整图和来源，再到模板页替换主体、文字、布局等变量。只浏览不需要安装；希望代理直接检索时再安装指定技能，注意 npm 的 `install all` 会写入多个客户端目录。

## 一个使用示例
官方使用路径改写，未执行：要做一张工具介绍信息图，先找 Infographic Visualization 案例，记录标题区、层级与标注关系，再将模板中的业务内容换成已核实的工具功能。预期得到可交给图像工具的完整提示词，而非简单追加“高级感”形容词。

## 注意事项与相关项目
站内直接生成涉及账号或所选服务的额度；浏览图库和付费生成是两件事。案例部分来自 YouMind 等社区来源，仍需回看原作者及素材许可。YouMind 同名仓库更突出社区原始提示词，本仓库增加了结构化模板与技能路径。

新增的 2.5 展示专题与原有图库、模板分别运行，README 明确这次更新未新增实时 2.5 生图。案例原始生成条件与精确工具模型标识仍有未核实部分，不能仅凭专题标题判断实测模型。
