## 它是什么
jstraining 是面向已有基础的 JavaScript 全栈培训材料，共四讲：前端历史与趋势、React、Node 应用开发及前端工程。它把浏览器端与服务端的基本工作连起来，并配有环境准备文档和 demos。README 定位为两天训练营的材料，这描述内容组织方式，不意味着两天即可掌握全部工程能力。

## 适合什么场景
适合回顾 JavaScript 全栈的基本组成，或查早期 React、Express 与工程化示例。前提是了解 HTML、CSS、JavaScript 和命令行基本语法，零基础读者应先补足这些输入。

## 如何开始
先读 docs/preparation.md 核对软件与版本，再按主题进入 docs/react.md、docs/node.md 或 docs/engineering.md；需要动手时选择 demos 中对应练习。每个例子的依赖与入口应单独查看，不把资料库当成一个统一业务应用。

## 注意事项与相关项目
材料保留 Travis CI 等历史工程工具，React 与 Node API 需要按示例版本复核。课程覆盖的是基本路径，不包含当前生产系统的全部身份验证、部署和运维要求。README 许可为 GPL v3，复用代码或改编材料前应阅读完整许可，单纯阅读无需额外环境。
