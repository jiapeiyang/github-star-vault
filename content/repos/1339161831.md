## 它是什么
Monocolor Editorial Print 是用于海报、杂志封面、人物图像和包装等场景的视觉 Skill。它以单色或受控双色印刷为中心，先确定内容、版式和色版职责，再组织纸面留白、网点、字阶与局部套印等元素。

所查 README 对应 v1.2.0，默认使用有明确主次的双色方案，用户明确要求单色时切换成一块色版。仓库同时包含设计系统数据、色卡、参考分析与验证脚本；宿主具备图像工具时可产出图片，否则返回生产提示词并说明限制。

## 适合什么场景
希望让一组海报、封面或邀请函保持有限色彩与编辑版式时，可以用它明确视觉规则。已有照片时，可以要求保留人物或物体的识别特征，再重新处理裁切、网点与排版。需要全彩图像或复杂 3D 场景时，不属于这套规则的主要方向。

## 如何开始
1. 打开 README 查看色卡、版式原则和 examples，确认这种印刷语言符合用途。
2. 按宿主方式安装；Claude Code 的示例是将仓库放入对应 skills 目录，其他环境读取 SKILL.md 入口。
3. 提供主题、必须准确出现的标题和事实信息；有参考照片时一并提供。
4. 指定单色或双色偏好后，检查生成图片、实际提示词和配方说明是否一致。

## 一个使用示例
README 中建筑展览海报的请求可整理为：

```text
用 Charcoal + Signal Red 为混凝土建筑展览制作竖版海报。
标题为“Concrete Forms”；红色只用于日期、地点和一处几何强调。
日期与地点留空，等我提供准确内容后再填写。
```

预期得到主色负责图像与主要信息、强调色具有明确用途的方案；不能自动编造活动详情。此例依据上游示例改写，本站未生图，也未验证实际印刷分色或文字渲染。

## 注意事项与相关项目
数字图片呈现的套印与纸张效果不等于已经具备专业印刷文件。参考图应提供视觉语法，而非照搬其独特构图。代码、指令和脚本的 MIT 许可与 examples 及第三方参考图片的许可范围不同，使用素材时需查看 ASSET-LICENSE.md。hand-drawn-styles 更像多画风配方菜单，本项目则围绕有限色版建立一套持续一致的视觉规则。
