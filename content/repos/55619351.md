## 它是什么
vue-sortable 是 SortableJS 的轻量 Vue 指令包装，使用 v-sortable 把拖拽能力加到现有容器。README 的设计目标是保持指令简单，不依赖 jQuery。与 Vue.Draggable 的组件和数组同步方式相比，这里的典型例子通过 onUpdate 回调手动改变源数组顺序。

## 适合什么场景
适合回顾 Vue 早期指令插件怎样封装原生拖拽，或维护已使用这套接口的旧项目。新项目应先核对 Vue 主版本与维护状态，不应因名称相近就把它与 vuedraggable 当成同一包。

## 如何开始
按 README 安装 npm install vue-sortable，导入 Vue 和插件后 Vue.use(Sortable)。无构建版本需先引入 Vue 与 SortableJS，再引入插件。给容器添加 v-sortable 配置，同时准备源数组和 onUpdate 方法，明确拖拽后的数据更新。

## 一个使用示例
官方逻辑节选，未执行：在 onUpdate(event) 中用 splice 把 event.oldIndex 的条目取出，再插入 event.newIndex。对于 Foo、Bar、Baz，将第一项拖到末尾，预期数组同步为 Bar、Baz、Foo；这是文档描述的操作目标，本站未启动示例或验证 DOM 与数组一致性。

## 注意事项与相关项目
README 的浏览器示例使用 el: 'body' 等旧 Vue 写法，不能当成现代 Vue 3 用法。数据同步由回调承担，列表有过滤、排序视图或非条目节点时，索引可能不能直接映射原数组。完整组件化需求可另看 Vue.Draggable，并按它支持的 Vue 版本选择。
