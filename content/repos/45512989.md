## 它是什么
掘金翻译计划是社区协作翻译互联网技术文章的项目，涵盖前端、后端、移动端、人工智能、设计、产品和算法，并整理若干大型文档与手册译本。README 将近期文章与分类总表连接起来，也提供选题、翻译、提交和校对的协作指南。它是内容翻译与发布流程，不是自动机器翻译软件。

## 适合什么场景
适合英文原文阅读有阻力时查中文译文，或者想在一个主题下浏览多篇国外技术讨论。也适合有意参与翻译的人了解协作规范，但普通读者无需注册社群或贡献内容。

## 如何开始
先按 README 的领域选择文章，较多内容可进入对应分类文件，如 AI.md、android.md 或 algorithm.md。阅读译文时保留原文链接、发表日期及译者信息；涉及安装或 API 时应进一步核对原项目当前文档。参与协作则从官方指南开始，不应重复翻译已认领内容。

## 注意事项与相关项目
“官方文档及手册”指原始资源的形态，不表示每个中文译本都是厂商官方维护。译文可能落后于原文更新，目录也有 2017/2018 年手册等固定历史版本。上游数量与贡献者统计不是本站实时计数，原文许可和译文归属需要分别遵守。
