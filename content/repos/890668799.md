## 它是什么
modelcontextprotocol/servers 当前收纳少量 MCP 参考实现，如 Everything、Fetch、Filesystem、Git、Memory 和 Time。它展示客户端如何通过统一协议调用工具、读取资源和使用提示，便于开发自己的服务。

README 明确这些是参考实现，并非开箱即用的生产系统。寻找完整社区服务器列表应到 MCP Registry，不能把旧合集印象当成当前仓库范围。

## 适合什么场景
理解 MCP 服务端结构；接入一个范围受限的文件或 Git 工具进行试验；对照官方 SDK 编写自己的服务。

## 如何开始
先选具体 `src/` 子目录并读其 README。TypeScript 服务常由 npx 启动，Python 服务可用 uvx；还必须在支持 MCP 的客户端中配置命令和参数。不要只在终端启动进程就期待聊天工具自动出现。

## 一个使用示例
官方配置改写，未执行：将 Filesystem 的启动参数限定为一个测试资料目录，客户端加载后先列出允许文件，再读取其中的示例文档。预期代理只在声明范围操作；目录路径应由用户明确选择，不能默认授权整个磁盘。

## 注意事项与相关项目
每个工具的权限、输入校验和副作用不同，参考实现需要按用途评估。README 中可能仍有历史示例，应以目标服务目录和发行信息为准。技能描述流程，MCP 服务器实际提供可调用能力，两者可以配合。
