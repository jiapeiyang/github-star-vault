## 它是什么
Archify 让代理先产出类型化 JSON IR，再由 Node.js 渲染与校验系统生成独立 HTML/SVG。支持架构、工作流、时序、数据流和生命周期图，以及搜索节点、跟踪关系、主题切换和导出。

它还可比较两份已验证快照，显示新增、删除、移动与改线等差异。布局和交互来自结构化数据，因此比单独画一张图片更便于继续修改和追问。

## 适合什么场景
讲解仓库主要调用链；审查架构调整前后变化；向团队分享离线可探索的系统图。没有代码库时也可从明确的系统描述开始。

## 如何开始
按 README 安装 archify 技能，或使用临时调用方式。给出范围、核心组件、主路径与外部依赖；分析仓库时要求来源依据。先核对节点和关系再调样式，后续可继续要求突出回滚路径或移动组件。
