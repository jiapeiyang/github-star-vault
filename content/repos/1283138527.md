## 它是什么
hand-drawn-styles 是一套工具无关的画风提示词配方。核心的 PROTOCOL.md 规定如何选择风格、处理比例和填入内容，STYLES.md 保存实际配方，适配文件则让不同智能体宿主读取这些材料。

它默认输出可交给图像模型的提示词，不直接生成图片。所查 README 列出 18 个整数编号风格及 3.1 变体，涵盖线条讲解、水墨、像素、纸雕、绘本等。部分需要参考锚点的风格还会输出带资源与步骤的 JSON 调用包。

## 适合什么场景
经常做说明插画、内容封面或系列图片，希望复用已经选定的描述而少做重复拼接时，可以使用它。也适合先看 examples 中的样图再选配方。它不负责文章撰写、账号发布或替你选择最终生图服务。

## 如何开始
1. 浏览 README 的画风表与 examples，选定编号、中文名或英文别名。
2. 按宿主说明接入完整仓库，保留协议、配方、渲染脚本和需要的参考资产。
3. 提供主体、动作、准确文字和可选比例；未指定风格时让宿主列出菜单。
4. 检查最终提示词是否保持原始内容，再交给自己使用的图像工具执行。

只复制 SKILL.md 而遗漏其引用的配方或资产，可能使实际流程不完整。

## 一个使用示例
给已接入配方库的宿主一个明确请求：

```text
用 8 号水墨写意画风，画雨后的竹林与一只停在石上的鸟。
横向 16:9，不加文字，只输出最终提示词。
```

预期使用水墨写意的对应配方，填入主体和比例，得到可复制文本。此例按 README 的编号与比例规则编写，未调用图像模型，不能保证某种模型会得到与上游样图相同的结果。

## 注意事项与相关项目
3.1 风格在 README 中有参考锚点和三阶段流程的特殊要求，不能以普通文本预览替代完整生产调用。其他风格也各有布局特点，不是任意互换的滤镜。mono-color-skill 聚焦有限油墨的编辑印刷视觉，本仓库则提供多种画风选择；两者的输入与交付规则应分别阅读。
