## 它是什么
vue-analysis 对应《Vue.js 技术揭秘》，把 Vue 2 的内部机制划为八章：准备工作、数据驱动、组件化、响应式、编译、扩展、Vue Router 与 Vuex。它从入口到 mount、render、update、patch 逐层展开，帮助把常见 API 与实际流程连接起来。

## 适合什么场景
适合维护 Vue 2 应用、想理解依赖收集和视图更新，或需要系统阅读源码路线的人。README 明确分析版本为 Vue 2.5.17-beta.0，这里的“最新版本”是写作时表述，不能套到当下 Vue 3。

## 如何开始
通过 README 的电子书链接直接阅读。先了解 Flow、目录与构建，再看数据驱动和响应式；若当前问题是模板如何成为 render 函数，可进入编译章。电子书可免费阅读，配套视频课程是独立付费产品。
