## 它是什么
dsh-purge 是面向 DeepSeek Harness 的本机插件，提供 Clean／Drill 面板、提示词编辑、规则集和宿主策略补丁。上游以受控本地实验和红队研究为定位，试图区分宿主限制与模型行为；这种定位不证明任何模型会按预期回应。

## 适合什么场景
在自己拥有或获授权的本地环境研究宿主行为，观察补丁、提示词和权限策略的作用。它不是通用模型服务，也不赋予对第三方系统开展测试的权限。

## 如何开始
先核对 Harness 版本以及实际使用的是 Web 还是 Desktop profile，阅读 Supported hosts、Install 和 Restore。两个 profile 独立安装和应用；添加插件不等于已经 Apply。运行前应理解会修改哪些本机文件、备份保存在哪里。

## 一个使用示例
状态检查流程整理，未执行：在已配置的本地实验环境查看 Clean 面板或 `/purge status`，确认实际 `DSH_HOME` 和补丁清单对应目标实例。仅记录状态，不把检查动作扩大为 Apply、重启或更改其他 profile。

## 注意事项与相关项目
恢复与卸载的清理范围不同，用户提示词文件的处理也不同，应按当前 README 核对。上游同时给出 Apache-2.0、署名和禁止原版转售等说明，分发前需检查具体条款。Purge Community 是另一仓库，其版本、包名和迁移规则不能混用。
