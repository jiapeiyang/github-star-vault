## 它是什么
Magpie 将本机多个编码代理的模型选择放进同一个界面，提供菜单栏、普通窗口、终端界面与 CLI。它还包含本地网关，在客户端与提供方之间转换不同 API 格式。
它管理配置和请求转发；模型能力、账号资格、费用与服务条款仍由上游决定。README 的跨代理订阅共享是项目功能描述，本次没有登录账号验证。

## 适合什么场景
同时使用多个编码代理，希望集中查看当前模型；接入自有 API 或本地模型服务；在几套配置之间切换。

## 如何开始
从上游 README 与 Releases 核对系统和安装入口。启动后先确认识别到了哪些代理，再添加一个有权使用的提供方，查看实际返回的模型列表。修改前检查被管理的配置文件并保留原配置。

## 一个使用示例
公开流程改写，未执行：已有一个本地模型服务和两个编码代理，在 Magpie 中添加该服务，分别选择模型，再检查配置和一次最小请求。预期是切换与转发可观察，不意味着模型效果或额度增加。

## 注意事项与相关项目
网关接触模型请求与凭据；分享给其他电脑时需核对监听范围和访问控制。模型列表不证明账号已获相应权益。本文未验证跨平台安装、协议转换完整性或订阅复用。
