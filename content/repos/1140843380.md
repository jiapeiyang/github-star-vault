## 它是什么
last30days-skill 让代理按主题检索 Reddit、X、YouTube、GitHub、HN 等不同来源，再根据时间和互动信息归纳讨论。平台适配脚本负责获取材料，代理负责筛选与解释，最后应保留原始链接。

当前 README 描述 v3 流程，并把 `skills/last30days/SKILL.md` 指为运行行为的准确信息入口。哪些来源可用取决于密钥、网络和浏览器会话，仓库列出的覆盖范围不等于每次都能完整读取。

## 适合什么场景
想知道一个工具最近被怎样评价；收集真实使用案例与问题；在采访、选型前快速补齐近一个月背景。历史原理或正式产品规格仍适合直接查官方文档。

## 如何开始
按宿主选择一种安装路径，例如通用 Skills CLI 的项目级安装；不要同时保留插件版和另一份技能导致重复入口。首次运行遵循设置向导，检查 doctor 结果和可用来源，再输入具体主题及时间范围。需要 X 等来源时仅配置相应访问方式。

来源缺失应在结果中说明，不能用旧内容冒充近 30 天。凭证应留在配置或安全存储中。订阅作者动态可考虑资讯雷达类项目；本仓库更适合按需围绕一个问题检索。
