## 它是什么
awesome-agent-skills 是一份偏向入门与精选的中文 Agent Skills 导航。README 先解释标准文件结构和按需加载方式，再介绍安装入口、教程与实践资源，帮助读者从“找到一个 Skill”走到“知道它放在哪里、会带来什么文件”。

其结构说明把 SKILL.md 作为必需入口，把 scripts、references、assets 作为按需附带的代码、资料和模板。这个仓库适合作为阅读地图；所链接的第三方能力和安装器仍由各自项目维护，不是一个统一运行的应用。

## 适合什么场景
已经听说 Skills、但不清楚目录和脚本如何配合时，可以先看标准结构。需要从一个重复任务寻找现成流程，或比较项目级和用户级安装方式时，可继续阅读安装部分。具体宿主的识别规则有差异，不应把通用目录示意理解为所有产品都完全相同。

## 如何开始
1. 打开 README 的快速入门与标准结构，确认需要的是可复用流程还是单纯 API 工具。
2. 根据任务选择教程、合集或具体 Skill，再查看目标仓库内容。
3. 如采用 README 介绍的 skills CLI，可先列出候选仓库中的技能。
4. 根据实际宿主选择安装范围，并在安装后检查新加入的文件。

```shell
npx skills add anthropics/skills --list
```

这条命令将 README 中的列举语法应用于其链接的官方示例仓库；运行 npx 本身需要可用的 Node.js 与网络环境。

## 一个使用示例
希望为重复生成文档建立流程时，先通过该导航找到文档处理 Skill，再检查 SKILL.md 是否说明输入文件、产出格式、所需脚本和验证方法。上面的 `--list` 可帮助先看候选名称，之后再按目标宿主的安装说明选择具体能力。

预期是明确哪些文件将参与任务，以及安装哪一项，而不是一条安装命令就证明文档产出可靠。本例是对 README 使用方式的说明性改写，本站未执行命令。

## 注意事项与相关项目
清单中的宿主支持数量和 CLI 命令可能更新，实际使用时应核对对应版本；实验字段也可能被部分宿主忽略。社区简介不能代替具体 Skill 的实现审查。yzfly/awesome-skills-zh 可用于交叉发现资源，vercel-labs/skills 则是 README 所述安装与管理命令的独立项目。
