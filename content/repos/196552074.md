## 它是什么
“大前端面试宝典—图解前端”按主题整理前端原理与面试讨论，强调用图解释抽象概念。README 提供在线阅读、每日一题归档，以及 docs/assets/drawio 中可编辑的图源。它是一套图文资料和讨论入口，不是自动面试、打分或模拟招聘系统。

## 适合什么场景
适合在技术概念较抽象时寻找图解，或想从原理与设计角度整理面试问题。作者明确认为面试判断有主观性，这份资料不能保证适用于所有团队，也不能代表通用录用标准。

## 如何开始
先进入在线阅读站按主题浏览；想找历史讨论可看 docs/daily。需要进一步理解图示时，同时阅读相关文字，分清节点代表数据、模块还是执行步骤。如果要修改原图，可使用 README 指出的 draw.io 源文件，但只读无需安装工具。

## 注意事项与相关项目
README 明确标注 WIP 且不定期更新，主题覆盖和图解深度不一致。图可以帮助理解，也可能隐藏异常路径和版本差异，实际技术决策仍需官方文档。其 leetcode 关联仓库侧重算法题解，当前仓库则围绕更广的前端问题。
