## 它是什么
Compound Engineering 是一组编码代理技能，核心过程把构思、计划、实现、评审与工程知识归纳连起来。后一次改动可以读取前一次形成的解决方案和约定，减少反复重建上下文。归纳材料应当可被后续任务直接找到，并明确来源与适用条件。

## 适合什么场景
适合持续维护的代码库、同类问题反复出现，或希望把审查结论沉淀为后续可读资料的团队。也可只调用 ce-plan 或 ce-code-review，不必为一个小修改运行所有流程。产物是否有效仍要看它是否准确对应当前代码。

## 如何开始
按 README 选择宿主安装路径。Claude Code 先添加 EveryInc/compound-engineering-plugin marketplace，再安装 compound-engineering。Codex App 的说明是添加自定义 marketplace 后安装并重启；Codex 使用 `$ce-plan` 等技能调用语法，与其他宿主的斜杠示例不同。先确认安装版本，再提供一个范围清楚的实际任务。

## 一个使用示例
官方工作流归纳，未执行：对某个搜索问题先用 ce-brainstorm 梳理触发条件，用 ce-plan 形成方案，实现后用 ce-code-review 核对，最后将可复用的原因和修复约束写到工程资料中。预期下次遇到同类问题能找到来源和结论，不能把文档数量当作代码质量证明。

## 注意事项与相关项目
README 提醒旧安装升级时要先刷新 marketplace，仅 plugin update 可能仍停留旧版本。各宿主插件包与调用语法不同，不能只复制一段命令到任何工具。知识归纳应保留证据、适用范围与过期条件，避免把一次偶然结果写成永久规则。
