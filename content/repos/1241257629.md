## 它是什么
Agent Learning Hub 是 Datawhale 社区维护的 AI Agent 资料路线图，核心内容集中在 README。它把官方博客、论文、开源实现和工程主题放在同一张阅读地图里，从基本循环、工具调用一路延伸到上下文管理、多智能体协作、Skills、浏览器操作和评估。

理解这个仓库时，可以把它看成“按能力与项目目标组织的索引”。它没有统一的运行程序，也不提供一套可直接安装的 Agent 框架；每个主题连接到独立的原始资料和实现，实际运行环境由目标项目决定。

## 适合什么场景
想确认某个 Agent 工程问题该看哪些资料，或在选框架之前比较工具协议、记忆、权限和评估等组成部分时，可以从这里定位入口。已经有具体需求时，无需按全文顺序阅读；README 的 Curated Resources 和 Project Ladder 为查资料与找示例提供了不同入口。

## 如何开始
1. 打开 README，先确定问题属于工具调用、检索、编排、能力包装还是评估。
2. 跳到相应主题，看该段列出的能力与原始资料。
3. 从官方文档理解契约，再选一个对应的开源项目检查实现。
4. 如果准备运行示例，进入该项目单独核对环境和账户要求；这里没有通用的 install/start 命令。

## 一个使用示例
如果问题是“智能体为什么不断重复调用同一个工具”，可以在基本循环部分关注终止条件、最大步数和错误处理，再到评估主题查阅 trace、工具调用次数与失败原因的观察方式。

预期得到两个明确的排查方向：循环如何决定继续，以及工具结果如何反馈给模型。这个例子是根据 README 主题整理的资料检索路径，未运行其中链接的框架。

## 注意事项与相关项目
README 的优先级和路线排序代表维护者的工程观点，选择仍取决于实际场景。外链项目会独立变化，旧文章中的 API 不宜直接当成当前接口。hello-agents 提供更连续的中文章节与配套案例，可在这里发现主题后转去深入阅读；本仓库更适合快速定位资料。
