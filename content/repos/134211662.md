## 它是什么
javascript-zh 是 Airbnb JavaScript 风格指南的中文整理，按引用、对象、数组、函数、模块、比较、命名与测试等主题列出建议。规则通常附带原因、好坏示例和 ESLint 规则链接，因此可用来理解团队规范为何这样写，而不只是照抄格式。

## 适合什么场景
适合查一个具体编码风格问题，或为团队讨论统一规则提供参照。它是工程约定，不是 JavaScript 语言规范；项目已有一致做法时应先评估迁移成本，不必因为上游推荐就批量重写全部代码。

## 如何开始
直接从目录跳到相关主题，无需运行仓库。先读规则原因和反例，再查看 ESLint 对应规则。需要自动化检查时，核对当前 eslint-config-airbnb 或 base 包与自己的 ESLint、模块系统是否兼容，不能沿用本翻译旧的 Babel 前提而忽略版本。

## 一个使用示例
官方示例归纳，未执行：比较原始值赋给另一个变量与数组引用共享的例子。`const foo = [1, 2]; const bar = foo; bar[0] = 9;` 会影响同一个数组。这说明 const 限制重新赋值，不会让对象内容不可变。预期理解规则边界，再决定是否需要复制数据。

## 注意事项与相关项目
文档保留 Babel preset、polyfill 与 ES5 兼容等历史背景，实际浏览器支持要按目标环境核查。部分译词可能不够精确，应结合英文原文理解；格式偏好也不应覆盖正确性、可读性与项目现有契约。
