## 它是什么
Claudian 是 Obsidian 插件，将笔记库作为代理工作目录，接入 Claude Code、Codex CLI、Grok Build、OpenCode 或 Pi。它提供对话、多会话、文件引用、技能和内联编辑差异预览。
插件界面与底层编码代理相互独立，安装插件不代替安装、认证和配置底层代理。

## 适合什么场景
在阅读笔记时让代理解释或整理内容；对选中文本先查看修改差异；把多步资料操作留在笔记库工作区。

## 如何开始
当前 README 要求桌面版 Obsidian 1.13.0 以上与至少一个兼容代理。从社区插件中搜索 Claudian，安装并启用，再确认代理 CLI 能被图形应用找到。先用无敏感信息的测试笔记库确认工作目录和权限。

## 注意事项与相关项目
提示、附件和工具结果可能发给所选模型服务；笔记库同时是文件操作范围。GUI 的 PATH 可能与终端不同。插件没有代替模型提供方资格与费用检查，协作功能也已独立为另一个插件。
