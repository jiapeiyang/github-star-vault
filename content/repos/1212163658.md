## 它是什么
仓颉 Skill 将书籍、视频字幕、播客转写等长内容中的方法论整理为智能体可调用的能力。所查 README 对应 v2.5.0，描述的流程先理解全文，再提取候选框架、原则、案例和术语，经过来源核对后生成 Capability Bundle，最后编译为单一入口或紧凑的技能包。

它的关键取舍是先保存能力卡与关系，再决定哪些能力需要独立入口。产物还包括供人阅读的摘要、术语和验证材料。这样的结构方便复用方法与判断条件，但抽取是否忠实、能力是否有用仍需要结合原文和实际任务检查。

## 适合什么场景
希望把一份自己有权使用的操作手册或方法论材料转成可重复调用的流程时，可以考虑该项目。视频和播客需要先准备字幕或转写文本，不能只给一个无法读取的链接就假定已理解全部内容。想保留整本文字的译文时，translate-book 更贴近目标。

## 如何开始
1. 查看 README 的宿主安装入口及当前版本说明，选择与实际环境对应的方式。
2. 准备可读取的源文本；视频可按上游建议先提取字幕或音频转写。
3. 指定源文件和希望解决的问题，让宿主评估材料是否包含可复用方法。
4. 检查输出中的来源依据、触发条件和边界，再决定交付单一 Skill 还是能力包。

上游网站可浏览已经生成的 Skill Pack，仓库则保存代码、方法与模板。

## 一个使用示例
向已装好该能力的宿主提供如下任务：

```text
使用 cangjie-skill，从 ./interview-guide.md 提炼可执行的方法。
保留每项方法的来源依据、适用条件和不适用情况。
```

预期先形成能力卡及关联，再生成可安装入口和 `DIGEST.md` 等阅读材料。输入文件和任务为依据 README 的说明性改写；本站未提取文档、编译 Skill 或执行效果评估。

## 注意事项与相关项目
README 展示的案例与压力测试描述属于上游提供的能力说明，不能据此认定生成内容没有误读。v2.5.0 的 Bundle 与编译方式也不应套用于旧版产物。book-to-skill 更强调章节资料和按需查询，本项目强调可执行的方法组合；两者都需要审阅生成内容和源资料许可。
