## 它是什么
这是山月围绕前端、后端与运维问题整理的技术博客仓库。README 提供前端工程化、Node、无服务器方案、个人服务器和 k8s 集群运维等专栏入口，同时列出开发者工具箱、npm 在线执行、周刊和面试项目。它连接具体问题的文章与作者的其他工具，不是一个要整体部署的后端系统。

## 适合什么场景
适合从前端页面问题继续查到打包、部署或服务器配置，或寻找“是否真的需要一台服务器”的方案讨论。跨领域阅读时要区分概念文章与可直接执行的运维操作。

## 如何开始
先按 README 专栏选范围，进入 shanyue.tech 对应栏目，再按文章主题定位。阅读命令前核对操作系统、软件版本和是否依赖真实服务器。只读文章不需要运行仓库中的脚本；首页链接到的其他项目也有各自独立使用条件。

## 一个使用示例
说明性导航示例，未执行：准备托管一个静态工具页，可先看“有可能你并不需要服务器”，再与“个人服务器运维”比较需要自己负责的工作范围。预期得到托管方向的阅读入口，而不是还没理解需求就去购买或配置服务器。

## 注意事项与相关项目
README 是专栏概览，没有逐项说明每篇文章的环境要求，不能据此补造启动命令。涉及服务器、k8s 或在线 npm 执行时，真实资源和代码执行边界需另行确认。与 Daily-Question 相比，这个仓库偏专题文章，后者按问题、答案和示例组织。
