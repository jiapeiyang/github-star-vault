## 它是什么
Superpowers 为编码代理提供完整开发流程：先明确目标与设计，再拆成可执行计划，进入实现、测试和审查。技能之间可以组合，强调 TDD、避免不必要功能，以及按计划检查子任务结果。

它是方法与宿主集成，不是新的编码模型。自动触发是否生效、子代理是否可用，都依赖实际宿主与安装方式。

## 适合什么场景
复杂需求经常跳过设计就写代码；希望每个实现任务有明确验收；需要系统化排障、独立审查和开发收尾。很小的改动应结合本地约定评估流程成本。

## 如何开始
按 README 选择实际宿主的插件入口，例如 Claude 官方 Marketplace 的 Superpowers 或 Codex 插件搜索。安装后先描述一个具体目标，核对生成的设计和计划，再在授权范围进入实施。更新需走同一安装渠道，避免多份技能互相覆盖。

## 一个使用示例
官方流程改写，未执行：为项目增加导出功能，先明确格式、错误场景和输入限制，形成小任务后实现一个完整路径，再测试真实输出、审查 diff。预期验收围绕功能与文件结果，不以“已经调用测试技能”作为通过证据。

## 注意事项与相关项目
测试和子代理增加的工作量应与风险匹配。技能不能替代用户授权或项目的发布边界。Ponytail 专注实现简化，Superpowers 更覆盖从设计到收尾的过程；同时使用时应统一规则。
