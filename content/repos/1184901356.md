## 它是什么
HumanLayer 的这个仓库收集面向 Claude Code 的 Skills，重点是改善代码仓库中的指令、类型和智能体工作流。它没有独立应用界面；具体能力由安装到宿主中的 Skill 提供，再由宿主读取当前项目并执行任务。

当前 README 列出 improve-claude-md、narrow-react-prop-types、build-iterated-agentic-loop、design-control-loop 和 show-me。它们分别涉及规则文件重写、React 属性类型收窄、迭代编码工作流、控制循环设计和图解说明。

## 适合什么场景
项目的 CLAUDE.md 越写越难遵循，或者组件类型为 Storybook 和测试状态保留了大量生产中不会出现的分支时，可以先阅读对应 Skill。需要把重复编码任务组织成仓库内流程时，则查看工作流相关能力。不同 Skill 修改的对象不同，不必一次安装全部。

## 如何开始
1. 在 README 的 Available Skills 中选择具体能力。
2. 查看该 Skill 的内容，确认它会读取和修改哪些项目文件。
3. 通过上游给出的 skills CLI 安装选中的条目。
4. 在目标项目中显式调用，之后审阅产物和差异。

```shell
npx skills add humanlayer/skills --skill improve-claude-md
```

## 一个使用示例
在已安装对应 Skill 的项目中，README 给出的调用为：

```text
/improve-claude-md
```

目标是重写当前项目的 CLAUDE.md，用条件块表达不同场景下的重要约定。检查结果时，可以对照改写前后是否保留了原来的项目约束，而不只看文件是否变短。安装与调用均来自上游 README，本站未执行，也未验证其一定能改善模型遵循率。

## 注意事项与相关项目
工作流类 Skill 可能创建 GitHub Actions、提示词或其他仓库文件，影响范围比单纯解释文本更大。安装前应阅读具体实现。此仓库是 HumanLayer 提供的第三方能力集合，不能与 Claude Code 内置功能混为一谈；其他宿主的适配情况应独立核对。
