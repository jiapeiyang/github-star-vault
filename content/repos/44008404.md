## 它是什么
i5ting/vsc 是中文 VS Code 使用资料，围绕编辑器界面、文件与搜索、Git、调试、任务和 Express 调试案例展开。README 保留 VS Code 早期版本、系统要求和操作截图，因此它是一份历史编辑器工作流教程，不是 VS Code 本体源码或当前配置模板。

## 适合什么场景
适合回顾如何把 Node 项目调试接入编辑器，或者找回终端打开项目、查看差异和设置断点的概念说明。熟悉当前编辑器的人可按主题跳读，无需复原整套旧工具环境。

## 如何开始
先从功能区说明理解文件、搜索、Git 和调试各自职责，再看 Node/Express 例子。当前编辑器安装应从 VS Code 官方入口获取；README 提到的 coden 与 vsc 是旧辅助方案，不是现在使用编辑器的必要前提。实际 launch 配置应按当前调试器生成。

## 一个使用示例
官方操作路径改写，未执行：打开已有 Express 项目，找到真正的服务启动入口，在运行与调试配置中指向它，设置一个请求处理断点，再访问该路由。预期在编辑器查看调用栈和变量；本文没有创建 Express 工程或验证断点命中。

## 注意事项与相关项目
文中 launch.json 采用早期 0.1.0 配置形态，name、program 等概念仍可理解，但不能整段复制到当前环境。系统支持如 Yosemite、Ubuntu 14.04 是历史描述，不是当前最低要求。快捷键也可能是作者自定义方案，应查看自己平台绑定；旧截图不表示当前 UI 必须相同。
