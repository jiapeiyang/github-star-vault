## 它是什么
huashu-design 是运行在编码代理中的设计技能，围绕 HTML 创建可点击原型、演示文稿、时间轴动画与信息图。它包含风格参考、脚本、素材和演示，先让用户看到多个方向，再推进内容、变体和细节，最后用浏览器检查。它不是 Figma 插件，也不是完整后端应用框架。

## 适合什么场景
适合把提纲变成演示、验证移动端操作流程、将逻辑解释为短动画，或对现有设计做分维度评审。需要可编辑 PPTX、视频或静态图时，可以选择对应导出路线；原型的交互效果与真实服务端功能应分开验收。

## 如何开始
README 安装入口为 `npx skills add alchaincyf/huashu-design`。安装后检查 references、assets、scripts、demos 是否完整，只有 SKILL.md 会遗漏运行资料。向宿主提供目标、素材与交付格式，先看三个真实视觉方向并选择，再让代理生成完整内容，最后核对浏览器和导出结果。

## 一个使用示例
官方任务改写，未执行：要求“做一个番茄钟 iOS 原型，四个核心屏幕能点击”。先比较风格方向，再确定开始、暂停、完成等状态，生成 HTML 后逐个点击验证跳转。预期是可以浏览和操作的原型文件；它不会自动变成已签名的 iOS 应用。需要视频时再按对应脚本导出并检查时长与声音。

## 注意事项与相关项目
仓库说明从 2026-05-14 起使用 MIT，旧的企业授权文案已废止，但第三方素材仍要逐项核对来源。脚本导出依赖与浏览器条件按所选任务准备，不能因为 HTML 可打开就声称 PPTX 可编辑或视频已导出。frontend-slides 是更聚焦网页演示的相关技能。
