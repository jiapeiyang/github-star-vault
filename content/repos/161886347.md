## 它是什么
system_architect 是系统架构设计师考试资料索引，维护更新记录、综合知识与案例分析真题、论文参考以及教材和刷题渠道。内容从 2018 年持续积累，适合按考试年份和科目查找历史资料。

README 说明部分后续资料自 2021 年起不再免费更新，公开仓库和外部完整资料不是相同范围。它属于资料汇总，不能当作官方考试公告或通过考试的保证。

## 适合什么场景
找某年综合知识题型；对照案例分析和论文的出题主题；回看教材版本变化。想报名时，应从仓库的官方入口继续核实当地通知。

## 如何开始
先看 UpdateLog 和 README 最近更新日期，再按“真题及解析”选择年份与科目。需要打印作答可找无解析版，核对答案则找对应解析版，避免两个年份混用。报名、查分和证书查询使用 README 列出的官方服务入口。

## 一个使用示例
资料导航示例，未执行下载：查找 2025 年 5 月的综合知识、案例分析和论文条目，分别记录题目版本及解析来源，再对照最新版教程定位不熟悉的术语。预期得到一个明确的资料查询路径，而不是要求安装项目或启动应用。

## 注意事项与相关项目
历史答案可能被后续更正，旧教材与现行考试要求也可能不同。部分网盘、课程与商业入口需额外访问条件，本次未逐个验证下载。第三方教材和试卷的公开链接不代表拥有任意再分发权。
