## 它是什么
Canvas UI 提供液体、玻璃、碎裂等视觉组件，效果层运行在实际 HTML 内容上。它通过兼容 shadcn 的 registry 将源码加入项目，支持多种框架，并提供 WebGL 与 WebGPU 两条渲染路径。
它不是把整张界面截图替换成画布；README 说明被包裹的内容仍是可交互子树。

## 适合什么场景
给已有页面添加局部创意视觉；希望直接修改组件源码；比较框架和 GPU 渲染路径的实现差异。

## 如何开始
先核对目标框架与 registry 安装说明。README 的 React 示例为 npx shadcn@latest add @canvas-ui/liquid-react；未初始化 shadcn 的工程须先初始化。源码进入 components/canvasui，再按文档引入 Liquid 包裹已有内容。
