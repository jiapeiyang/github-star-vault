## 它是什么
awesome-design-md 用 Markdown 描述真实网站的颜色、字体、排版、组件和视觉规则，按 AI 平台、开发工具等类别提供参考入口。目标是让代理读取一份设计说明后，持续生成风格一致的页面。

它把“工程怎样构建”和“界面怎样呈现”区分开来：DESIGN.md 关注后者，但只有宿主实际读取时才能影响输出，不是所有工具都自动识别的运行配置。

## 适合什么场景
做新页面前寻找视觉语言；把零散风格词变成可复用规范；比较开发者产品如何组织留白、字级和强调色。

## 如何开始
从 Collection 找相近产品，阅读对应 DESIGN.md，挑出适合自己内容的规则。放入项目时补充自身品牌与约束，并明确要求代理读取；已有 DESIGN.md 不应直接被参考文件覆盖。

## 一个使用示例
官方使用方法改写，未执行：选择 README 中偏编辑排版的 Claude 参考，提取暖色强调、文字层级和留白策略，再要求代理为自己的工具列表页应用这些原则。预期是新的内容结构与一致视觉，而非冒充原产品或照搬商标。

## 注意事项与相关项目
公开 CSS 的整理不意味着取得原站完整视觉身份的使用权；分析也可能遗漏动态状态。Dembrandt 从网页实测样式提取 token，本项目提供已经整理好的文档入口。
