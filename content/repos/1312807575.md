## 它是什么
ChatGPT Web for Codex 是一个第三方桥接项目，尝试把 ChatGPT 网页会话接入 Codex 的任务界面。README 描述的链路是本地 Responses/SSE 桥接层连接启动器内嵌浏览器，再把网页中的流式内容传回原任务；完整模式还通过 MCP 将工具能力连接到该任务。

它不是 OpenAI 官方 API 或官方集成。网页中的模型入口、账户能力和界面状态会影响桥接行为，因此仓库中的支持列表应理解为作者针对其版本的说明，不能直接当成 OpenAI 产品的通用能力承诺。

## 适合什么场景
希望研究现有任务界面如何与网页会话连接，或者评估这类第三方集成的运行与维护代价时，可以从架构图和模式表入手。只需要标准模型 API 的应用，则应先使用对应的正式接口；这条网页桥接链路引入了额外的页面依赖。

## 如何开始
1. 阅读 README 的 Modes、Limitations and security，以及故障排查文档，确认所需能力属于哪个模式。
2. 如决定试用，按对应操作系统选择 Releases 中的启动器，并先查看安装脚本内容。
3. 按上游流程在启动器内嵌浏览器登录，运行 browser smoke test，再安装模型入口并重启宿主。
4. 需要本地工具连接时，另行核对 MCP 设置和实际授权范围；浏览器模式与完整工具模式并不等价。

## 一个使用示例
以验证基本文本链路为目标：在配置完成后选择桥接入口，提交一个无本地文件和外部操作的简短解释任务，检查网页会话与原任务中的文字是否对应，以及中断后是否如实报错。

预期确认的是当前版本的消息往返，不据此推断文件、终端或其他工具已经可用。此例是根据 README 架构整理的说明性验证路径，本站没有安装启动器、登录账号或建立隧道。

## 注意事项与相关项目
上游将一种手动发送方式命名为“Zero Risk”，该名称不能理解为不存在账号、隐私或集成风险。Temporary Chat 也不意味着本地推理，提示仍由相应服务处理。网页结构变化可能使集成失效；模型可用性和服务规则需另行核对。HAPI 偏向远程查看已有编码会话，本项目则改变所选任务的模型传输路径。
