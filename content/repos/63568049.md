## 它是什么
DDFE-blog 是滴滴前端团队的文章索引，正文多放在 Issues。目录包括 Vue、cube-ui、移动端、Node Stream、自动化测试、webpack 和工程经验。它的特点是把具体源码机制与业务工程经验放在一起，例如 Vue 2 数据依赖、vue-router history、webpack loader 与 chunk 图生成。

## 适合什么场景
适合维护旧 Vue/webpack 工程时查找结构解释，或了解组件库和移动端应用当时怎样落地。它是技术文章集合，不是一个统一的组件包，也不是当前框架官方手册。

## 如何开始
从 README 选择系列；源码分析可先读总览，再跟随同系列序号，避免直接从中间的 loader 或文件生成章节开始。进入 Issue 后确认对应版本与作者提供的代码位置，再在自己项目的依赖中核对是否匹配。
