## 它是什么
book-to-skill 将书籍、技术文档或文档文件夹整理成智能体按需读取的 Skill。工作分为两部分：Python 提取器把文件转成文本与元数据，宿主智能体再按 SKILL.md 的要求整理概念、判断规则和章节资料。

产物包括总入口 SKILL.md、按章拆分的 chapters 文件、术语表、模式汇总和速查表。后续提问时，宿主先通过索引定位章节，再读取相关内容。它并不是给整本书自动建立一个独立在线搜索服务，转换和问答仍依赖所选宿主的模型能力。

## 适合什么场景
经常回查同一份技术手册、设计规范或内部运行手册时，可以考虑把结构化知识整理成可复用入口。它也接受多个文件，适合将一组彼此相关的文档合并整理。只需临时查一页内容时，直接阅读原文通常更省步骤。

## 如何开始
1. 准备自己有权处理的文档和支持 Skills 的宿主。
2. 按 README 安装能力，并确认 Python 3 及输入格式需要的提取工具。
3. 纯文本与 Markdown 不需要额外提取依赖；PDF 可按文档结构选择 pdftotext、pypdf 或 Docling 等。
4. 调用转换后，检查章节索引与原文是否对应，再用一个具体问题检验结果。

```shell
npx skills add virgiliojr94/book-to-skill
```

扫描版 PDF 需要先得到可识别文本；README 明确说明无文本层时应先做 OCR。

## 一个使用示例
在已安装 Skill 的宿主中，将自己编写的系统手册转换为可查询资料：

```text
/book-to-skill ./system-handbook.md
```

预期得到一个含入口、章节资料和术语的 Skill 目录。随后可以要求宿主根据相应章节说明某个部署决策的前提，并回查原手册是否支持这个回答。调用形式来自官方 README，输入文件名为说明性替换；本站未执行转换或验证问答效果。

## 注意事项与相关项目
README 的 token 节省比例来自上游特定测试，不能推广为所有文档的结果；“无幻觉”也不能作为本站保证。本地提取不等于文本始终留在本机：使用云端模型时，交给模型的内容仍遵循该服务的数据处理规则。工具许可证不自动授予所处理书籍的再分发权。cangjie-skill 更强调方法论能力卡与组合，translate-book 则以整本翻译为目标。
