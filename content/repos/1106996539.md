## 它是什么
UI UX Pro Max 提供设计资料检索与设计系统生成流程，先理解产品需求，再推荐模式、视觉风格、颜色和排版，最后结合指定框架实现。搜索脚本使用 Python 标准库，技能内容与宿主安装入口分开。

它覆盖多种 Web、移动与桌面技术栈；若没指定，README 默认方向是 HTML + Tailwind。设计建议是候选方案，仍需结合内容和品牌判断。

## 适合什么场景
为新页面建立一致视觉起点；不知道某类产品适合什么信息层级；按具体技术栈寻找可访问性和交互注意事项。

## 如何开始
当前 npm 包是 `ui-ux-pro-max-cli`，安装后命令仍叫 `uipro`。在项目目录按实际宿主执行 init，先用 dry-run 查看写入范围。准备 Python 3.x，给出产品类型、受众、关键页面和技术栈，让代理先给设计系统再实现。
