## 它是什么
Front-End-Develop-Guide 是前端资源导航，围绕 HTML、CSS、JavaScript 与 Web API，延伸到 Node、MongoDB、WebGL、浏览器扩展、桌面和移动应用。条目通常附一句用途说明，帮助知道某份文档能解决什么问题；它不是自带运行环境的课程项目。

## 适合什么场景
适合想找基础规范或某个衍生领域入口，或回顾 2015 年前后前端技术版图的人。资源覆盖广，可作为发现线索，但没有必要把所有方向都当作当前项目必备能力。

## 如何开始
直接从 README 目录选择主题。语法和 API 优先跟随 MDN、W3C 等文档入口，写作风格可看 Google/Airbnb 指南，图形需求再进入 WebGL。打开外链后核对当前页面与版本，旧链接失效时根据原作者和标题找正式迁移地址。

## 一个使用示例
导航示例，未执行：想在网页里展示交互三维图，先从衍生方向进入 WebGL 资源，再返回 JavaScript 与浏览器 API 基础确认画布、事件和动画前提。预期找到适合自己的起点，而不是把选择图形库等同于完成整个三维功能。

## 注意事项与相关项目
README 明确链接《致 Front-End Developers（2015）》，不少工具与站点具有历史背景。合集保留的图书下载、转载与外部素材有各自版权，仓库收录不自动代表可再发布。开发工具推荐也应结合维护状态与实际工程环境。
