## 它是什么
Rainman Translate Book 是将整本 PDF、DOCX 或 EPUB 翻译到目标语言的 Agent Skill。它先通过 Calibre 和 Pandoc 转换文本并分块，再由宿主安排独立子代理翻译各块，最后检查对应关系、合并并输出多种格式。

清单文件记录源块哈希，用于防止混合旧内容；术语表和相邻块的短上下文用于减少跨块名称、代词和术语漂移。这样的分工主要解决长文本上下文与合并完整性问题，并不能自动证明每句话都翻译正确。

## 适合什么场景
需要把一份较长的技术手册或有权处理的电子书转成可连续阅读的译文时，可以考虑这条流水线。可恢复执行与选择性重译适合中途打断或修改术语后的再次处理。只翻译少量段落时，这些格式转换和分块步骤可能没有必要。

## 如何开始
1. 准备支持该 Skill 的宿主，并确认其子代理功能可用。
2. 安装 Calibre，使 `ebook-convert` 在 PATH 中可用；另需 Pandoc、Python 3 和 pypandoc。
3. 按 README 选择宿主对应的安装方式。例如 Codex 路径为：

```shell
npx skills add deusyu/translate-book -a codex -g
```

4. 提供输入绝对路径与目标语言；先用短样本检查文字提取和术语，再处理全文。

## 一个使用示例
在已安装的宿主中，官方用法可改写为：

```text
$translate-book Translate /path/to/manual.epub into Chinese.
```

预期工作目录中生成合并的 `output.md` 及 `book.html`、`book.docx`、`book.epub`、`book.pdf` 等产物。检查时应同时看章节是否齐全、术语是否一致、表格和插图是否保留。输入路径是占位示例；本站未运行翻译、格式转换或建立子代理会话。

## 注意事项与相关项目
模型调用的成本与并发限制取决于宿主和服务，转换质量也受原始文件影响。替换输入、输出语言或模板后，应按上游说明使用新的工作目录或处理已有产物，不能假定旧结果会自动全部更新。book-to-skill 和 cangjie-skill 主要提炼可调用知识，本项目则保留整本译文的阅读形态。
