## 它是什么
awesome-coding-js 汇总数据结构、算法和常见 JavaScript 功能的实现说明。它既有排序、树、链表、字符串、栈队列，也有 call/apply/bind、EventEmitter、防抖、节流和 Promise 模拟等专题。目录承认同一题可按多个考察维度重复出现，因此它更像多入口知识索引，而不是不重复的题库。

## 适合什么场景
适合前端开发者按一个实现问题找说明，或把算法与常见语言机制放在一起对照。基础语法和数据结构知识会有帮助；这些教学实现不应直接当成经过完整兼容验证的标准库替代品。

## 如何开始
从 README 或 conardli.top 进入，先选 JavaScript 专题还是算法分类。对于一个实现，先确定支持的输入与限制，再看代码和推导；目录的星数用于作者区分入门与进阶，不表示项目质量评分。
