## 它是什么
MiniMax H3 Cloud 是 Codex 视频生成插件。它把选择云 GPU、创建或启动实例、准备 ComfyUI Runtime、提交工作流和下载 MP4 串成一次任务，并在结束或失败后关机。当前 README 的平台入口是优云智算。

它支持文本生成视频、首尾关键帧以及 1–9 张参考图。仓库提供的是工作流和资源编排，模型权重不包含在插件中，因此安装插件并不等于已经具备模型运行环境或免费算力。

## 适合什么场景
- 本机没有合适 GPU，希望临时使用云端生成视频。
- 已在 Codex 中整理脚本和图片，想把生成任务接入同一工作过程。
- 需要明确资源配置、费用确认和输出文件位置的单次生成。

## 如何开始
前提是 macOS 或 Linux、支持插件的 Codex、Node.js 20 以上、`ssh`、`ffprobe`，以及优云智算账号与 API Key。CompShare CLI 要求 0.3.5 以上。按 README 安装 Marketplace 中的 `minimax-h3-cloud@sac-y-minimax-h3`，调用插件后依次完成本机凭证设置、GPU 选择、视频参数和费用确认。凭证通过官方 CLI 保存在本机，不应作为提示词发送。

## 一个使用示例
官方流程改写，未执行：输入一张已获使用权的角色图片，要求生成一个短镜头。先选择关键帧模式、画幅和时长，核对当前 GPU 价格，再提交工作流。预期在 Codex 中看到视频并取得 MP4；默认输出目录是 `~/.local/share/minimax-h3-cloud/outputs/`。这不是本次已创建云实例或已生成视频的记录。

## 注意事项与相关项目
云 GPU、磁盘和镜像由平台计费，插件免费不代表运行免费。默认 30 分钟兜底关机是上游策略，仍应检查资源状态与账单。模型许可有地区和用途限制，需按 README 链接核对当前协议；MIT 代码许可不能代替模型许可。
