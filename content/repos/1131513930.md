## 它是什么
daily_stock_analysis 从多个市场数据源取得行情、技术指标、新闻和基本面，再由模型整理报告。Web/桌面工作台提供手动任务、历史报告、回测和持仓入口，自动化可通过 Actions、Docker 或本地任务执行。

它同时有多轮策略问股，但分析报告、回测与真实交易是不同环节。模型给出的评分和点位不能替代独立风险评估。

## 适合什么场景
每天整理固定自选股的信息；对照历史报告与后来行情；查询新闻事件如何影响某个研究假设。只需要基础数据时可先核对免费来源覆盖。

## 如何开始
按文档选择本地、Docker 或 Actions。先配置一个可用模型和明确股票列表；Actions 推送另需目标渠道配置。本地 WebUI 可用 `python main.py --webui-only`，默认访问 `http://127.0.0.1:8000`，先手动分析一只股票再安排定时任务。

## 一个使用示例
官方流程改写，未执行：输入一个明确市场代码，生成报告后检查行情日期、新闻链接和风险项，再查看完整 Markdown 并追问某项判断依据。预期得到可追溯研究材料，本站未运行模型分析、回测或消息推送。

## 注意事项与相关项目
免费数据可能限流、缺字段或延迟；不同市场支持边界应看专项文档。“无需服务器”不代表模型和搜索 API 无费用。PA Agent 更偏 K 线诊断，UZI-Skill 更偏多维个股研究。
