## 它是什么
jawil/blog 把前端技术文章放在 GitHub Issues，并按年月列出。内容从类型转换、原型、bind、正则到 Node 路径、PM2、表单验证和 CSS 技巧，常由一个具体疑问展开。仓库本身主要承担文章导航与讨论入口。

## 适合什么场景
适合记得某个“看起来奇怪”的 JavaScript 例子，想重新找回解释，或维护旧 Node/CommonJS 代码时查概念。文章中的技巧应按可读性与实际需求选择，不以行数少作为质量标准。

## 如何开始
先在年度目录找主题，再打开 issue 的正文与评论；涉及 demo 时看作者的环境和文件结构。只阅读无需安装。遇到版本相关行为，记录代码是在 CommonJS、ESM 还是浏览器中执行，再查当前 API。

## 一个使用示例
真实文章示例改写，未执行：进入 issue #18，在 CommonJS 文件中打印 __dirname、__filename、process.cwd() 和 path.resolve('./')，分别从脚本目录与项目根启动。预期文件自身位置与进程工作目录不必一致，由此解释 fs 读取相对路径为何可能失败。

## 注意事项与相关项目
文章主要写于 2017–2018 年，Node 的模块体系和浏览器 API 仍在变化。__dirname 等示例不能不加处理直接用于 ESM。正文中某些“一行技巧”适合讨论语言边界，但用于团队代码前还要评估异常输入与维护成本。
