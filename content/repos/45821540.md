## 它是什么
OpenWrt 是面向嵌入式设备的 Linux 系统，通过可写文件系统和软件包管理扩展路由器等设备的功能。该仓库是核心系统与构建体系；LuCI 界面、社区软件包及路由组件由相关仓库分别维护。

## 适合什么场景
设备明确受支持，需要定制网络功能或自行构建固件。它不是随便下载一个镜像就能装到所有路由器上的通用应用。

## 如何开始
普通用户先从 Firmware Selector 查精确型号与硬件修订，进入 Info 阅读该设备的安装和恢复步骤。开发者需要区分大小写的文件系统与构建依赖，按 README 更新 feeds、安装 feeds、运行 `make menuconfig` 选目标，最后构建。

## 注意事项与相关项目
刷写和错误的目标选择可能导致设备无法启动。不同版本的包、内核和升级路径需要分别核查；README 的构建说明不替代机型文档。sing-box、Xray-core 属于可进一步评估的网络工具，本条不保证它们在任意固件上均有可用安装包。
