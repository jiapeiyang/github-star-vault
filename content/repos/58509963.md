## 它是什么
《TypeScript 入门教程》从 JavaScript 开发者的视角解释 TypeScript，强调循序渐进地理解类型系统。它是一份中文教程与网站源内容仓库，主要产物是可阅读的章节，不是一个安装后为项目自动增加类型的工具。

它与官方手册的侧重点不同：这里适合建立概念顺序，官方手册适合进一步确认完整规则和当前版本行为。遇到编译器的新特性或边界情况时，应把教程中的解释与当前 TypeScript 文档结合起来。

## 适合什么场景
- 已经会写 JavaScript，希望看懂类型注解、联合类型和接口。
- 给旧代码添加类型时，需要查一个小而直接的例子。
- 遇到类型报错，希望先找到概念解释，再定位具体的编译器行为。

README 明确把熟悉 JavaScript、了解 ES6 和 npm 的读者作为主要对象；它不替代 JavaScript 基础教材。

## 如何开始
1. 通过在线阅读入口浏览介绍和基础章节。
2. 针对具体问题查找对应文件，例如 `basics/union-types.md`。
3. 将例子放到自己的 TypeScript 环境或官方演练环境，使用当前项目的编译选项验证。
4. 对教程中引用的历史资料，回到当前官方文档核对变化。

阅读和检索教程无需在本地启动其 Pagic 网站，也不需要为了查一章先安装全部站点依赖。

## 一个使用示例
当一个变量既可能保存文字也可能保存数字时，可在基础目录查看“联合类型”。说明性示例如下，未执行：

```ts
let value: string | number
value = '42'
value = 42
```

这个例子表达同一变量允许两种类型；它并不意味着可以不加判断地调用某一种类型专有的方法。下一步可在章节中查看“访问联合类型的属性或方法”相关解释，再回到实际报错位置。

返回实际代码时，可以先缩小变量类型再调用专有方法，把章节中的概念对应到当前报错。
