## 它是什么
ygs-code/vue 是围绕 Vue 2 风格实现进行逐行注释和流程解释的源码阅读项目。README 把模板转换、Object.defineProperty 数据响应、虚拟 DOM 和 diff 分成几个部分，并从 new Vue、_init、$mount 到编译过程展示代码。重点是让读者沿着实例创建过程理解各模块怎样接上。

## 适合什么场景
适合已经使用过 Vue 2、希望追踪模板如何变成页面，或对观察者、依赖和视图更新关系感到模糊的读者。它不适合作为 Vue 3 的初始化或响应式实现指南，也不是一个业务页面模板。

## 如何开始
从 README 的整体模块说明开始，再看 new Vue 实例入口中的生命周期、事件、render 与 state 初始化。随后阅读挂载模板与编译 AST 部分，遇到具体函数回到仓库源码上下文。运行调试前需确认该副本的具体版本，README 摘要没有给出可靠的小版本号。
