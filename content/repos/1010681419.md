## 它是什么
learn-claude-code 是代理运行框架的教学仓库，用小型 Python 实现展示模型如何请求工具、接收结果并继续下一轮，以及权限、Hooks、上下文压缩和工作流状态怎样围绕核心循环加入。它解释编码代理的运行机制，不是 Claude Code 的官方源码或替代发行版。

## 适合什么场景
适合已有 Python 和模型 API 基础，想理解“模型加工具”如何成为可持续执行系统的人。每章有叙述、代码和图，可以按机制查阅；无需为了看结构就先调用真实模型或执行 shell 工具。

## 如何开始
当前主线是根目录 s01 到 s17，每章有 code.py；agents 目录保留旧 12 章，两套编号并不完全对应。先读 s01_agent_loop，再检查工具调用与权限章节。实际运行需按 requirements.txt 安装依赖，并从 .env.example 配置已授权 API；在受控目录和有限工具权限下试验。
