## 它是什么
Awesome Claude Skills ZH 是面向中文读者的 Agent Skills 资源导航。README 同时整理概念介绍、开放规范、官方指南、社区能力包、工具设施和专题文章。它的主要价值是提供查找入口：从“想让智能体完成哪类任务”出发，找到对应项目，再到原仓库核对实现和安装方法。

页面将官方资源、社区合集与垂直领域项目分开。例如，官方部分连接 anthropics/skills；垂直领域部分可以找到架构图、文档转换、写作和视频等用途。这里的收录和简介属于维护者策展，并不意味着清单中每个项目都经过独立性能或安全验证。

## 适合什么场景
记得某个中文 Skill 的用途、却忘了名字时，可以先在 README 内搜索主题。刚接触 Skills 时，可从背景概念和官方文档理解文件结构；准备挑选能力包时，可对照社区集合与单项工具，避免为了一个功能安装整个大合集。

## 如何开始
1. 直接打开仓库 README，无需克隆或启动服务。
2. 使用目录跳到官方文档、开源库或垂直领域，再搜索用途词，如“架构图”“文档”或“写作”。
3. 打开候选项目的原仓库，检查 SKILL.md、附带脚本、适用宿主和安装方式。
4. 只选择与当前任务有关的能力；需要规范依据时，沿开放标准和官方指南链接继续阅读。

## 一个使用示例
目标是寻找把项目结构画成可交互图示的能力：在 README 搜索 `archify`，找到垂直领域中的对应条目，打开其仓库，进一步查看支持的图类型和输出格式，再判断是否适合当前的架构说明任务。

预期获得一个可继续核对的候选工具和原始文档入口，而不是在这个清单页面直接生成图。此例依据 README 中真实收录条目整理，未安装或调用对应 Skill。

## 注意事项与相关项目
README 中关于热度、规模或效果的评价来自维护者，可能随时间变化。宿主支持程度、全局安装路径和脚本权限应以目标项目及宿主文档为准。与 libukai/awesome-agent-skills 相比，这里可作为另一份中文发现入口；与 anthropics/skills 相比，它主要汇集链接而非提供全部能力的实现。
