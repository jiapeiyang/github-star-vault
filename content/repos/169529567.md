## 它是什么
“谷粒—Chrome 插件英雄榜”是一套浏览器扩展的中文介绍文章，以编号目录连接到各插件的用途和操作说明。网站由 docsify 构建并托管在 GitHub Pages。其组织重点是用户任务，例如看重定向路径、生成网页目录、查看网页历史和整理书签，而不是扩展源码的统一实现。

## 适合什么场景
适合不记得扩展名称但记得功能时查找，也适合在安装前了解一个扩展解决的问题。若要开发自己的扩展，应另查浏览器扩展开发文档；文章集合本身没有共同的安装命令。

## 如何开始
先在 README 按用途关键词搜索，打开编号文章；再沿文章中的发行入口核对扩展名称、开发者和当前版本。安装前阅读请求权限，并确认文章针对的浏览器版本。优先一次验证一个扩展，便于判断效果来自哪个工具。

## 一个使用示例
说明性导航示例，未执行：排查一个页面经过哪些跳转时，可从目录打开第 125 篇“Redirect Path”。先看它展示重定向信息的方式，再按文章入口找到扩展。预期是获得跳转链的可视信息；本站没有安装扩展，也未验证特定页面是否能完整展示所有客户端跳转。

## 注意事项与相关项目
目录同时保留旧扩展、新扩展和油猴脚本，资源类型并不完全相同。Chrome 扩展的平台规则及可用性会变化，例如目录中已经区分 uBlock Origin Lite 与早期 uBlock Origin。推广链接和作者评价不是本站背书；对读取网页内容、Cookie 的扩展尤其应核对实际权限和用途。
