## 它是什么
toJump 用网页界面辅助操作微信“跳一跳”，通过连接手机展示操作流程：用户选择小人底部和目标方块位置，工具据此完成跳跃。README 提供 Android USB 调试和 iOS WDA 两条接入方式，Node 服务负责网页端入口。这是设备控制实验，不是游戏源代码，也不是一个完全自主的游戏代理。

## 适合什么场景
适合研究网页与手机调试接口如何配合，或理解由坐标输入映射为设备触摸的历史方案。需要真实手机、调试授权和对应系统工具，普通浏览器页面单独运行不能操作手机。

## 如何开始
上游要求先安装 Node，取得项目后 npm install、npm start；服务默认 4000 端口，可在 config.js 修改。Android 需开启 USB 调试并授权电脑，部分设备还需允许模拟点击；iOS 需按文档配置 WDA 地址。device 配置要与设备类型一致。

## 注意事项与相关项目
README 已提示截图未经处理可能加载较慢，连接与触摸精度还受设备和旧接口兼容影响。WDA 与 Android 权限配置应以当前工具文档为准，不应为了测试授权陌生电脑。项目年代较早，不能保证今天的微信、iOS 或 Android 仍能按原步骤工作。
