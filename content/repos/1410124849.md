## 它是什么
Anatomy 是通过“构建可工作的物体”解释概念的 Agent Skill，用大量具体零件、几何关系和交互表达机器、仪器或系统。主要输出 SVG、HTML，也可提供 React 和可选 WebGL／三维效果；它不是通用数据图表库。

## 适合什么场景
解释令牌桶、连接池或机械装置等具有明确机制的主题。适合文档插图和交互演示；人物、精确地图及缺少可构造机制的抽象主题不是上游重点。

## 如何开始
按 README 用 skills CLI 选定宿主，例如项目级安装后在对应代理中调用。工具脚本需要 Node.js 20.10+，浏览器检查需要 Chrome／Chromium。先从小机制开始，明确零件数量、交互变量与期望产物。

## 注意事项与相关项目
三维模式在上游仍为 beta，示例性能不能外推到任意复杂图。几何与浏览器审核可能花较长时间；WebGL 不可用时应核对 SVG 回退。diagram-design 更适合抽象架构和流程，AetherViz 更偏教学主题网页。
