## 它是什么
Puppeteer 是用于控制 Chrome 或 Firefox 的 JavaScript 库，通过 DevTools Protocol 或 WebDriver BiDi 提供页面导航、元素定位和浏览器操作 API，默认以无可见界面的方式运行。它让脚本驱动真实浏览器，适合验证页面行为，也常用于截图、抓取和自动化工具的底层。

## 适合什么场景
适合自己的网页端到端操作、生成页面产物，或读取需要浏览器执行后的内容。它需要浏览器运行环境，与只发送 HTTP 请求的库不同；目标站点的登录、访问规则和稳定性仍需单独处理。

## 如何开始
按 README 安装 puppeteer；puppeteer-core 只提供库、不自动下载 Chrome。若安装脚本被包管理器阻止，文档给出 npx puppeteer browsers install 补装浏览器。之后用 launch 创建浏览器、newPage 创建页，再导航并定位元素，结束时 close 释放进程。

## 一个使用示例
官方示例节选，未执行：
```js
import puppeteer from 'puppeteer';
const browser = await puppeteer.launch();
const page = await browser.newPage();
await page.goto('https://developer.chrome.com/');
await browser.close();
```
目标是打开官方文档页并释放浏览器；更完整的 README 示例会填写搜索框、点击结果并读取标题。本站没有启动浏览器或向该页面发送这段脚本。

## 注意事项与相关项目
库安装成功不等于浏览器已下载，系统依赖和版本匹配仍是运行前提。页面选择器会随网站改版变化，自动化成功也不等于所有浏览器行为都已覆盖。代码中应明确关闭自己创建的浏览器，避免留下后台进程。
