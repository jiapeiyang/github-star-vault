## 它是什么
Cockpit Tools 是面向 macOS、Windows 和 Linux 的 AI IDE 账号管理应用，覆盖 Antigravity、Codex、Copilot、Cursor 等多个客户端。它集中显示账号与配额，支持切换账号、导入凭据和管理应用实例；不同平台使用各自的认证与本地配置方式。

## 适合什么场景
适合已经拥有多个受控账号，需要在不同项目间区分客户端环境，或想集中查看剩余额度与重置时间的人。工具帮助组织账号和实例，不会增加提供方实际授予的配额，也不能保证第三方账号状态接口持续兼容。

## 如何开始
先从 Releases 选择系统安装包，再阅读所用平台章节。优先从当前客户端或官方授权流程导入自己的账号，核对 Dashboard 显示的身份与套餐。需要多实例时设置独立目录、绑定账号并指定工作项目，然后在启动后的官方客户端再次检查身份，确认没有误切正在使用的会话。

## 一个使用示例
说明性示例，未执行：为两个项目创建不同的 Codex 受管实例，各自绑定已授权账号，启动后分别打开对应目录；在配额页刷新并查看 Hourly、Weekly 状态。预期是两个明确区分的工作环境，而不是两个窗口天然证明认证与文件目录完全隔离。本次没有导入凭据或启动实例。

## 注意事项与相关项目
部分切号动作会写回官方客户端认证文件，导出文件也未必包含可恢复的完整登录凭据。macOS 对子进程的目录权限可能显示为 Cockpit Tools 请求，需按实际任务判断。README 说明开源发行尚未接入 Developer ID 签名与公证；本站不把绕过系统保护作为默认安装步骤。相关 Antigravity Cockpit 更聚焦编辑器内配额展示。
