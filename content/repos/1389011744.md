## 它是什么
Lemo-Opuscar 是用代码制作影片的风格工具箱，每种风格配提示说明和演示短片，涵盖绘画、印刷、图形、动漫、游戏与电影等方向。当前 README 列出 59 种，数量是核查时的上游状态，不是本站质量评分。

## 适合什么场景
已有故事与信息结构，想为短片选定统一视觉语言，或从现有样例发展自己的风格。它依赖编码代理来导演与实现，不是提供通用视频生成模型的在线服务。

## 如何开始
先浏览公开画廊选风格，再按 README 安装 Claude Code 插件或克隆仓库。其他宿主使用其 `plugin/skills/lemo-opuscar/` 入口。准备 Node 20+、ffmpeg 和 Python 3.11+；首次会下载共享工具到用户目录，影片项目存放在发起任务的目录。
