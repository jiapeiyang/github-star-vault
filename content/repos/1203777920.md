## 它是什么
AI Berkshire 用价值投资方法整理公司研究，包含质量筛选、新闻归因、完整投资研究和团队式评审。不同角色分别关注商业模式、财务估值、逆向风险与长期确定性，目标是形成可比较的判断和假设。

仓库同时维护大量公开报告，适合先看实际产物再决定是否运行。引用投资大师代表方法论角色，不是本人提供意见或背书。

## 适合什么场景
围绕一家公司的护城河和现金流建立研究提纲；寻找估值假设中的反例；比较同一公司不同日期的公开研究。它不执行证券交易。

## 如何开始
先从 `reports/README.md` 选一家公司查看报告结构。按宿主安装对应 commands 或 Codex skills，然后从 quality-screen 或 news-pulse 这种窄任务开始，值得继续时再使用 investment-research。提供明确公司、研究日期和问题，核对事实来源后再评价结论。

## 一个使用示例
官方流程改写，未执行：先筛查一家公司业务是否可理解、利润是否有持续性，再对“客户集中造成风险”查年报和反例，最后比较乐观与保守估值情景。预期交付证据、假设和未知项，不把角色评分平均值直接当成买入依据。

## 注意事项与相关项目
README 的历史收益属于作者展示，本站未独立审计，也不能证明未来收益。多轮研究会增加 Token 成本。UZI-Skill 覆盖更广流派与指标，本项目集中价值投资研究纪律。
