## 它是什么
lexfridman-cn 是 Lex Fridman Podcast 的非官方中文导航站，包含双语标题、AI 导读、单集链接、搜索与全文 RSS，并链接官方音视频来源。站点代码和已整理的内容可构建为纯静态网站。

## 适合什么场景
按主题找回长访谈，先看中文导读再回原始节目核对，或研究播客导航与静态内容站的实现。中文导读是 AI 归纳，不能视为嘉宾原话或经过官方审核的翻译。

## 如何开始
阅读可直接使用公开站点。开发预览按 README 克隆后运行 `python3 tools/build.py`，再用 `python3 -m http.server 8123 -d site` 查看。构建只用 Python 标准库；追新、生成导读和转写是另一条管线，可能需要模型、macOS 钥匙串或本地转写工具。

## 一个使用示例
使用流程示例，未执行：在搜索框输入一个嘉宾加主题词，选中单集，阅读导读后通过官方音频时间戳核对关键结论。记录原始节目来源，避免仅引用导读中的概括句。

## 注意事项与相关项目
代码 MIT 不代表导读、元数据和第三方媒体都适用同一许可。上游集数与文章数是时间快照；官方源不可用时，本站不会保证播放。Horizon 面向多来源资讯简报，本项目专注固定播客的阅读与发现。
