## 它是什么
Caveman 分为两部分：较轻的技能约束回答文风，减少铺垫与重复说明；可选的本地 proxy 位于代理与模型服务之间，压缩输入内容并在本地保留原文供恢复。前者影响输出表达，后者进入请求链路，安装、成本与数据边界不同。

## 适合什么场景
适合嫌编码代理解释过长，希望保留命令、路径和错误原文而缩短周边叙述的人。对复杂方案、评审证据或教学材料，过度缩写也可能降低理解，应明确哪些内容必须完整。想减少输入 token 时才需要研究 proxy。

## 如何开始
只试文风技能可使用 `npx skills add JuliusBrussee/caveman`，未自动激活时按宿主支持调用 /caveman。先让它处理一段常见解释，检查关键条件是否丢失。proxy 另有 @caveman-ai/cli 和 setup 流程，应先读 INSTALL.md 与隐私说明，再决定是否改变代理启动方式。

## 注意事项与相关项目
README 的 token 节省比例来自项目评估，不是每种语言与任务的保证。技能使用 MIT，proxy runtime 标为 BSL-1.1，不能对整仓库笼统套一种许可。本地压缩保存原文并不自动证明语义未丢失，应对重要工具输出和精确错误保留核对路径。
