## 它是什么
Map-of-Javascript 用大幅图片组织 JavaScript 及相关 Web 概念。README 除主图外，还链接数据结构与算法、HTML/CSS/DOM、密码学、响应式和技巧图。主图将 Object、Function、Array、Promise、事件循环、作用域与闭包等内容排在一张图上，通过连线与短代码帮助读者观察相邻关系。

## 适合什么场景
适合已经认识部分概念、想快速回忆它们怎样关联的读者，也可作为讨论或讲解时的全景索引。它不是可交互执行环境，小字密集的图也不适合替代完整文本教程。

## 如何开始
先从 README 打开需要的原图并放大，而非直接阅读缩略图。选择一块区域，例如集合或异步，再看关联线指向哪里。遇到省略的语义或陌生 API 时，以图上关键词去官方文档查具体条件，不需要安装仓库。
