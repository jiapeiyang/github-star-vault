配方只在 `config/recipes.json` 中人工维护。新增条目时保留三个到六个有输入输出的步骤；工具引用必须存在且至少被一个步骤使用，来源和核查日期必填，证据状态仍为 `public-sources`。配方引用的工具前提变化时，一并核对对应的 `content/repos/*.md`，不把 README 未变化当作所有文档都已复核。

修改后运行上述 Python、前端、Sites 与构建检查。`app/public/data/*.json` 仍为生成产物，不手改、不提交；`data/repositories.json` 继续只由同步脚本维护。
