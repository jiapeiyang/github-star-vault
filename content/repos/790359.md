## 它是什么
Sequelize 是基于 Promise 的 Node ORM，通过模型与关联表达数据库记录，并提供事务、预加载、延迟加载和读复制等能力。README 列出多种 SQL 数据库，同时将文档区分为 Sequelize 6 稳定版与 7 alpha。理解它时需要先选主版本和数据库方言，再看对应 API，而不是混用包名与驱动配置。

## 适合什么场景
适合希望以 JavaScript/TypeScript 模型访问关系数据库的服务，或管理已有表与关联。ORM 可以减少常见查询样板，但不会替应用决定索引、事务边界、数据权限或迁移策略。

## 如何开始
v6 官方入门要求安装 sequelize，再单独安装所选数据库驱动，例如 SQLite 使用 sqlite3、MySQL 使用 mysql2。用 Sequelize 构造实例指定连接参数或 URI，再 authenticate 检查连接，任务结束 close 释放资源。尝试概念时可用内存 SQLite，避免依赖已有数据。

## 一个使用示例
v6 官方示例改写，未执行：
```js
const { Sequelize } = require('sequelize');
async function check() {
  const db = new Sequelize('sqlite::memory:');
  try { await db.authenticate(); }
  finally { await db.close(); }
}
check().catch(console.error);
```
目标是确认驱动与连接工作，不建表、不写业务数据；本文没有安装驱动或运行示例。

## 注意事项与相关项目
默认分支展示 @sequelize/core 信息，而 v6 文档使用 sequelize，二者不能只改导入名就认为完成迁移。sequelize-typescript 的 README 明确面向 v6，装饰器扩展也要匹配版本。连接成功不等于模型、迁移和事务正确，实际操作数据库前仍需确认环境与表结构。
