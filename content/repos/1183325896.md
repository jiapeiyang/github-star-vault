## 它是什么
Emil Kowalski 的 Skills 仓库把界面设计与动画经验整理为编码助手可读取的能力包。内容覆盖动画曲线、时长、属性选择、已有动效审查，以及 Expo、Swift 和界面库选择等具体主题。

它的核心价值在于把一些容易遗漏的界面判断显式写出来，例如进入动画应该如何减速、哪些交互值得添加动效。它不是一个可直接导入的 React 动画组件库，也不会自动替用户确定所有设计取舍。

## 适合什么场景
已有页面能正常工作，但动画节奏、层次或交互细节不理想时，可以阅读或调用对应 Skill。需要从零写某个过渡效果时，查看 animate；想审视现有动效时，查看 review-animations 或 improve-animations。与当前技术栈无关的能力无需一起使用。

## 如何开始
1. 在 README 的 Reference 中找到目标 Skill，先看它的适用范围。
2. 对照当前宿主是否支持这些 Skill 的目录和工具要求。
3. 按上游提供的 skills CLI 命令安装，再显式提出范围明确的界面任务。
4. 在实际页面里检查结果，兼顾键盘、触控和减少动态效果偏好。

```shell
npx skills@latest add emilkowalski/skills
```

## 一个使用示例
如果弹窗进入时感觉突兀，可以要求宿主使用 review-animations，检查该弹窗的时长、缓动和参与动画的属性，并解释建议调整的原因。之后只改这个交互，比较打开和关闭的实际效果。

这个例子依据 README 中的能力划分整理，本站没有安装、运行或对某个真实弹窗实施修改。是否更自然需要在页面上观察，不能仅从命令成功判断。

## 注意事项与相关项目
README 中的“更好的品味”是作者对规则价值的描述，不是可直接推广到所有项目的保证。已有设计系统、品牌要求和可访问性约束仍需保留。不同宿主能力与组件库 API 也可能影响执行结果，应查看具体 Skill，而不只阅读目录摘要。
