## 它是什么
Claude HUD 使用 Claude Code 的 statusline API，读取标准输入 JSON 和会话 transcript，把模型、上下文容量、工具活动、代理和 todo 进展显示在输入区下方。它不需要额外窗口或 tmux。

上下文数据来自宿主，活动则从记录解析。它帮助观察当前会话，不是另一个调度引擎，也不能判断任务结果是否符合需求。

## 适合什么场景
长会话想看到上下文占用；同时运行子代理时判断谁在工作；在终端中快速确认项目路径和 Git 状态。

## 如何开始
按 README 添加 Marketplace 并安装 claude-hud，重新加载插件后执行 `/claude-hud:setup` 配置状态栏。再用 `/claude-hud:configure` 选择 Full、Essential 或 Minimal、语言与布局。Windows 设置流程要求可用的 Node.js LTS。

## 注意事项与相关项目
多个 Claude 配置目录共享 plugins 符号链接时，HUD 配置可能是同一文件，独立覆盖要按 README 使用相应路径。上下文百分比与账户配额不同；CodexBar 看跨服务额度，HUD 看当前 Claude 会话。
