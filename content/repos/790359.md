## 它是什么
Sequelize 是基于 Promise 的 Node ORM，通过模型与关联表达数据库记录，并提供事务、预加载、延迟加载和读复制等能力。README 列出多种 SQL 数据库，同时将文档区分为 Sequelize 6 稳定版与 7 alpha。理解它时需要先选主版本和数据库方言，再看对应 API，而不是混用包名与驱动配置。

## 适合什么场景
适合希望以 JavaScript/TypeScript 模型访问关系数据库的服务，或管理已有表与关联。ORM 可以减少常见查询样板，但不会替应用决定索引、事务边界、数据权限或迁移策略。

## 如何开始
v6 官方入门要求安装 sequelize，再单独安装所选数据库驱动，例如 SQLite 使用 sqlite3、MySQL 使用 mysql2。用 Sequelize 构造实例指定连接参数或 URI，再 authenticate 检查连接，任务结束 close 释放资源。尝试概念时可用内存 SQLite，避免依赖已有数据。

### 本地验证：构造对象和默认值，不写数据库

复验时先按 Star Vault 源码中的 `docs/examples/v1.3/README.md` 安装独立依赖，再运行同目录的 `sequelize.mjs`。下文展示该完整测试的核心输入与结果；脚本不属于上游仓库。

环境：macOS arm64、Node.js 24.14.0、`sequelize 6.37.8`、`mysql2 3.24.3`。命令：`node sequelize.mjs`。mysql2 只满足方言模块加载，整个例子没有连接数据库。

```js
const db = new Sequelize('unused', 'unused', 'unused', { dialect: 'mysql', logging: false })
const User = db.define('User', {
  name: DataTypes.STRING,
  favoriteColor: { type: DataTypes.STRING, defaultValue: 'green' },
}, { timestamps: false })
const user = User.build({ name: 'Ada' })
console.log(user.toJSON())
user.set({ favoriteColor: 'blue' })
console.log(user.toJSON(), user.isNewRecord)
```

输入只有 `name: "Ada"`，构造后的实际对象为：

```json
{"favoriteColor":"green","id":null,"name":"Ada"}
```

修改后的对象为 `{"favoriteColor":"blue","id":null,"name":"Ada"}`，`isNewRecord` 仍为 `true`。默认值已经生效，ID 还没有数据库生成；`build` 与 `set` 只是操作内存中的模型实例。本例没有调用 `authenticate`、`sync`、`save`、`create` 或查询，不能据此声称连接、SQL、约束或事务已验证；脚本最后调用 `close()` 释放实例资源。

## 注意事项与相关项目
默认分支展示 @sequelize/core 信息，而 v6 文档使用 sequelize，二者不能只改导入名就认为完成迁移。sequelize-typescript 的 README 明确面向 v6，装饰器扩展也要匹配版本。连接成功不等于模型、迁移和事务正确，实际操作数据库前仍需确认环境与表结构。
