## 它是什么
Dembrandt 用 Chromium 渲染页面，再读取 DOM 的计算样式，归纳颜色、字体、间距、边框、阴影、动效和组件。输出可用于 W3C Design Tokens、Tailwind 主题或给代理阅读的 DESIGN.md。

它提取的是页面实际观察到的样式并附带分析，不等于恢复原始设计稿的全部语义。多页面抓取可以增加重复模式的证据，CI 则能把预览版本与保存的基线比较。

## 适合什么场景
整理已有网站的视觉规范；迁移项目时盘点真实颜色字体；检查版本是否发生设计 token 漂移。想恢复完整交互源码时需要其他重建工具。

## 如何开始
需要 Node.js 18 以上。按 README 安装 `dembrandt` 后先运行 `dembrandt install-browser`，因为 `playwright-core` 不自带浏览器。再给出目标站点，选择终端输出或 `--save-output` 保存结果；只提取单页确认质量后，再考虑 crawl。

## 一个使用示例
官方命令摘录，未执行：

```shell
dembrandt dembrandt.com --design-md
```

目标是得到代理可读的设计资料；若需要与 Tokens Studio 等工具对接，README 提供 `--dtcg`。预期输出包括观察到的颜色、排版和间距，接入项目前应检查是否把偶发值误当成全局规范。

## 注意事项与相关项目
登录态、延迟加载、暗色主题与视口会改变采样结果。提取字体 URL 不等于获得字体再分发许可。awesome-design-md 提供现成参考文本，Dembrandt 更偏从实际网页生成观察资料。
