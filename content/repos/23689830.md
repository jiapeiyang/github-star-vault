## 它是什么
《Docker 从入门到实践》是一部中文容器技术书，覆盖镜像、容器、仓库、Dockerfile、数据、网络、Buildx、Compose，进一步延伸到编排、安全、监控和 CI/CD。README 当前标明基于 Docker Engine v29.x，并按基础、进阶、原理和实践划分章节。书稿与 Docker 引擎是不同资源，阅读并不要求先运行容器。

## 适合什么场景
适合查容器基本概念、将一个应用整理为镜像，或为部署与运维问题找中文说明。读者具备基础 Linux 知识会更顺畅；具体宿主系统和发行版的安装方式仍须分别确认。

## 如何开始
在线可通过 GitBook 或 SUMMARY.md 目录阅读，离线 PDF 从 Releases 获取。想开始操作时，先按第 3 章安装并验证 Docker，再阅读镜像、容器和仓库的关系，最后才编写自己的 Dockerfile。需要本地阅读站点时 README 另提供 mdPress 路径。

## 一个使用示例
官方快速开始示例，未执行：
```shell
docker run -it ubuntu bash
```
目标是在已正常运行 Docker 的环境进入 Ubuntu 容器交互 shell。首次可能需要下载镜像，预期获得容器内终端；本文未拉取镜像或启动容器，也不把容器内文件修改视为宿主机修改。

## 注意事项与相关项目
默认分支的 preview-pdf 会随主线覆盖，和正式 Release PDF 不是同一个稳定版本。容器网络、卷挂载及权限设置会影响真实宿主资源，阅读示例时必须确认具体参数。书籍采用 CC BY-NC-SA 4.0，原样引用与改编需遵循许可，不能把所有内容当成无条件转载。
