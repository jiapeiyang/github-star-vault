## 它是什么
koa-jwt 是 Koa 的 JSON Web Token 校验中间件，负责从请求中取得 token、验证后把解码结果放入 ctx.state.user，供后续代码使用。它不负责完整登录界面，也不会仅凭 token 有效就判断用户能访问哪条业务数据；身份校验与业务授权是相邻但不同的步骤。

## 适合什么场景
适合已有 JWT 签发方的 Koa API，在受保护路由前验证调用者；也适合研究中间件顺序怎样形成访问边界。尚未确定 token 来源和签名方式时，应先明确认证契约。

## 如何开始
按 README 安装 koa-jwt，选择与 Koa/Node 匹配的版本。默认从 Authorization Bearer 头取 token，也可设置 cookie 或 getToken；自定义 getToken、cookie、header 按顺序取首个非空值。把校验放在受保护处理器之前，提供匹配签发方的 secret 或公钥，必要时配置 issuer、audience 与撤销检查。

## 注意事项与相关项目
passthrough 会让请求继续往下，即使没有有效认证，因此下游必须显式判断用户状态，不能把它当作仍然强制保护。默认解码字段可用 key 改名，撤销不是自动维护的黑名单。README 保留旧版本兼容说明，现代 Koa 的支持仍需按依赖版本核对；也不要把完整 token 写入公开日志。
