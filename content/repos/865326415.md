## 它是什么
21st.dev 以 shadcn 风格分发 React 组件，主要使用 Tailwind CSS 与 Radix UI。每个组件可以有多种演示，使用者将源码与依赖加入自己的项目后继续定制。

这个仓库同时是 registry 网站的实现，包含用户、元数据和文件存储。因此“使用一个组件”和“本地搭建整个 21st.dev”是两种工作量很不同的路径。

## 适合什么场景
找按钮、折叠面板或营销区块的实现参考；需要可修改源码而不是黑盒依赖；想向社区展示自己的可复用 React 组件。

## 如何开始
普通使用先浏览在线演示，检查组件代码与依赖，再在项目根目录运行条目提供的 shadcn 安装命令。自建平台则需按仓库准备 Supabase、Clerk 和 R2 等配置，不能仅 npm install 就获得完整服务。

## 一个使用示例
官方命令摘录，未执行：

```shell
npx shadcn@latest add "https://21st.dev/r/shadcn/accordion"
```

目标是引入 Accordion 及其必要文件，再用项目真实内容接入，检查键盘与展开状态。安装可能修改全局样式和主题，应查看 diff。

## 注意事项与相关项目
社区组件的依赖、可访问性和版本适配仍需检查，精选不代表所有场景都验证过。cult/ui 同样强调源码复制，21st.dev 更偏多作者 registry 和演示发现。
