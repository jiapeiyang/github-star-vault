## 它是什么
WeChat Intelligence Hub 把本地微信记录转成可检索的联系人历史、群聊主题、待回复、承诺和业务线索。项目包含 `wechat-cli` 只读数据入口和 `wechat-intelligence-hub` 情报工作流，底层 Reader、Agent 入口和确定性本地引擎分别维护。

本次 README 标注 `v0.9.2-preview.2`。完整数据库模式要求本人授权的本地数据库及访问材料，只能覆盖已经同步到本机的数据。macOS 通知预览是另一种有限来源，只包含系统保留的入站预览，不能当成完整聊天记录。

## 适合什么场景
- 找回某个产品、联系人或项目在聊天里的上下文。
- 按指定时间范围汇总群聊主题与待跟进事项，并追溯原消息。
- 先用虚构数据理解本地索引和报告流程，再判断是否有必要接入个人资料。

## 如何开始
建议先阅读仓库安装与访问条件说明，并从全虚构 Demo 了解产物。上游完整安装入口为 `./scripts/install.sh --with-sqlcipher`，会安装两个 Skill 及其本地引擎；这不代表数据库访问已配置成功。

真实接入前应检查已有配置和数据覆盖。Reader 核心不负责获取密钥；实验性接入助手另有授权和副作用范围。个人说明、联系人、数据库和报告应留在本地。完成有效接入后，再初始化个人关注信息，并按实际时间范围检索或生成报告。

## 一个使用示例
官方虚构数据入口，未执行：在克隆的仓库中运行下面的演示，而不接入真实微信。

```bash
bash projects/wechat-intelligence-hub/scripts/run_demo.sh
```

该入口用于检查虚构数据下的索引、判断和报告链路。真实使用中的完整日报可输出 Markdown 与交互式 HTML，包含行动、群聊、联系人等入口；应逐条核对结论是否能回到原消息，不把推测的商机或承诺当成已经确认的事实。

## 注意事项与相关项目
微信版本、数据库覆盖和访问权限会影响结果；README 的本机实读验收是上游记录，本站未复验。该项目默认只读，不发送消息；回复草稿与实际发送是两个步骤。报告可能含敏感聊天和个人资料，不能作为公共仓库附件提交。项目采用 AGPL-3.0-only，付费社群与软件使用和商业授权分开。
