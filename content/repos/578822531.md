## 它是什么
LocalSend 是通过局域网在附近设备之间传文件和文字的开源应用，可用于 Mac、Windows、Linux、Android 和 iOS 之间交换资料。它把“发现设备—选择文件—接收”放在应用里完成，文件传输不依赖聊天软件账号或第三方中转服务器。

从工作方式看，两端运行的是同一套传输协议：设备在本地网络里发现彼此，再通过 HTTPS 交换内容。因此“同一个 Wi-Fi 名称”不一定就代表能互相连接，访客网络的设备隔离仍可能阻断发现或连接。

## 适合什么场景
- 把 Mac 上的图片、PDF、项目压缩包发给 Windows 备用机，不想登录聊天软件。
- 把手机照片传到电脑，或者在不同系统之间临时交换一段文字。
- 有局域网但没有外网时，仍需在附近设备之间传文件。

它适合主动选择并发送资料，不是持续同步目录的网盘，也不会自动替你解决远程跨网访问。

## 如何开始
1. 从仓库的 Download 区域选择对应平台的发行版本；通常无需编译 Flutter 源码。
2. 在发送和接收设备上启动应用，连接允许设备互访的同一局域网。
3. 选择要发送的文件或文字，再选择目标设备；接收端核对并接受传输。
4. 如果设备列表为空，先检查本地网络权限与访客网络隔离。上游列出的默认入站端口是 TCP/UDP 53317，应按当前网络政策允许应用通信。

Windows 便携模式还可在可执行文件旁创建 `settings.json` 保存设置；这是上游文档提供的可选方式，不是所有平台都需要的步骤。

## 一个使用示例
目标是在电脑间传送一份 PDF。图形界面中选择 `report.pdf`，选中目标设备，接收端确认后检查收到的文件名和内容。

仓库还提供基于协议 v2 的 CLI。已单独安装 CLI 时，上游示例为：

```shell
localsend-cli send report.pdf photo.jpg ./project-backup
```

命令会展示已发现的设备，选中目标并按 Enter。也可用 `--to` 指定唯一设备别名或 IP。该示例来自官方 README，本站未进行两台设备的传输实测，图形应用的安装也不代表 CLI 一定已在 PATH 中。

## 注意事项与相关项目
通信仍受防火墙和网络隔离限制。当前 README 对 Windows 的最低版本列为 Windows 10；需要旧系统时应核对对应历史发行版。文件夹会递归收集文件，但 CLI 文档说明空目录不会被传输。发送前应确认目标设备，避免把整个目录中不需要的文件一起选入。
