## 它是什么
decaffeinate 将 CoffeeScript 源码转换成现代 JavaScript。它是迁移工具，目标是让已有 CoffeeScript 项目逐步转向 JavaScript，同时尽量保留程序语义。README 提供单文件、递归目录和在线 REPL 使用方式，并建议真实项目配合 Conversion Guide 与转换后的清理流程。

## 适合什么场景
适合维护遗留 CoffeeScript 应用、减少语言工具链依赖，或比较同一逻辑在两种语法中的表达。它不是通用重构器，生成 JavaScript 并不自动解决旧业务逻辑和测试缺口。

## 如何开始
先在可回滚副本中选一个小文件，阅读相关转换选项。上游安装命令是 npm install -g decaffeinate；单文件执行 decaffeinate input.coffee 会生成 input.js。目录级转换可递归处理，但大项目应先按转换指南规划，再考虑 bulk-decaffeinate 包装工具。

## 一个使用示例
官方命令示例，未执行：
```shell
decaffeinate input.coffee
```
目标是把一个已知输入文件转换成相邻 JavaScript 文件。之后对照原函数的参数、返回值和边界行为运行已有测试，预期确认语义一致；不是仅检查输出文件存在就宣布迁移完成。

## 注意事项与相关项目
README 将项目状态标为 Complete，但同时明确不作正确性保证，展示项目中的测试也有历史版本或调整说明。CoffeeScript 特有行为、模块加载与构建配置需要一起审视。本文未转换任何文件，也没有执行在线 REPL；示例不会自动改写项目依赖或发布配置。
