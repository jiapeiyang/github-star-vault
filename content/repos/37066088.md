## 它是什么
sudo-prompt 为 Node 或 Electron 中的非图形命令提供系统权限提升对话框。macOS、Linux 和 Windows 使用各自平台机制，调用者通过 exec 获取错误、标准输出和标准错误。它解决的是后台应用无法方便向用户请求权限的问题，不应被理解为绕过系统授权。

## 适合什么场景
适合桌面应用确实需要执行一条有权限要求的维护命令，或者希望用原生系统对话框展示授权。普通文件处理和不需要提权的任务无需使用；README 明确要求不要用它启动图形应用。

## 如何开始
按上游安装 npm install sudo-prompt，调用 sudo.exec 时命令不要再加 sudo 前缀。options.name 仅允许字母数字与空格、最长 70 字符；环境变量通过 options.env 显式传入。不同平台对图标和名称的支持不同。

## 一个使用示例
官方示例改写，未执行：
```js
const sudo = require('sudo-prompt');
sudo.exec('echo hello', { name: 'Example App' }, (error, stdout) => {
  if (error) throw error;
  console.log(stdout);
});
```
目标是观察经系统授权后的输出 hello；本条没有触发权限弹窗或执行任何提权命令。

## 注意事项与相关项目
exec 不返回 child_process.exec 那样的子进程对象，不能直接依赖 pid 或进程控制。Linux 依赖 pkexec 或 kdesudo，Windows 走 UAC。多次调用不会自动按顺序执行，也可能出现多次密码提示；实际接入应保持命令内容受控，避免把外部输入直接拼成高权限 shell 命令。
