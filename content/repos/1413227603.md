## 它是什么
这是可用代码修改的解说视频工程：用 Remotion、React 和 SVG 生成画面，把动画与字幕或音乐节拍对齐，并包含程序合成的音乐、音效和制作技能。每帧由代码决定，适合检查时间线与重复渲染。

## 适合什么场景
制作解释概念、展示流程或带字幕的风格化短片，也适合学习代码动画的组件与场景组织。它不是通用视频剪辑器；作者的全部配音、照片、视频和授权音乐没有随仓库发布。

## 如何开始
准备 Node.js，导出还需 ffmpeg。克隆后按 README 执行 `npm install`、`npm run audio` 和 `npm run studio`，先打开不依赖外部素材的 30 秒 `ep00-demo`。使用制作技能还需要已配置的 Claude Code 与供 Python 辅助脚本使用的 uv；完成演示后再研究单集结构与风格提炼技能。

官方演示流程整理，未执行：在 Studio 预览 `ep00-demo`，修改一处字幕和对应视觉元素，检查动画是否仍与时序一致。预期得到一段可重复渲染的演示，不以其他单集缺失音频来判断整个工程无法运行。

## 注意事项与相关项目
部分单集会因未分发的原始素材而静音或留空，音乐脚本也可能需要自行提供合法音轨。上游展示不代表本站渲染结果。Lemo-Opuscar 更强调风格工具箱；AetherViz 面向交互教学网页，交付形式不同。
