## 它是什么
CodexBar 把不同 AI 编码服务的额度窗口和重置倒计时放进菜单栏，可为每个服务显示图标，也可合并切换。视提供商支持，还能展示余额、费用扫描和服务状态。

数据从已有 CLI、OAuth、API Key、浏览器会话或本地应用文件读取。它主要负责观测，不增加额度，也不是统一的模型调用网关。

## 适合什么场景
开始长任务前检查会话或周额度；同时用多个服务时减少逐个打开仪表盘；区分额度耗尽与服务故障。

## 如何开始
macOS 应用要求 14 以上，可用 `brew install --cask codexbar` 或官方 Releases。打开 Settings → Providers 启用实际使用的服务，按其数据源完成登录或配置。Linux 另有 CLI 发行，不等同 macOS 菜单栏应用。

## 一个使用示例
官方使用流程改写，未执行：启用两个已有登录态的服务，查看各自剩余额度和下一次重置时间，再决定当前任务使用哪一个。若某项数据缺失，回到提供商设置检查来源，而不是把空值解释为剩余零。

## 注意事项与相关项目
不同提供商计费窗口、缓存和费用口径不能直接混加；显示时间也不是额度一定即时恢复的承诺。浏览器 cookie 与 API Key 涉及账号权限，应只配置可信来源。Thaw 可整理菜单栏空间，CodexBar 提供具体配额内容。
