## 它是什么
cult/ui 的基础定位是可访问、可定制的源码组件，使用者复制进项目后建立自己的组件库。当前 README 同时推广 AI SDK agents、交互 artifact、完整模板和 CULT PRO 付费区块。

应区分开源组件、关联模式站和商业模板：它们可能具有不同获取方式、依赖与服务配置，不能看到同一 README 就认为全部内容免费可用。

## 适合什么场景
寻找可修改的界面组件；参考聊天、表格或图表 artifact 的交互；需要查看 AI 工具调用怎样落到前端界面。

## 如何开始
从 README 的 Documentation 进入 `cult-ui.com/docs`，选择实际需要的组件，阅读示例、依赖和安装方式。相关 AI 模式可先看在线预览，再决定复制代码、shadcn 安装或下载模板；只引入组件时不必部署整个关联平台。

## 注意事项与相关项目
模型调用、鉴权、支付和抓取功能可能需要独立服务与 Key；模板宣传中的生产可用性需自行验证。许可证要按实际取用文件和产品核对。21st.dev 更偏社区 registry，cult/ui 更偏作者组件与配套模板。
