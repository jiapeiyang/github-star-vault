## 它是什么
cult/ui 提供可复制、可修改的 React 源码组件，当前 README 列出 150 多个免费组件，使用 shadcn registry 安装，沿用 Tailwind CSS v4 与 shadcn 默认 token，多数组件使用 Motion。使用者把组件代码带入自己的项目后维护。

应区分开源组件、关联模式站和商业模板：它们可能具有不同获取方式、依赖与服务配置，不能看到同一 README 就认为全部内容免费可用。

## 适合什么场景
寻找卡片、导航、交互和动效组件；在已有 shadcn/Tailwind 工程中加入局部控件；希望直接修改源码并沿用自身设计 token。

## 如何开始
从 README 进入 `cult-ui.com/docs`，选择组件并检查依赖、预览和安装命令。可以使用组件 URL 安装，也可按文档配置 registry 命名空间。面向代理的资料另提供 `llms.txt` 和 Markdown 文档入口；只使用组件不需要部署关联 AI 平台。

## 一个使用示例
README 安装示例，未执行：先在试验分支查看 Shift Card 的交互，再按实际项目运行：

```shell
npx shadcn@latest add https://www.cult-ui.com/r/shift-card.json
```

预期把组件及所需依赖加入工程；检查新增文件、键盘操作和窄屏表现后，再接入自己的内容。安装成功不等于整页体验已经验收。

## 注意事项与相关项目
模型调用、鉴权、支付和抓取功能可能需要独立服务与 Key；模板宣传中的生产可用性需自行验证。许可证要按实际取用文件和产品核对。21st.dev 更偏社区 registry，cult/ui 更偏作者组件与配套模板。
