## 它是什么
MinerU 是文档解析工具，尝试保留标题、段落、表格、图片和公式结构，并把复杂版面转换成便于检索处理的文本与 JSON。它可识别扫描文档并启用 OCR，公式转 LaTeX、表格转 HTML；输出还有布局可视化，便于与原文对照。

## 适合什么场景
适合处理论文、双栏 PDF、扫描资料，或给后续搜索与抽取准备结构化输入。它解决内容解析，不等于精确还原页面设计。公式、手写文字和复杂表格仍可能识别错误，应在导入下游前抽查关键数据。

## 如何开始
可先用 README 链接的在线演示评估公开样本，敏感文件应选择合适的本地路径。完整本地安装示例为 `uv pip install -U "mineru[all]"`，需先按环境要求准备 Python 与 uv。GPU 与纯 CPU 后端不同，CPU 可明确选择 pipeline；macOS 不沿用上游 Docker 路线。

## 一个使用示例
官方命令改写，未执行：用一份有双栏文字与公式的公开 PDF，运行 `mineru -p sample.pdf -o output -b pipeline`。检查输出 Markdown 的段落顺序、公式和表格，再对照布局可视化定位错误。预期得到可处理内容，而不是保证每个字符和表格数字都正确；本次没有下载模型或执行解析。
