## 它是什么
ljianshu/Blog 将文章放在 GitHub Issues 中，README 按浏览器、JavaScript、ES6、CSS、网络与框架主题索引。内容面向初中级开发者，常从一个日常问题解释背后的机制，例如缓存、作用域、原型与模块化。它是作者文章集，不能仅下载 README 就获得全部正文。

## 适合什么场景
适合记得一篇“缓存机制”或“跨域”文章，想通过主题重新找到全文，或把几个相关概念串起来查阅。文章采用作者归纳，应结合发布日期、评论勘误及现代规范判断结论。

## 如何开始
无需安装。先在 README 找主题，再进入具体 issue，查看题目、正文、更新时间和讨论。资料只在外部博客时，优先跟随作者原始链接，不从其他转载推断最新内容。

## 一个使用示例
真实阅读入口示例，未执行网络实验：从浏览器相关分类进入 issue #23“深入理解浏览器的缓存机制”，先区分缓存存储位置与 HTTP 缓存策略，再在自己的测试页面查看请求头和响应。预期形成可以用网络面板验证的问题，不把“缓存层固定顺序”等文章概括当作所有浏览器的稳定实现。

## 注意事项与相关项目
缓存隔离、HTTP/2 Push 与浏览器存储机制已有版本演进，旧文适合帮助理解历史，不应直接作为当前配置依据。README 声明未经允许不得转载；本条仅作简要归纳并链接原文，没有复制整篇文章。
