## 它是什么
Anthropic Art 是一个用于生成编辑插画的非官方 Agent Skill。它把主题转成视觉隐喻，再约束背景、承载形、线条与留白，使图片呈现一致的手绘感。仓库明确声明它与 Anthropic 没有隶属、授权或合作关系。

它提供的是风格说明和参考资源，不是图像模型。真正生成图片仍依赖宿主的图像能力；安装 Skill 不等于获得额外的模型服务或商业授权。

## 适合什么场景
适合为博客头图、社交卡片、短视频封面或抽象 AI 概念配图。比如把“注意力保护”转成一只手保护火焰的画面，比要求模型绘制抽象概念名称更具体。它主要面向简洁二维插画，不以摄影、三维质感或写实产品图为目标。

## 如何开始
1. 先查看 examples 中的效果，判断是否符合文章或产品的视觉语境。
2. 阅读 skill 目录中的 SKILL.md 与风格参考。
3. 按宿主的安装方式导入该目录，不把整个仓库误当作一个 Skill 根目录。
4. 提供主题、用途、比例与是否允许文字，再检查产物是否符合要求。

## 一个使用示例
可参照 README 的显式调用方式提出：

```text
使用 $anthropic-art 生成一张“保护注意力”的方形插画。
用两只手保护一朵小火焰，背景覆盖整张图，不要文字。
```

预期是具有完整背景与明确视觉主体的插画，而不是透明图标。检查时看主题是否一眼可辨、边缘是否留有意外白框、文字是否被误生成。这里是对上游例子的中文整理，本站未调用图像模型。

## 注意事项与相关项目
风格参考不能被当成品牌授权。具体图像的使用权还取决于素材、生成服务和最终用途。仓库声称根据公开页面核验过配色等规律，但本站未独立复核其全部视觉研究，也不复制官方作品构图。
