## 它是什么
这个仓库是以提示词为中心的图像案例库，当前 README 汇集 462 个案例，按电商、广告、摄影、海报、角色与 UI 等用途分组。每个案例通常提供 Prompt、结果图和可用的作者或原始来源，便于观察构图、材质、文字与输出约束如何表达。

## 适合什么场景
适合已有具体视觉目标，需要参考一份完整提示词的结构，或想比较不同风格的描述方式。它不是模型权重或独立生图程序；API 自动化和可调用技能在 README 中明确属于相关的独立仓库。

## 如何开始
先在 Menu 选择用途分类，再进入接近目标的案例，查看是否有必需的输入图片。复制完整 Prompt 后替换品牌、文字与构图变量，准备自己的素材，在有权限使用的生图工具中试验。README 推荐 EvoLink 入口，但案例阅读本身不要求购买该服务。

## 一个使用示例
官方案例导航改写，未执行：进入 E-commerce Cases，查看“Miniature Diorama Skincare Advertisement”。它用大比例护肤品瓶与微缩人物构成产品广告。若改成自己的产品，应替换瓶身文字与产品特征，同时保留想参考的比例和灯光约束。预期是一个可试验的广告构图提示词，不能保证得到与示例图逐像素相同的结果。

## 注意事项与相关项目
README 的模型能力介绍和推广链接来自仓库维护方，不是本站对模型 API 的独立验证。复制提示词时要检查源作者、输入图和品牌资产；仓库许可不自动证明所有第三方示例可再分发。本站没有调用模型、比较供应商价格或验证全部 462 例。
