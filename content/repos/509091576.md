## 它是什么
sing-box 是通用代理平台。仓库提供核心实现，安装、客户端和配置说明主要放在官方文档站。需要分别理解流量从哪里进入、向哪里发出，以及什么规则决定路径；安装内核本身不会生成可用的上游节点。

## 适合什么场景
按域名、地址和网络条件组织流量，或为自己的网络工具接入代理内核。只想导入订阅的用户，应先看适合自己系统的客户端入口与版本支持。

## 如何开始
从官方 Installation 选择平台与发行版本，按同版本 Configuration 阅读 DNS、入站、出站和路由配置。默认仓库 README 位于 `testing` 分支，不能将该分支文档与任意旧稳定版混用。准备已获授权的上游连接信息，并用最小配置验证后再加规则。

## 一个使用示例
配置思路示例，未执行：先让一个本地代理入站只连接一个测试出站，确认请求可通，再添加一个指定域名的路由规则。分别检查连接、DNS 与规则命中，避免同时变更多层后无法判断原因。具体字段以安装版本文档为准。

## 注意事项与相关项目
配置可能含认证信息，不应放进公开仓库。更改系统路由或 TUN 会影响其他应用，应明确作用范围并保留恢复方式。Xray-core 是另一套内核；FlClash 使用 Mihomo，不能直接假定配置格式兼容。许可证还限制衍生项目对原名称和关联关系的使用。
