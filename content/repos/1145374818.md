## 它是什么
Thaw 把菜单栏项目分成常用、隐藏和始终隐藏区域，支持悬停、点击、手势或快捷键显示，也能从键盘搜索项目。配置可按显示器、Space 或 Focus 切换，并提供演示时收起项目的 Zen mode。

它关注的是菜单栏的可见性与布局，不是卸载后台应用；隐藏图标之后，应用仍按原有方式运行。

## 适合什么场景
菜单栏图标太多被刘海遮住；希望只在需要时显示低频工具；录屏或演示时暂时收起杂项；不同显示器需要不同布局。

## 如何开始
当前 README 要求 macOS 26 以上。可用 `brew install thaw` 或下载最新 DMG。首次启动授予辅助功能权限以移动项目，先安排常用与隐藏区，再设置一个容易记住的显示快捷键。屏幕录制权限是可选项，主要用于实时预览和壁纸取色。

## 注意事项与相关项目
某些项目无法捕获时会用应用图标代替，不代表后台工具失效。安装前核对系统版本，不能把旧菜单栏工具的兼容性沿用到当前版本。Atoll 更偏刘海快捷面板，两者解决的入口问题不同。
