## 它是什么
MuMuAINovel 用向导生成大纲和角色，再提供人物关系、章节编辑、润色、伏笔与写作风格管理。后端以 FastAPI、数据库和模型 SDK 组织内容，前端 React 提供可视化操作。

它主要调用外部模型 API，本地不要求大型生成模型 GPU；PostgreSQL 保存多用户项目，嵌入模型和容器仍占用本机资源。

## 适合什么场景
想在界面中持续管理一本小说；需要导入导出角色卡或项目；创作中反复调整世界观、章节和伏笔，而不是只做一次聊天续写。

## 如何开始
准备 Docker/Compose 和至少一个模型服务 Key，按 README 从 `backend/.env.example` 创建根 `.env`，填写数据库密码与模型配置。启动后使用本地账户或 LinuxDO 登录，选择“使用向导创建”，输入基本信息生成初始设定，再进入章节编辑。

## 一个使用示例
官方路径改写，未执行：建立一个奇幻故事项目，先确认世界规则和角色关系，再生成首章；若章节违背已定设定，修改相关内容后重新生成或润色。预期项目资料和章节可以持续管理，不必每轮粘贴整本背景。
