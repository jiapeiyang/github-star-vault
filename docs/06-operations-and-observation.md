## 观察什么

| 指标 | 如何记录 | 不计入的情况 |
|---|---|---|
| 用途找回 | 真实输入词、筛选条件、目标仓库、是否找到及主要阻力 | 自动冻结用例通过不算真实使用成功率 |
| 解读帮助 | 是否看懂用途、能否找到入口、哪个步骤仍不明确 | 打开详情不等于实际使用过项目 |
| 示例质量 | 示例是否与上游一致；执行时记录版本、环境、结果和失败 | 公开资料归纳不算实测 |
| 历史回顾 | 实际重访的仓库与触发原因 | 随机按钮曝光不计重访 |
| 资料维护成本 | 一次复核花费的实际时间、变更点与障碍 | 检查 SHA 相同不算全面重读 |
| 加载和交互 | 设备、网络、路由、可见问题及可重复步骤 | 本地模拟不冒充真机或用户流量 |

网站不采集访问行为。使用者可先本地记录，授权后再更新观察 Issue；不添加分析 SDK 或数据库。

```markdown
## YYYY-MM-DD · 实际使用记录

- 版本/页面：
- 设备与网络：
- 任务与目标仓库：
- 搜索词及筛选条件：
- 是否找到、哪些信息有帮助：
- 解读或示例问题：
- 实际复核耗时（若有）：
- 可复现阻力及下一步：
```

## 本地维护

```shell
python3 scripts/verify_data.py
python3 scripts/generate_readme.py
python3 -m unittest discover -s tests
npm --prefix app test
npm --prefix app run test:sites
GITHUB_PAGES=true npm --prefix app run build
```

来源检查和差异报告见 [资料维护指南](07-curation-guide.md)。同步失败时先看对应日志并修复明确原因，不加入无条件重试。只有实际记录表明用途检索、内容整理或 Git 维护反复阻断任务时，才评估更复杂能力。

## 我没有防什么

不自动记录行为，不保证定时任务准点，不为临时 API 限流增加队列或备用调度器；不恢复个人学习字段，不加入数据库、在线写入或自动分类。未在真实手机和运营商网络完成的检查应继续标为未覆盖。
