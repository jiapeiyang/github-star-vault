## 它是什么
这是主要使用 JavaScript 的 LeetCode 解答目录，README 以题号、标题、源码、解释和难度组成表格。许多行保留题目信息但源码为空，已有解答则链接到 Algorithms 中的文件，有些同时提供 Python。它可用来找早期 JavaScript 解题写法，不能理解为表格每一题都已经有答案。

## 适合什么场景
适合按题号查函数实现，或比较同一道题的不同语言表达。想获取全量现代题库、最新接口或统一测试框架时，应另行查平台和代码目录。

## 如何开始
先在表格搜索题名或题号，再检查 Source Code 一栏是否有链接；没有链接就只是收录索引。进入源码后核对输入输出签名，返回原题确认约束。Explanation 列和源码列分开，存在源码不意味着也有完整中文解释。
