## 它是什么
vscode-leetcode 将题目列表、题干、解题文件与提交结果放到 VS Code。用户选择站点和语言后打开题目，在熟悉的编辑器编写答案，再通过 Code Lens 发起测试或提交。题目执行与账号记录依赖 LeetCode 服务，扩展并不是本地题目判题引擎。

## 适合什么场景
适合已经有 LeetCode 账号，希望把代码文件放在自己的工作目录中管理，或减少浏览器与编辑器切换的人。阅读题目、运行自定义测试、提交答案和收藏题目是不同动作，后两者会改变远端账号状态。

## 如何开始
按 README 的 Marketplace 入口安装，确认 VS Code 与 Node 环境满足所用版本要求；Node 路径可通过 leetcode.nodePath 配置。先选择 leetcode.com 或 leetcode.cn，再登录，两个站点账号不共享。设置 leetcode.workspaceFolder 和默认语言，打开一道题预览题干。
