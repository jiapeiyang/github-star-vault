## 它是什么
Trellis 在项目中建立 `.trellis/spec/`、tasks 和 workspace，把规范、当前需求和历史记录分别管理。代理按 Plan、Implement、Verify、Finish 进入任务，相关上下文按阶段注入，避免每次会话重新解释全部约定。

它是围绕已有编码代理的项目层，支持多种客户端；共享规范可审查，个人日志按开发者分开，不等于替换 Git 或模型本身。

## 适合什么场景
团队需要稳定工程标准；长期项目经常跨会话续作；单一 AGENTS.md 已塞入过多任务细节；希望实现与检查读取不同但相关的上下文。

## 如何开始
准备 Node.js 18 以上与 Python 3.9 以上，安装 `@mindfoldhq/trellis`，在项目执行 `trellis init -u your-name`，只选择实际使用的平台。先从现有代码整理少量关键规范，再描述任务形成 PRD，核对计划后进入实现。

## 注意事项与相关项目
生成规范需要人工核对，错误规则会被持续注入。README 表示 Implement 阶段不自动 commit，但其他收尾动作仍需看具体版本和授权。CCG 偏多模型桥接，Trellis 偏仓库内的规范与任务记忆。
