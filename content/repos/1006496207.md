## 它是什么
SuperClaude 是 Claude Code 的社区配置框架，通过行为指令与组件组合，提供研究、构思、实现、测试和项目管理等命令。它不替换 Claude Code，也不是 Anthropic 官方项目。当前 README 描述 v4.3.0，以 /sc:* 斜杠命令为主要入口。

## 适合什么场景
适合希望统一一组任务命令、减少重复解释流程的 Claude Code 用户。已有团队规则时，可比较哪些命令真正补足缺口，再选择所需部分；单纯安装全部命令不代表项目已经获得对应的测试和发布能力。

## 如何开始
官方当前路线是 `pipx install superclaude`，随后运行 `superclaude install` 安装命令。可用 `superclaude install --list` 与 `superclaude doctor` 检查安装，再重启 Claude Code。MCP 是可选部分，先用 `superclaude mcp --list` 看需要的服务，不要因为安装框架就引入全部外部依赖。

## 一个使用示例
官方命令说明改写，未执行：对于新增表单功能，先用 `/sc:brainstorm` 明确字段和错误状态，再用 `/sc:implement` 按项目现有结构实现，最后 `/sc:test` 检查相关路径。预期各命令约束任务方式，真正验证仍需测试输出和浏览器结果；本次未在项目中安装框架。

## 注意事项与相关项目
README 明确说 v5 的 TypeScript 插件系统仍在开发，示意性的 /plugin 安装命令不能当成 v4 可用步骤。模型与 MCP 的性能提升是上游主张，须在自己的任务上比较。相关 GSD Core 和 BMAD 更强调阶段管理，采用时避免叠加多套相互矛盾的全局规则。
