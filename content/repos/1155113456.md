## 它是什么
yichen-skills 是一组按任务拆分的技能，涉及 X Articles 草稿、微信和企业微信授权数据、公众号导出、网页研究、社交收藏导出、音视频转写与记忆资料库。各目录的能力、依赖和成熟度不同，不是一个安装后即可统一运行的平台。

## 适合什么场景
已经有明确的资料整理或内容工作流，愿意逐项核对输入范围与权限。例如把自己的一篇 Markdown 文章整理成待审阅草稿，或处理用户显式提供的离线数据快照。

## 如何开始
先从任务列表选一个技能，阅读该目录 README 与 SKILL.md，再安装所需依赖。总说明要求 Python 3.9+，部分流程还要 Playwright、浏览器登录、ffmpeg 或外部服务；不要一次为全部技能授予本机数据访问。

## 一个使用示例
官方工作流整理，未执行：选 X Articles 草稿上传技能，使用自己的 Markdown 与已登录浏览器，生成一个新草稿并人工核对格式。该流程的目标是草稿，不应顺带发布；是否触达账号和上传文件应在执行前明确。

## 注意事项与相关项目
上游声明仅限个人学习和非商业个人使用，商业用途包括公司内部部署需事先书面授权。聊天、数据库和收藏导出可能含私密内容；实验性读取器的样例测试不证明所有真实版本兼容。EverOS 是独立记忆运行时，小红书 MCP 是另一套平台自动化服务。
