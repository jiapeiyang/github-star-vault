## 它是什么
git-tips 将常用 Git 操作按“想完成什么”组织，例如查看差异、找冲突、切换分支、回看历史、stash 与恢复文件。每项给出短命令，适合记不住参数时查找。README 先区分工作区、暂存区、本地与远端，帮助理解命令影响范围。

## 适合什么场景
适合快速找一个只读检查命令，或先弄清改动位于哪个 Git 状态。撤销、删除和强推等条目会影响历史或文件，查到命令后仍要根据当前状态判断，不能把所有技巧当作可直接执行的快捷键。

## 如何开始
用页面搜索找到任务标题，先读周围说明，再在测试仓库确认行为。README 的测试环境为 Git 2.7.4 Apple Git，当前 Git 可用帮助文档核对参数。实际操作前先确认当前仓库和分支，并看哪些改动已经暂存或提交。

## 一个使用示例
官方命令示例，未执行：提交前用 `git diff` 查看工作区与暂存区差异，再用 `git diff --cached` 查看准备提交的内容；遇到合并冲突可用 `git diff --name-only --diff-filter=U` 列出未解决文件。预期清楚下一步要处理哪一层改动，这些查看命令本身不会提交或推送。

## 注意事项与相关项目
reset、clean、删除分支和强制推送等操作后果不同，尤其不能把“恢复到远端状态”理解为保留全部未提交内容。仓库示例中的 master、远端名和 commit ID 是占位上下文，采用前要换成真实目标。本站未运行破坏性 Git 操作。
