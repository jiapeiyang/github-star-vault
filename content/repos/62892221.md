## 它是什么
react-latest-framework 是在 create-react-app 基础上改造的 React 技术栈模板，整合 Redux、React Router、Immutable、Ant Design 和异步路由。README 明确版本为 React 16.8.6、Webpack 4.28.4，部分组件用 Hooks，其他仍保留 class 与 Connect 写法，方便对照。

## 适合什么场景
适合回顾 React 16 时代的状态管理、路由与构建组合，或维护相似旧工程时查看组织方式。名称中的 latest 是历史命名，不能作为今天新项目技术选型的推荐依据。

## 如何开始
先阅读 README 和依赖版本，选择隔离目录取得代码，再按原工程依赖安装。官方脚本为 npm start 运行 demo、npm run build 构建、npm run serve 预览。先确认旧工具链与 Node 兼容，不为运行示例直接升级所有包，否则会失去版本参照。

## 一个使用示例
官方说明改写，未执行：打开 App.js、BaseLayout/index.js 和 Login.js，观察 Hooks 写法与其他 class/Connect 组件如何读取状态和接入路由。若运行 demo，只在本地使用 README 提供的演示登录，检查登录页面如何切换到主布局。预期理解模板结构，不把演示账号当作真实认证实现。

## 注意事项与相关项目
README 给出的是客户端渲染 demo，生产认证、权限和后端服务需要单独实现。react-loadable、happypack 等历史依赖不能无评估地搬入新项目。本站未安装旧依赖、运行构建或验证其当前漏洞状况。
