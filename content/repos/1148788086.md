## 它是什么
mattpocock/skills 把工程中常见的沟通与实现问题拆成较小的技能，强调按需组合和可修改。它包括需求追问、结合文档澄清方案、领域术语统一等方法，帮助用户明确代理应解决的问题。不同于完整阶段框架，每个技能可以用于一项局部工程活动。

## 适合什么场景
适合需求表达模糊、团队术语经常解释不清，或希望保留自身开发节奏但补充一两种方法的任务。比如使用 grill-with-docs 前先提供具体代码与产品约束，产出应是能推进实现的决定，而不是为了提问而无限延长讨论。

## 如何开始
Claude Code 的 README 安装入口为 `/plugin install mattpocock-skills`；其他代理可使用 `npx skills@latest add mattpocock/skills`，选择需要的技能。两种安装方式分别是管理式插件和可编辑文件，不建议重复安装。初次在仓库运行 `/setup-matt-pocock-skills`，配置 issue 来源、标签和文档目录，再调用具体技能。

## 注意事项与相关项目
安装器里的宿主选择、插件自动更新与文件式手工更新是不同维护方式。README 的“使用每次改动”是作者方法建议，实际应按任务大小选择。不要把技能对外部 issue tracker 的操作权限，误认为安装插件就已授予；本次未安装或发出外部任务。
