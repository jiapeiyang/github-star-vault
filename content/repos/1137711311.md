## 它是什么
Codewhale 是开源终端编码代理，能够读取仓库、编辑文件、运行命令并检查结果。模型通过云服务或 Ollama、vLLM、SGLang 等本地入口连接，因此终端界面与模型提供商是分开的选择。

README 提供只读 Plan，以及 Ask、Auto-Review、Full Access 等权限模式；会话、目标和恢复功能服务于较长任务。它不仅生成代码片段，也可能实际改变工作区，使用前需要明确允许的操作范围。

## 适合什么场景
在终端修复失败测试、跨文件维护项目；希望比较多个模型但保留同一代理交互；使用自有推理端点进行仓库协作。

## 如何开始
从官方 Releases 或 README 安装说明获取匹配平台的程序。首次启动选择模型提供商或离线方式，进入项目目录后先用只读任务熟悉输出；通过 `/model` 更换提供商和模型。包管理器安装与直接安装的更新路径不同，按 `docs/INSTALL.md` 处理 PATH 与升级。

## 一个使用示例
官方命令摘录，未执行：

```shell
codewhale exec "fix the failing tests and explain what changed"
```

输入是当前仓库及已有失败测试，预期代理调查、修改并解释验证结果。实际使用时应补充禁止触碰的外部服务与目标测试；命令返回不等于测试一定通过。

## 注意事项与相关项目
模型端点的权限、上下文与工具调用能力会影响任务表现。`/undo` 和快照恢复应看具体恢复范围，不能假设能撤回已发生的外部动作。与 Herdr 搭配时，前者处理代码任务，后者组织会话。
