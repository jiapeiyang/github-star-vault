## 它是什么
XERJ 是本地优先的搜索引擎，支持代码、文档、日志、JSONL、CSV 和 PDF 等输入，并提供 Elasticsearch 兼容 API 与 MCP。它把文件导入、索引和搜索服务放在一个 Rust 二进制中；接口兼容范围仍需对照项目文档。

## 适合什么场景
为个人项目资料建立可供助手检索的索引，或用现有搜索客户端查询本地内容。适合先用一个小目录验证结果，再决定是否增加向量能力和更大的语料。

## 如何开始
从发行包或检查过的安装入口取得对应平台程序。先启动搜索节点，再运行 `xerj autoindex` 导入目录；MCP 的 `xerj mcp` 只是连接节点的 stdio 服务，不会自动启动节点。认证开启时导入工具也需要明确传入 API Key。

## 一个使用示例
README 查询方式整理，未执行：在已运行且已导入示例文档的本机节点查询 `http://localhost:9200/_cat/indices`，再用 `_search` 搜索一个已知词，核对命中文档与来源。若开启认证，应按文档传凭据，不能为了消除 401 直接关闭共享节点鉴权。

## 注意事项与相关项目
`--insecure` 关闭 TLS 和鉴权，上游仅将其作为本机开发边界，不能照搬到公网或共享主机。索引内容和 MCP 调用会扩大资料可访问范围。性能对比来自作者，本站未复测；EverOS 侧重记忆生命周期，MindFS 侧重工作站交互。
