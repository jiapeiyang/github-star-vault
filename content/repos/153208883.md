## 它是什么
33-js-concepts 中文版围绕调用栈、类型、作用域、闭包、Promise、事件循环、原型、函数式编程等概念收集文章与视频。它参考英文原项目并调整部分分类，强调先看介绍再看深入材料，用多个来源帮助理解同一主题。

## 适合什么场景
适合知道某个概念名但不知道从哪篇解释开始，或想把分散的 JavaScript 基础连成关系。作者也说明它不是必备清单；可按当前问题选择相关概念，不必按数字顺序阅读所有资源。

## 如何开始
无需安装。先从目录跳到概念，再区分入门文章、深入文章与视频。遇到多篇说法不同，优先查规范或 MDN，再用文章例子辅助理解。需要英文原始上下文时，可通过 README 的 leonardomso/33-js-concepts 链接回查。
