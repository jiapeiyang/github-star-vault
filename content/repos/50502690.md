## 它是什么
sequelize-typescript 在 Sequelize v6 之上提供基于类与装饰器的模型定义方式。@Table 标记模型，@Column 标记数据库列，关联、索引、作用域和钩子也有对应装饰器。它保留 Sequelize 的数据库操作能力，同时让模型声明更贴近 TypeScript 类；并不是一个与 Sequelize 无关的新数据库。

## 适合什么场景
适合已采用 Sequelize v6、希望用 TypeScript 集中表达模型结构的项目。使用前需要了解数据库方言、模型与实际表之间的关系；只添加装饰器不会自动完成生产数据库迁移。

## 如何开始
按 README 安装 sequelize、reflect-metadata 与 sequelize-typescript，并准备数据库所需驱动。tsconfig 需启用 experimentalDecorators、emitDecoratorMetadata，target 为 es6 或更新。使用本库的 Sequelize 与 Model，并通过 models 配置或 addModels 注册模型。

## 一个使用示例
官方模型示例节选，未执行：
```ts
import { Table, Column, Model } from 'sequelize-typescript';
@Table
class Person extends Model {
  @Column
  name: string;
}
```
目标是声明一个带 name 列的模型。之后还需在 Sequelize 实例中注册 Person 并连接数据库；该片段没有实际建表或写数据，严格属性初始化等编译选项需按项目处理。

## 注意事项与相关项目
README 明确假定 Sequelize 6，不能直接套入未来主版本的装饰器契约。以 .ts 路径寻找模型与编译后 .js 部署路径可能不同，优先确认运行时真正加载到的模型。装饰器元数据推断有类型边界，特殊列应显式指定 DataType；数据库权限和迁移仍属于应用职责。
