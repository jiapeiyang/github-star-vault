## 它是什么
Flux 是围绕单向数据流组织 React 应用的一种架构模式，这个仓库提供 Dispatcher 与部分辅助类。典型职责包括 Action 表达变化、Dispatcher 分发、Store 管理状态、View 展示结果。README 强调 Flux 更像模式而非完整框架，并明确说明项目已归档、不会再变更。

## 适合什么场景
适合回顾 React 状态管理的历史，或阅读采用 Dispatcher 与 Store 的旧项目。新项目应按现有需求评估维护中的方案；README 列出的替代项目也需要另行核实当前状态，不能自动视为推荐清单。

## 如何开始
先读 examples/flux-concepts 与概念文档，理解单向流，再查看 flux-todomvc、flux-chat 等示例。只需 Dispatcher 时上游安装入口为 npm install flux，并用 require('flux').Dispatcher 获取。若使用 Flux Utils，应阅读其 Store 与容器约束。

## 注意事项与相关项目
辅助类不是覆盖所有场景的框架，异步、业务组织与视图接入还需应用自己设计。源码构建说明使用 Gulp，示例中也有 Flow 类型语法，不能直接当作普通 JavaScript 运行。可与 flux-comparison 对照当时多种实现，但它们共同属于需要保留历史语境的资料。
