## 它是什么
FED 是一个纯静态前端导航站，同时提供可导入的站点数据包。条目包含名称、网址、说明、图标和标签，页面支持分类、关键词搜索及关键词点击。它把分散的前端文档、社区与工具入口整理为可搜索目录，适合作为开发工作中的网址索引。

## 适合什么场景
适合找回某个前端资源站、搭建小型团队导航页，或参考如何把 JSON 数据变成静态目录。它不会代理所收录网站，也不保证这些外站持续可用。

## 如何开始
浏览时使用分类或关键词定位条目，再前往原网站。需要数据时按 README 安装 @wcj/fed 并导入默认数据。若维护自己的目录，先理解根目录 data.json 的字段，再新增名字、网址、描述和标签；源码开发说明另外提供 build、watch 和 server 脚本。

## 一个使用示例
官方数据用法改写，未执行：目标是在自己的工具页列出前端资源。
```js
import data from '@wcj/fed';
console.log(data.map(item => item.name));
```
预期取得包内条目名称；上游给出的 MDN 样例还包含 url、des 与 tags，可据此显示链接和说明。这里只演示读取数据，未搭建导航页面。

## 注意事项与相关项目
README 的导入数据示例使用 icon，而贡献说明的示例出现 ico，真实接入时应检查所用包版本和 data.json，不能把两种写法当作已确认相同。部分条目说明含旧技术如 Firefox OS，目录的“收录”不等于当前推荐。与 Star Vault 相比，这里主要整理网址，不记录个人 Star 时间。
