## 它是什么
diagram-design 是面向编码代理的图示设计技能，用自包含 HTML 与 SVG 表达架构、流程、时序等内容。它按语义与图型加载参考，还提供品牌导入、命名样式配置、可选动效及 PNG／SVG 导出。

## 适合什么场景
需要给技术文档、方案说明或演示制作可阅读、可修改的图示，且希望符合已有品牌。它能协助组织视觉关系，但架构事实仍应来自真实代码或明确需求。

## 如何开始
按 README 使用 `npx skills add cathrynlavery/diagram-design`，选择实际宿主。先浏览画廊，再提供参与者、关系、读者与交付格式。首次在品牌项目中使用时，需要导入样式、手填设计值或明确接受默认样式；不要把默认模板冒充已经匹配品牌。

## 注意事项与相关项目
导入 Mermaid、draw.io 或 Excalidraw 不等于证明原图语义正确；导出和浏览器验证也有环境前提。Anatomy 偏向带具体机械结构的等距图；DESIGN.md 是设计规范格式，不能把它们的配置文件直接视作同一种标准。
