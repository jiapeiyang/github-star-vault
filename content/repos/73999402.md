## 它是什么
Fe-Interview-questions 将前端问题拆为 readme/1.md 等小文件，并收集 React、Vue、数组操作、入门路线和开发资源。它更像主题索引加作者整理的问答，部分目录来自其他开源项目，README 保留了原作者和来源入口。

## 适合什么场景
适合回忆过去常见的 CSS、跨域和 JavaScript 问题，或从一个主题找到其他整理项目。内容跨度大、年代不同，适合查线索，再对照当前规范，而不是整库当作统一版本的标准答案。

## 如何开始
直接打开 readme 目录选择篇章，无需安装。第一篇包含定位、跨域与数据格式等问题；看到具体方案时记录浏览器、协议与使用前提。涉及转载资源时优先打开原仓库，确认是否已有更新或勘误。

## 一个使用示例
真实章节导航示例，未执行：在 readme/1.md 找到“如何解决跨域问题”，比较 JSONP、CORS 与 postMessage 各自解决的数据请求或页面通信场景，再查当前浏览器文档。预期知道“跨域”不是一种统一问题，不能把多个历史技巧混用为同一个方案。

## 注意事项与相关项目
第一篇仍含 document.domain、window.name、Flash 等历史路径，以及过度简化的 JSON/XML 性能断言，采用前必须重新核查。README 链到作者另一个 JavaScript 题库，可作为更新线索；本次只核对资料结构与样例，不把其中每条答案都认证为正确。
