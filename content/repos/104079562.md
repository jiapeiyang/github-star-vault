## 它是什么
ieaseMusic 是基于 Electron、React、MobX 和 JSS 的非官方网易云音乐桌面应用。README 展示首页、播放列表、歌词、评论和播放器等界面，并说明 API 由 NeteaseCloudMusicApi 提供。它把网页技术放进桌面壳，增加键盘操作、桌面通知与主题等桌面体验。

## 适合什么场景
适合研究音乐播放器界面、Electron 与应用状态管理的协作，或回顾过去的跨平台桌面客户端。单纯想稳定听歌时，应先确认当前发行版本与服务可用性，不能把历史截图视为今天仍能正常登录或播放。

## 如何开始
普通体验从 Releases 选择平台包；README 的下载示例以 v1.3.4 为主，列有 Mac、Linux 的 deb/rpm/AppImage 等形式。源码开发则先初始化并更新 submodule，再 npm install、npm run dev。实际 Node/Electron 兼容范围应以锁定版本与包配置为准。

## 一个使用示例
官方快捷键说明改写，未执行：已有可播放曲目进入队列时，Space 用于暂停或播放，左右方向键切换曲目，Cmd+P 打开播放列表。预期是减少鼠标操作；本条未安装应用，也未登录账号、请求曲库或验证音频播放。

## 注意事项与相关项目
README 保留旧 Homebrew 命令、Alfred 3 入口和历史网络配置，不能照抄旧 IP 修改 hosts 来判断可用性。音乐接口与平台授权决定可播放范围，应用开源不等于获得曲库授权。若只想对照 Vue Web App，可查看 NeteaseCloudWebApp；两者前端架构和桌面能力不同。
