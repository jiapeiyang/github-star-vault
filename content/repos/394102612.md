## 它是什么
fmhy/edit 是 FMHY 资源目录的编辑与贡献入口。README 指向正式网站、更新记录、Markdown 与 JSON 备份，并解释目录标记和社区推荐。
上游说明网站和 GitHub 不托管目录所指向的文件；这里主要组织外部资源，而不是提供一种本地开发运行时。

## 适合什么场景
找回互联网资源目录；理解条目的来源和推荐标记；向社区提出链接修正或补充建议。

## 如何开始
从 README 的 Wiki 网站进入浏览，需要了解变化时看 News & Monthly Updates。准备贡献前阅读贡献指南，并先检索单页索引避免重复；目录中的资源仍需到原站核对。

## 一个使用示例
官方导航流程归纳，未执行：找到一个资源名称，在单页索引中搜索是否已收录，核对原始地址，再整理修改理由。预期得到一份待提交建议；本次没有向社区发送或发布内容。

## 注意事项与相关项目
第三方索引、章节跳转和社区推荐是不同标记，推荐不等于安全、版权或长期可用保证。本文没有逐条审计外链、下载资源或验证 JSON API。
