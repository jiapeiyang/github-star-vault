## 它是什么
OpenDesign 是面向 macOS 和 Windows 的本地优先设计应用。它连接编码代理或模型端点，以需求说明、设计方向、生成文件、评审和导出构成工作流程。设计系统用 DESIGN.md 等文件描述，Studio 同时呈现对话、文件和预览，支持原型、演示、文档、图片与 HyperFrames 动画等产物。

## 适合什么场景
适合希望在一个界面中组织网页原型、品牌样式和演示文件的人，尤其是已有编码代理但缺少设计预览工作流时。它输出可运行文件与导出物，并不意味着具有传统设计画布全部编辑能力；最终所需格式应在开始前明确。

## 如何开始
从官方 Download 或 Releases 获取平台版本，按支持表连接已安装的代理 CLI，或配置自己的兼容端点。Home 中选择产物类型、工作目录、模型和设计系统，写明内容要求；需要复用流程时到 Plugins 选择技能。随后在 Studio 检查生成文件与预览，再继续细化。

## 一个使用示例
说明性示例，未执行：为产品做一份演示，先选择 Deck，提供页数、真实文案和品牌参考，在设计系统中核对字体与颜色，再在 Studio 检查缩略图、讲者备注和正文。满意后选择适合的 HTML、PDF 或 PPTX 导出。预期是可检查的文件；导出后仍需在目标阅读器复核排版。

## 注意事项与相关项目
“支持某代理”有 MCP/CLI 集成与原生 runtime 两种方式，不能假定每项能力相同。生图、视频或云模型可能需要额外服务和费用；本地优先并不代表模型请求完全离线。README 的供应商促销与模型广告随时会变，本条不以其作为长期购买建议。
