## 它是什么
claude-code-best-practice 把 Claude Code 的原语与实现入口并排整理，包含子代理、命令、技能、hooks、MCP、插件和设置，还有社区技巧、报告与工作流示例。

README 建议先把它当参考课程阅读，而不是一次安装的万能技能。文档链接帮助理解概念，`.claude/` 和 implementation 目录则提供可检查的配置例子。

## 适合什么场景
分不清 command、skill 和 agent 应如何分工；想设计项目自己的工作流；检查 CLAUDE.md 是否过长或缺少真实工程约定。

## 如何开始
从 CONCEPTS 选择一个概念，同时读对应 best-practice 与 implementation。需要完整例子时查 weather-orchestrator 的 command → agent → skill 流程，再根据自己任务改写。hooks 实现已有独立仓库，不能假设本仓库包含所有声音通知代码。

## 一个使用示例
官方导航改写，未执行：阅读天气编排示例，记录主命令怎样分派查询、子代理怎样调用技能、最终怎样汇总，再用同一结构设计只读的仓库信息检查。预期复用分工原则，不把天气任务的工具与权限直接复制进代码审查。

## 注意事项与相关项目
社区技巧与官方契约需分开核对，版本更新后命令路径可能变化。不要整包覆盖现有用户配置。claude-plugins-official 主要用于发现和安装插件，本项目主要帮助理解如何组织这些能力。
