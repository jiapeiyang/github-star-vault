## 它是什么
claude-plugins-official 是插件 Marketplace 的目录仓库。`plugins/` 放内部维护插件，`external_plugins/` 收录合作方和社区插件；每个插件可以组合命令、agents、skills 和 MCP 配置。

它提供发现与分发入口，而不是把所有插件功能打包为同一个工具。目录收录也不等于所有外部组件由 Anthropic 编写或持续保证安全可用。

## 适合什么场景
寻找 Claude Code 的现成扩展；检查插件实际带入哪些文件和 MCP 服务；参考 example-plugin 理解插件结构。

## 如何开始
在 Claude Code 的 `/plugin > Discover` 浏览，先看目标插件 README、来源和权限，再安装具体插件。命令格式为 `/plugin install {plugin-name}@claude-plugins-official`，其中名称必须来自实际条目，不能直接使用展示标题。

## 一个使用示例
官方流程改写，未安装：在目录中找到某个开发工具插件，先检查 `.claude-plugin/plugin.json` 及可选 `.mcp.json`，确认它只提供所需功能，再回到客户端安装并检查可用命令。预期能说明新增了哪些能力，而不是一次启用整个目录。

## 注意事项与相关项目
插件更新可能改变所包含软件和服务，应检查新版本。Marketplace 的 name 是稳定标识，展示名可单独改变。anthropics/skills 主要分发技能内容，本仓库分发可包含更多组件的插件。
