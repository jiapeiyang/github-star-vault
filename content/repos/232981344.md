## 它是什么
Big-React 是从零实现 React v18 核心能力的教学仓库，使用 pnpm monorepo，按标签记录 JSX、DOM 插入删除、Fiber、事件和 Lane 等机制加入的过程。它帮助理解框架内部各阶段如何协作，并不是完整 React 的兼容替代品。

## 适合什么场景
适合读官方源码时觉得跨度过大，想先观察精简实现，或通过相邻标签比较某功能如何落地的人。README 的 TODO 区分了已实现与未实现需求，可以用来选择阅读边界，不必假定名字相似就支持所有官方 API。

## 如何开始
先从 README 标签索引选一个机制；v1 涉及工程与 Fiber 基础，v6 加入事件，v8 涉及 Lane。阅读 packages 与 demos，再查看根 package.json 的脚本。当前主分支脚本提供 `pnpm build:dev` 构建开发包、`pnpm demo` 打开性能示例；所选历史标签仍要核对自己的 package.json。安装依赖后先构建再看 demo，不混用不同标签的源码。
