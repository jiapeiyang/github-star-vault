## 内容维护

- 新建导读必须引用真实已生成期刊，`lead_repo_id` 对应主读；`connections` 最多两个，只引用本期同主题仓库。
- `sources`、`reviewed_at` 与 Markdown 正文随人工核查更新；不能编造执行结果或个人学习状态。
- 本地顺序：`python3 scripts/generate_weekly.py` → `python3 scripts/verify_data.py` → 生产构建 → `python3 scripts/verify_weekly_build.py`。普通构建只消费档案，不偷偷生成新期。
- 不新增导读不会阻塞出刊；错误的已有导读会被源数据校验拒绝，避免发布错误关系。
