## 它是什么
bb-browser 是面向代理的浏览器命令行工具，既可打开页面、读可访问性树、点击和填表，也可调用社区维护的网站适配器，返回结构化数据。它让 CLI 经本地 daemon 和 CDP 连接实际浏览器，适配器在页面上下文中调用接口，因此能够沿用该浏览器已有的登录状态。

## 适合什么场景
查询已登录网站的内容、把重复网页操作接入命令行、给支持 MCP 的编码助手提供浏览器能力时，可以考虑它。平台适配器适合已知查询；缺少适配器时仍可使用普通页面操作。它的可用范围由当前网站、登录权限和适配器实际实现决定。

## 如何开始
README 要求 Node.js 18+，安装入口是 `npm install -g bb-browser`。按上游连接方式准备真实浏览器后，先运行 `bb-browser site update` 获取适配器，再用 `bb-browser site info zhihu/hot` 核对该命令的说明。Claude Code 或 Cursor 可将 `npx -y bb-browser --mcp` 配置为 stdio MCP；OpenClaw 另有 `--openclaw` 路径，无需扩展或 daemon。

## 一个使用示例
目标是读取知乎热榜。官方命令 `bb-browser site zhihu/hot` 使用浏览器执行对应适配器；希望后续处理结构化输出时可添加 `--json`。若站点没有所需动作，可先 `bb-browser open https://example.com`，再 `bb-browser snapshot -i`，根据本次快照中的元素引用继续操作。这是官方命令的使用说明，未执行；元素编号应以当前页面为准。

## 注意事项与相关项目
README 对反爬的宣传不等于网站保证允许或永远兼容。工具继承真实账号权限，点击、发布和下载都可能影响该账号；先核对动作再交给代理。daemon 默认监听 127.0.0.1:19824，无远程需求不应照抄全网监听示例。社区适配器来自独立的 bb-sites，网站更新后可能需要重新核查。
