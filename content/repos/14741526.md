## 它是什么
node-xlsx-writestream 是流式 XLSX 写入库，npm 包名为 xlsx-writestream。它可把对象数组转为工作表，也允许逐行 addRow、读取输出流，最后 finalize 结束文件。源码采用 Literate CoffeeScript，README 将其说明为从 node-xls-writer 派生的流式实现，适合观察早期 Node 的表格导出方式。

## 适合什么场景
适合按行产生数据的导出任务，或维护旧系统的 XLSX 下载接口。它是写入器，不能据此假定可以读取任意现有工作簿或保留复杂样式。

## 如何开始
按上游安装 xlsx-writestream。简单数据可调用 xlsx.write；增量导出则 new XLSXWriter，取得 getReadStream 并接到目标，按顺序 addRow，最后 finalize。对象的键用作表头，全部字段名应在第一行出现。列属性应在写任何行之前定义。

官方 API 改写，未执行：准备两行 {Name: 'Bob', Location: 'Sweden'} 与 {Name: 'Alice', Location: 'France'}，通过 write 输出 mySpreadsheet.xlsx。预期工作表第一行为 Name、Location，后续各行对应记录；文件是否能被目标 Excel 版本正常打开，还需要实际回读。

## 注意事项与相关项目
缺少 finalize 会使读取流不能正常结束。README 的示例先加行后定义列，但 Notes 又明确要求先定义列以避免部分 Excel 崩溃，实际应遵循该限制。性能数据来自 2013 年 MacBook，不能作为当前数据量的吞吐保证。本文未写文件、跑基准或验证内存占用。
