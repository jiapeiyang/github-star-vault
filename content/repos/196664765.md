## 它是什么
pwstrick/daily 是前端问题索引和资料集合，按 HTML、CSS、JavaScript、网络、工具、安全、性能、Node、TypeScript、Vue 等主题划分。题目清单链接到具体 issue，文章按年份与专题归档，适合围绕一个知识点反复查阅相关材料。

## 适合什么场景
适合想找以前见过的面试问题，或需要把一个宽泛主题拆成可回答的小问题的人。它也收录算法思路、书籍目录和专业英语资料，各部分用途不同，不需要为了查一道题顺序读完整仓库。

## 如何开始
直接从 README 进入 interview 下的领域文件，无需运行代码。先看题目文字和链接，再打开对应 issue 阅读讨论。若问题涉及协议或浏览器实现，记录其前提并对照当前规范；相关深入文章可以从 article 的专题入口继续查找。

## 一个使用示例
真实目录导航示例，未执行代码：进入 interview/network.md，找到“Web 缓存机制”链接到 issue #596，再对照相邻的请求首部、状态码与页面加载步骤题目。预期能把缓存问题分成请求条件、响应与浏览器行为，形成进一步验证的路径；题目列表本身不包含全部答案。

## 注意事项与相关项目
题量数字是 README 快照，新增删除后可能变化。社区答案、作者归纳与外部文章的权威性不同，技术结论应回到原始证据。涉及 GET/POST、缓存和安全的简化问答尤其要补充具体上下文，不能把一句口诀当作协议完整规则。
