## 它是什么
ineo6/hosts 通过 hosts 域名映射改善部分网络下 GitHub 页面与图片访问，提供远程列表，也提供本地测试 IP 后输出列表的 hosts-server。它影响的是域名解析，不是通用代理，也不能解决所有连接、权限或站点故障。

## 适合什么场景
适合已经确认问题与域名解析有关，想在受控环境比较不同解析结果的人。若故障来自账号、TLS、代理或 GitHub 自身，改 hosts 可能没有帮助。应先定位失败域名与网络现象。

## 如何开始
README 给出 SwitchHosts 远程规则和本地服务两条路线，首次改动前备份原 hosts。选择本地服务时从 Releases 获取系统版本，按文档启动到 localhost:8888，先检查实际输出。需要用到有效映射时再通过规则启用，不覆盖其他已存在的自定义条目。
