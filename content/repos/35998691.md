## 它是什么
electron-builder 为 Electron 应用生成 macOS、Windows 和 Linux 的可分发产物，处理打包内容、原生依赖、签名相关流程和更新发布所需支持。它不负责业务界面实现，而是把已有应用转换成安装包、便携包或可测试目录。打包、签名、上传与自动更新服务仍是可以区分的环节。

## 适合什么场景
适合已有 Electron 项目需要生成 dmg、NSIS、AppImage 等产物，或把构建流程移到 CI。跨平台目标受宿主、工具与签名条件约束，不能因为支持多平台就推断任意机器可完成所有发行流程。

## 如何开始
README 当前 v27 要求 Node >=22.12.0。先安装 electron-builder 为开发依赖，补齐 package.json 的 name、description、version、author 与 build 配置，并确定 appId、图标和实际打包文件。原生依赖可按文档加入 install-app-deps 的安装后处理。

## 一个使用示例
官方脚本示例，未执行：
```json
{
  "scripts": {
    "app:dir": "electron-builder --dir",
    "app:dist": "electron-builder"
  }
}
```
先运行 app:dir 检查未封装目录，再按目标生成安装产物。预期确认主入口及资源被带入；生成文件不等于已签名、已上传或用户更新链路可用。

## 注意事项与相关项目
v27 含原生 ESM、Node 下限及配置变化，升级前应读迁移文档；migrate-schema 会改写配置，不能无检查运行。README 说明 Yarn 3 需 node-modules 而非默认 PnP。本文未打包应用，也未使用证书或发布凭据。
