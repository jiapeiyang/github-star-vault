## 它是什么
这是“力扣加加”的中文算法题解与专题库。README 按难度列出代表题目，同时提供前缀和、二叉树序列化、最长上升子序列等专题入口。题解文件在 problems，部分跨题目讨论位于 selected。它的主要价值是通过题目解释思路与可复用方法，不是一个把所有题目统一运行的程序包。

## 适合什么场景
适合按题号找中文解释，或遇到一类问题时比较相关解法。准备面试也可按主题筛选；如果只需要标准库 API 或生产环境算法实现，应另查对应语言文档和经过工程验证的库。

## 如何开始
先确定问题的题号或算法主题，再从 README 对应难度进入题解。阅读时先核对输入约束、返回要求和复杂度，再看代码采用的语言。若要自己运行，需把相应函数放到题目要求的运行环境，不能假定仓库所有示例共用一个入口。

## 一个使用示例
说明性阅读示例，未执行：查“两数之和”时，从简单题目录打开 problems/1.two-sum.md；先把它与题号 167 的有序数组版本区分，比较题目是否保证排序，再选取对应思路。预期找回的是准确题型及解法依据，不能只因标题相近就复制另一题的实现。

## 注意事项与相关项目
题库目录是代表性选择，不保证覆盖平台全部题目；README 中的活动名和题目数量是上游陈述。与 soulmachine/leetcode 相比，这个仓库更适合按网页题解与专题跳读，后者另有 C++ PDF 阅读形态。
