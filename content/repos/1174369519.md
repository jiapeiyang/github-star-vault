## 它是什么
agency-agents-zh 是 agency-agents 的中文社区版，按工程、设计、经营、营销等部门组织角色文件。每份文件包含身份、关键规则、工作方式与交付物，用于让宿主采取某种专业视角；仓库还补充面向中文平台和行业场景的角色。角色定义不代表具备对应真人资质或独立运行能力。

## 适合什么场景
适合需要一份前端、安全、产品或运营任务的结构化提示，或想比较不同角色会关注什么问题。可把单个角色当作提示参考，不必一次安装数百份文件。实际判断还要依赖代码、资料和领域专家。

## 如何开始
先从 README 部门目录或在线专家库找到需要的角色，打开 Markdown 核对流程。Claude Code 与 Copilot 可直接采用相应格式；其他宿主按文档先 convert 再 install。只想试用时复制一份所需角色并提供任务上下文，不必启用整支代理团队。

## 一个使用示例
官方角色用法改写，未执行：打开 engineering 下的安全工程师定义，给它一个测试项目的具体接口和认证流程，要求按可验证证据检查权限。预期输出问题位置、触发条件和改进建议；不能只因角色模板列出 OWASP 就宣称系统已经完成安全认证。

## 注意事项与相关项目
README 的总数与在线图库段落存在不同快照数字，因此本条不把数量作为功能保证。转换后的宿主文件、实际可用工具和权限会影响执行。桌面 orchestrator 是另外的项目；复制角色文件不会自动获得界面、运行环境或模型订阅。
