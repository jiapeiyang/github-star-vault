## 它是什么
Agent Reach 是互联网能力配置层，维护不同平台的首选与备选后端，帮助代理安装依赖、诊断可用性并选择读取路线。实际抓取由 Jina Reader、gh、yt-dlp、OpenCLI 等上游工具完成；doctor 告诉用户当前平台走哪条路径以及缺少什么。

## 适合什么场景
适合新的代理环境需要阅读公开网页、RSS、视频字幕或 GitHub，而不想逐个平台研究工具的人。需要登录的社区与零配置公开读取不同，应只配置自己真正需要的渠道，避免导入大量不相关凭据。

## 如何开始
先按 README 的 docs/install.md 从本仓库安装命令，README 明确 PyPI 同名包不是该项目。当前 `agent-reach install --env=auto` 默认只检查环境，显式 --system 才安装系统依赖与写配置。随后运行 `agent-reach doctor` 查看渠道状态，再按单个平台的要求配置权限与登录。

## 一个使用示例
官方使用路线归纳，未执行：给代理一个公开 YouTube 视频 URL，先确认 doctor 中该渠道可用，再让上游字幕工具提取并摘要，保留视频链接与缺失字幕说明。预期是获得实际转录来源；字幕不可用时不应凭标题编造内容。RSS 或公开 GitHub 也可先采用无需账号的读取范围。

## 注意事项与相关项目
平台接口和可用后端变化很快，“支持”不代表每次访问都成功。用户提供的 Cookie、现有浏览器会话和 GitHub 写权限有不同作用，安装能力层不等于允许发帖或提交 PR。README 的“免费”说明受第三方服务政策限制，部署与代理费用需另核对。
