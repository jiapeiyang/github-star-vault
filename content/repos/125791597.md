## 它是什么
Interview Map 是用于组织技术面试知识点的中文资料图谱，仓库目录包含 JS、Browser、Network、Performance、Safety、Framework、Algorithm、DataStruct、Git 和 Career 等主题。README 提供在线阅读与图谱入口，也介绍了另外出售的进阶小册；开源内容与商业版本的范围并不相同。

## 适合什么场景
适合按知识领域快速找解释，或把浏览器、网络与性能问题放在一起复习。它是资料导航和文章集合，不是完整招聘标准，也不保证某家公司会按这些主题提问。

## 如何开始
从在线阅读站或仓库主题目录开始，先确定具体问题属于语言、浏览器机制还是网络，再打开对应内容。需要看整体关系时查看仓库图谱图片；需要可执行例子时应进入正文并核对代码前提，不以 README 中的小册宣传代替技术文档。

## 注意事项与相关项目
README 的统计、评价和写作进度属于作者当时的介绍，不能推断当前覆盖完整度。在线域名或文章路径若迁移，可继续以仓库目录为线索。资料内容仍需结合浏览器及框架版本核对，尤其不应把短面试答案当成覆盖异常与边界的生产方案。
