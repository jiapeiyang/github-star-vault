## 它是什么
CLIProxyAPI 是模型协议代理服务，提供 OpenAI、Gemini、Claude、Codex 等兼容接口，让客户端通过统一入口使用已配置提供方。它支持多账号与不同协议格式，管理 API 则负责配置和认证材料。代理本身与管理前端、桌面客户端是不同组件。

## 适合什么场景
适合已有多个受控模型入口，想让兼容 SDK 或桌面客户端共用一处配置。还可用于研究接口转换和提供方适配。上游账户允许怎样调用、实际支持哪些模型与字段，仍要按提供方与当前配置确认。

## 如何开始
桌面用户可从 README 推荐的 EasyCLIProxyAPI 入口开始，图形界面负责获取、启停与配置服务。手动部署则进入官方 Getting Started 选择系统路线。服务启动后，可访问同端口的 management.html，用管理密钥连接；调用客户端使用自己的代理 API key，两种密钥不要混用。
