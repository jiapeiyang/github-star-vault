## 它是什么
alibaba-interview 是阿里相关技术面试经历与文章的链接集合，按 IT 社区精选、云栖系列、学生求职系列和作者个人经历分组。现有目录较多面向 Java、数据研发和 DBA，也有社招与实习回顾。它保存的是公开文章入口，不是阿里官方题库、招聘系统或保证拿到 offer 的流程。

## 适合什么场景
适合回顾历史技术招聘讨论、比较社招与校招叙事，或为面试准备寻找问题主题。若要了解当前岗位要求，应以正在招聘的具体职位描述和面试沟通为准。

## 如何开始
先按自己的岗位方向和招聘类型选择分组，再看文章标题中日期与角色。打开原文时区分作者实际经历、参考答案和个人建议。记录有帮助的问题主题即可，不需要安装仓库，也不应把不同年代的经历拼成一套固定面试流程。

## 一个使用示例
说明性导航示例，未执行：准备 Java 社招时，先查“各大 IT 社区精选”中的 Java 方向文章，再与“学生党”分组比较题目深度和经验要求。预期得到需要进一步查证的知识点与提问方向，不能据此推断下一次面试一定出现相同题目。

## 注意事项与相关项目
目录包含明确写有 2014、2016、2017 的历史文章，云栖及第三方博客链接可能迁移。本文只核实到仓库的链接目录，未逐篇审阅外部面经的真实性，也不引用其中答案作为权威结论。可与 reverse-interview-zh 搭配，分别覆盖技术准备和了解团队的提问。
