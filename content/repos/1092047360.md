## 它是什么
claude-howto 是社区维护的教程与配置示例库，用图示、可复制文件和模块导航解释 Claude Code 的使用组合。目录涵盖 Slash Commands、Memory、Skills、Hooks、MCP、Subagents、Checkpoints 和 Plugins。它是使用资料，不是 Anthropic 官方客户端或服务。

## 适合什么场景
适合已经能启动 Claude Code，但想找某一项配置范例，或弄清多个扩展机制如何组合时查阅。无需按课程顺序完成全部内容；可以直接在 CATALOG.md 或模块目录定位当前问题，阅读所需的前提与示例。

## 如何开始
先核对自己的 Claude Code 版本，再从 README 的功能目录进入相应模块。只阅读文章不需要安装仓库依赖。要采用模板时，先打开模板内容，与项目已有 CLAUDE.md、commands 或 skills 对照，把需要的部分合并进去，避免直接覆盖已有规则。仓库另有中文 README 入口。

## 一个使用示例
官方入门例子改写，未执行：进入 01-slash-commands 查看 optimize.md，确认它做什么，再把所需命令文件放到测试项目的 .claude/commands，通过 `/optimize` 观察输出。预期是理解自定义命令如何传达任务要求，不能把模板里声称的优化效果当作已经验证的性能提升。

## 注意事项与相关项目
README 标明了跟随版本更新的目标，但社区资料与宿主发行仍可能有时间差。权限、安装路径和命令行为应以当前官方文档及实际版本为准。上游还包含测验和课程路径，按当前问题选读即可，不必为了找到一个配置而完成全部模块。
