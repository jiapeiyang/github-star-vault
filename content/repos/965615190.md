## 它是什么
BMAD-METHOD 是面向代理开发的敏捷方法，把产品与技术决策明确写出，并让后续实现继续使用这些上下文。小而清楚的改动可以直接构建与验证，复杂项目再增加规划深度；也允许只把简报、规格和架构产物带入已有工作流。

## 适合什么场景
适合从模糊想法走向软件，或接手已有系统时先确认真实代码背景。它提供产品、架构、UX 和测试等视角，但使用者仍需决定范围与取舍。无需把所有改动都变成完整课程或大型文档工程。

## 如何开始
当前 README 要求支持 Skills 的编码工具及 uv；Skills CLI 路线还需 Node.js、npm 和 Git，在项目内运行 `npx skills add bmad-code-org/BMAD-METHOD`，选择技能时包含 bmad。安装后让 bmad 执行 `bmad setup`，再用 bmad-build 说明要改什么。已有代码库可从官方 existing-codebases 文档进入。

## 注意事项与相关项目
核心 Method、Toolbox、测试扩展和游戏模块是不同模块，按任务选取即可。更新后 README 建议用 bmad doctor 修复现有 runtime，但操作前仍应核对项目差异。旧版教程的安装命令可能与当前技能体系不同，应按安装版本阅读。
