## 它是什么
Follow Builders 把 AI 研究者、创始人、产品与工程人员的公开帖子、播客和公司博客汇成资料流，再让代理按语言与篇幅偏好整理成 digest。客户端读取集中 feed，减少自行配置各平台采集接口的工作；原始链接跟随摘要，便于继续阅读全文。

## 适合什么场景
适合想定期了解 AI 产品与工程思考，但不想分别刷新多个频道的人。可按当天一次性查询，也可在已具备调度和发送能力的宿主中配置周期交付。资料源是维护方精选，并不覆盖所有重要消息或整个行业。

## 如何开始
README 为 Claude Code 提供克隆到 skills 目录并在 scripts 安装 npm 依赖的路线。读取 SKILL 后可用自然语言或 /follow-builders 进入设置，指定每日或每周、时间、语言及交付渠道。只在对话中阅读时不用配置外部发送；Telegram、邮件等仍需宿主和对应凭据支持。

## 一个使用示例
官方流程改写，未执行：要求“给我一份中文摘要，侧重工程实践并保留原文链接”，代理读取 feed 后将新播客、帖子和博客分组。挑选一条感兴趣的观点，打开其原始链接检查上下文。预期是帮助决定深入读什么，不是把摘要替代原作者完整立场。

## 注意事项与相关项目
“无需 API key”针对集中内容读取，不表示消息渠道也不需要认证。feed 维护和上游采集会影响时效、遗漏与转录质量；没有新内容时不应编造日报。README 的 ClawHub 入口仍标 coming soon，实际安装应核对当前可用渠道。
