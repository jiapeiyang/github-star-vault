## 它是什么
DMQ/mvvm 用精简代码解释 Vue 风格的双向绑定，重点展示 Observer、Compile、Watcher 和 MVVM 入口如何协作。它适合把响应式概念拆成几块可阅读的代码，而不是把一个生产框架完整缩小复制下来。

主分支的讲解基于 `Object.defineProperty()`：读取属性时建立联系，修改属性时通知订阅方；Compile 扫描模板和指令，Watcher 把数据变化连接到视图更新。README 另外提供 Vue 3 响应式精简代码的分支链接，两条实现路线需要分别理解。

## 适合什么场景
- 想知道修改 JavaScript 对象为何能更新页面文字。
- 希望沿一条最短链路观察输入事件、数据变更与 DOM 更新。
- 对照早期 defineProperty 思路与 Vue 3 的不同实现，不想先读完整框架仓库。

这份代码是原理演示，不能把“看到了绑定效果”当成组件系统、编译优化和复杂边界都已具备。

## 如何开始
1. 先读 README 开头的能力与限制说明。
2. 按 Observer → Compile → Watcher → MVVM 的顺序看对应讲解。
3. 打开仓库中的演示文件，对照 `js/observer.js`、`js/watcher.js`、`js/compile.js`、`js/mvvm.js` 的加载关系。
4. 从简单字符串输入入手，先验证最短的数据与视图链路，再看更复杂分支。

## 一个使用示例
上游 README 的示例把输入框和段落都绑定到 `word`，初始值是 `Hello World!`，按钮方法将它改成另一段文字：

```js
var vm = new MVVM({
  el: '#mvvm-app',
  data: { word: 'Hello World!' },
  methods: {
    sayHi: function () {
      this.word = 'Hi, everybody!'
    }
  }
})
```

需要同时使用 README 提供的 HTML 与四个脚本，单独复制这段构造代码并不能运行。预期是输入变化会更新绑定文字，按钮则通过修改数据更新视图。本段为官方示例摘录整理，未在本站运行。

## 注意事项与相关项目
作者明确说明实现经过简化，未考虑数组处理、循环依赖等情况。它适合解释原理，不宜作为生产框架直接接入。Vue 3 分支与主分支的机制不同，避免把主分支描述成当前 Vue 3 的完整实现。
