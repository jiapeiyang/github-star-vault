## 它是什么
Webfunny 面向技术监控和业务分析，整合前端错误、页面与接口性能、用户轨迹、录屏、后端链路和埋点看板。探针负责采集，服务端和控制台聚合分析；仓库同时承担产品介绍和私有部署入口，不应仅凭 GitHub 地址推断全部产品源码与功能都可免费使用。

## 适合什么场景
适合排查线上错误发生在哪个用户操作之后、寻找慢接口，或分析业务漏斗。技术监控与业务埋点的数据定义不同，应先明确要回答的问题，再配置采样、用户标识和事件字段。

## 如何开始
可先打开 README 的无注册 Demo，用示例数据了解控制台。实际部署根据社区版或企业版入口获取对应授权与文档，再准备 Node/Docker 等环境。接入真实应用前，先在测试环境添加所需探针，确认采集字段、上报目的地与可见权限。

## 一个使用示例
产品流程说明性示例，未执行：在 Demo 中选择一条前端错误，查看时间、页面和相关请求；真实接入时则用一次已知的测试错误检查是否上报，再核对 SourceMap 能否定位到正确版本。预期形成错误到代码的排查路径，不是只看 PV 面板就证明监控接入完整。

## 注意事项与相关项目
回放、远程调试和 Cookie/localStorage 查看涉及用户数据，采集与访问范围需按实际产品配置。README 的竞品比较和亿级规模主张属于维护方描述，本次未做压测或独立对照。社区版、企业版、源码购买与使用协议需要分别确认。
