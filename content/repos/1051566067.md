## 它是什么
CLI Proxy API Management Center 是 React 与 TypeScript 编写的管理前端，经 /v0/management 与 CLIProxyAPI 后端通信。它可查看状态、编辑配置、管理认证文件与提供方、检查配额和日志。真正转发模型请求的是后端，单独打开这个界面不会建立代理服务。

## 适合什么场景
适合已部署 CLIProxyAPI，希望用图形界面检查模型映射、凭据状态和错误日志的人。也适合排查“界面能连接但模型请求失败”的问题，因为管理接口和模型调用接口使用不同凭据，故障来源可能不同。

## 如何开始
README 当前要求后端至少 7.2.147，推荐先用后端自带页面：启动服务后访问 `http://<host>:<api_port>/management.html`，输入 management key。地址会从当前页面推断，也可手动改。开发本前端时才需要 Bun，使用 `bun install --frozen-lockfile` 和 `bun run dev`；单文件构建产物为 dist/index.html。

## 一个使用示例
官方流程归纳，未执行：连接自己的测试后端，先在 Dashboard 核对版本与连通状态，再到 Config Panel 检查某个模型别名，保存前查看差异，随后到 Logs 查相关请求。预期能区分配置修改是否成功与上游请求是否成功。没有启用文件日志时 Logs 导航可能不显示，不能直接当作前端丢失功能。

## 注意事项与相关项目
management key 与面向代理调用的 api-keys 不同；远程浏览器还需后端允许远程管理。README 说明管理密钥以轻度混淆形式存于 localStorage，不能把混淆当成保密存储。浏览器内提供方测试受 CORS 与浏览器网络限制，失败不必然说明服务器也不能访问上游。
