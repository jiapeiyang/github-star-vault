## 它是什么
mshared 是一个轻量状态共享库，提供命名 store、订阅与 React 接入方式，并用 globalShare 支持一主多从的微前端通信。它将各应用的状态放在有名称的结构里，通过 Shared 实例读取和修改，React 层另提供 Provider、Hook 与 HOC。README 以 Qiankun 示例展示跨应用使用场景。

## 适合什么场景
适合小型 React 应用共享状态，或研究微前端主子应用如何交换状态。它不是跨机器消息系统，global 也不表示把数据自动保存到服务器；状态生命周期仍由宿主应用管理。

## 如何开始
库安装可用 npm i mshared -S。先建立一个 Shared 实例，指定 storeName 和 initStore，再使用 setStore、getStore 与 subscribe。需要看完整 Qiankun 示例时，README 给出 yarn install、yarn run example:install、yarn run start，预期地址 localhost:7099。

## 一个使用示例
官方 getStore 示例改写，未执行：
```js
import { Shared } from 'mshared';
const share = new Shared({
  storeName: 'main', initStore: { count: 0 }, type: 'global'
});
share.setStore('main', { count: 1 });
console.log(share.getStore());
```
文档预期状态为 { main: { count: 1 } }，体现名称与值的分层，不能把它误认成只返回 count 的对象。

## 注意事项与相关项目
README 部分 Shared 与 React 片段有排版缺损，使用时应对照实际源码，尤其不要照抄不完整的构造表达式。文档说明 child 只能设置一个 globalShared，unSubscribe 会取消当前实例所有监听。生产项目仍需明确卸载时如何清理、哪些状态应该共享，体积数字只是上游标注。
