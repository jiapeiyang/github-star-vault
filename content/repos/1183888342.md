## 它是什么
Orca 是多代理编排桌面应用，可并排运行 Codex、Claude Code、OpenCode 和 Pi，并让各任务使用独立 Git worktree。工作区整合终端、文件编辑、浏览器设计模式和 diff 注释，减少在任务、预览与审查工具之间反复切换。

它还提供手机伴侣、SSH 工作树和 CLI。独立工作树解决的是文件改动隔离，最后仍需要比较并合并结果；不是多个代理自动写同一目录的默认保证。

## 适合什么场景
同一需求尝试多个实现后选择结果；同时处理不同 issue；直接从页面元素的截图、HTML 和 CSS 向代理反馈 UI 问题。远程主机算力与本地审查也可通过 SSH 工作区连接。

## 如何开始
从 README 的 Download 或 Releases 获取对应系统安装包。打开实际 Git 项目，配置已使用的代理，再创建一个任务工作树。先确认终端和文件根目录正确，再启动代理；需要 UI 调整时打开内置 Chromium，用 Design Mode 选择元素作为上下文。

## 一个使用示例
官方能力组合的说明性示例，未执行：对同一个搜索页面创建两个隔离工作树，分别让代理给出实现；在应用中预览结果，为 diff 中的问题行添加评论，再把反馈发送回相应代理。预期保留两份可比较的改动，审查后再选择合并。

## 注意事项与相关项目
远端、手机和第三方 issue 集成需要各自的授权配置。工作树不隔离共享数据库或外部发布操作，执行前仍需核对目标。Herdr 主要承载终端，Orca 更强调桌面中的浏览器、编辑与 diff 协作。
