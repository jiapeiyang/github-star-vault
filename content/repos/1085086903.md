## 它是什么
EverOS 是 Python 库和本地优先的记忆运行时，将对话、文件与代理轨迹保存为可读 Markdown，并同步 SQLite、LanceDB 索引用于检索。模型、向量、重排及多模态能力按配置分层提供，不是所有功能安装后都立即可用。

## 适合什么场景
为自己的助手或应用补充可迁移的长期记忆，想保留可阅读、可版本管理的原始资料。是否真的提高检索质量与任务效果，需要结合自己的数据验证。

## 如何开始
准备 Python 3.12+，在独立环境安装 `everos`。先尝试无需 Key 的 `everos demo`；完整运行按文档 `everos init` 配置模型凭据，再启动服务并检查 `/health`。单个 OpenRouter Key 支持基础记忆与关键词搜索，向量和重排需另配。

## 注意事项与相关项目
本地优先不代表模型调用全部离线，配置的提供商可能收到输入。记忆可能保存敏感信息，删除、隔离和有效性需按应用需求设计。XERJ 更偏通用内容搜索；yichen-skills 的资料库流程是另一套技能，不等于 EverOS 的服务接口。
