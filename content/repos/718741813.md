## 它是什么
screenshot-to-code 用多模态模型把截图、设计稿和屏幕录制转成前端实现，支持 HTML/CSS、Tailwind、React、Vue 等输出路线。项目分为 React/Vite 前端和 FastAPI 后端，后端调用模型与可选图像服务；截图预览工具还能让代理渲染自己生成的页面。

## 适合什么场景
适合把视觉参考变成可修改原型，或研究模型怎样理解布局与素材。单张截图不能包含全部页面状态、后台接口和响应式规则；生成结果需要补充真实交互和设计约束。

## 如何开始
可先用 README 的官方托管产品体验；本地运行至少需要 OpenAI、Anthropic 或 Gemini 之一的有效 key。后端用 Poetry 安装并启动到 7001，前端用 pnpm 安装并启动，默认页面在 5173。若需要生成页面截图，按说明安装 Chromium；缺少它时 Settings 会显示预览不可用。

## 一个使用示例
官方流程归纳，未执行：提交自己有使用权的页面截图，选择 React + Tailwind，检查生成预览的结构、文字和按钮，再指出一个具体差异让模型修订。预期得到能继续编辑的代码；应在目标宽度检查布局，并实际点击关键流程，而非仅凭相似截图认定完成。

## 注意事项与相关项目
视频模式依赖 Gemini，部分图片编辑与去背景能力依赖 Replicate；只有一个 key 时不能获得所有功能。截图中的真实标志和照片可能需要输入素材或额外提取，不能把猜测素材当成原图。Docker 运行与开发热更新路线不同，按目的选择。
