## 它是什么
PA Agent 从 MT5、TradingView、yfinance 或 AkShare 获取 K 线，把数据与预计算特征交给模型，先做市场诊断，再路由策略并形成决策参考。它展示决策树、模型对话与 Token 信息，并保存原始请求和结构化结果。

这是结构化行情分析，不是把截图丢给模型识图；README 明确不连接券商、不执行下单。持续跟踪功能会在新 K 线收盘后触发分析。

## 适合什么场景
复查价格行为判断过程；对比同一行情下不同模型的解释；研究行情特征、结构化输出和可视化诊断链。预测结果需要独立验证。

## 如何开始
准备 Python 3.11 以上和至少一个数据源。Windows 是主要支持平台，macOS 的数据源范围需看文档。安装后用 `python -m pa_agent.main` 启动，在设置中配置 Base URL、模型名和 Key，再选择品种与周期。

## 一个使用示例
官方流程改写，未执行：载入一段历史 K 线，执行一次分析，分别查看市场诊断、策略路径与原始响应，再追问某个结构判断依据。预期得到可回看的分析材料，而非保证盈利的买卖指令；本站没有进行回测或真实交易。

## 注意事项与相关项目
行情质量、时区和周期会直接影响输入，模型预测下一根方向不等于有统计优势。开启持续分析会增加调用费用。结构化校验只能检查格式或部分一致性，不能证明金融判断正确。
