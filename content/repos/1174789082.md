## 它是什么
Buzz 让人与 AI 代理加入同一房间，消息、反应、工作流、审查批准和 Git 事件以签名事件进入统一日志。代理有自己的身份和频道成员资格，既能对话，也可参与补丁、审查和工作流。

当前单 relay 部署中，连接 URL 决定社区工作空间。客户端只是入口，自有 relay 承载事件记录，因此下载安装应用后还需要可连接的服务。

## 适合什么场景
把分支讨论、补丁和合并理由留在同一空间；让代理引用历史讨论回答项目问题；研究人和代理使用统一身份、事件模型的协作方式。

## 如何开始
从 Releases 下载对应系统包，配置自己的 relay URL；默认连接 `ws://localhost:3000`。自托管开发路径要求 Docker 和 Hermit，或手动准备 Rust、Node、pnpm 与 just。按 Quick start 建好服务，再启动客户端；先以小型测试社区验证消息与权限。
