## 它是什么
Creator Buddy 是按创作任务组织的 Skill 工具箱。`gzh-Skills` 面向公众号文稿、标题和排版，`xhs-Skills` 覆盖小红书定位、选题和图文，`video-Skills` 面向脚本、字幕、剪辑、配音与封面。各子技能按任务组合，研究阶段先取得资料，再进入内容产出。

公开内容搜索依赖 Agent Reach、公开 API 或已配置的只读 CLI；不同平台的接入程度并不相同。图像、视频与音频产出也依赖宿主能力或外部服务，安装技能集合不等于所有平台和媒体工具都已就绪。

## 适合什么场景
- 从公开内容样本里研究选题，再整理成长文、短文或口播脚本。
- 已有文章，希望继续制作配图、公众号排版或视频辅助画面。
- 按一个具体制作环节选技能，避免每次重新组织整套提示词。

## 如何开始
上游提供 `npx skills add SpaceZephyr/creator-buddy`，或手动复制所需子技能到宿主的技能目录。先选公众号、小红书或视频方向，并说明已有材料、目标平台和期望产物。

研究任务先确认实际可用的只读数据入口；小红书的第三方兜底需要对应 token，抖音目前只是待接本地只读 CLI 的扩展入口。生成配图或视频时再配置对应能力和额度。只需要处理已有文字时，可以从写作或排版子技能开始。
