## 它是什么
Vue.Draggable 把 SortableJS 包装成 Vue 2 组件，重点是让拖拽后的 HTML 顺序与数据数组保持同步。它支持跨列表、事件、取消和 transition-group 等用法，也能通过 tag 与 componentData 配合其他 UI 组件。README 明确把 Vue 3 使用者引向另一个 vue.draggable.next 项目。

## 适合什么场景
适合 Vue 2 中的数据列表、看板和排序表单，尤其是界面顺序必须反映到响应式数组时。它不是只操纵 DOM 的指令包装，选择接入方式时要考虑 Vuex 与不可变更新。

## 如何开始
安装包名为 vuedraggable，README 特别提醒不要混淆 vue-draggable。在组件中 import 并注册 draggable，用它直接包住可拖动条目；v-model 指向与 v-for 相同的数组，每个条目使用稳定 ID 作为 key。

## 一个使用示例
官方示例节选，未执行：
```html
<draggable v-model="myArray">
  <div v-for="element in myArray" :key="element.id">
    {{ element.name }}
  </div>
</draggable>
```
前提是已注册组件并准备对象数组。预期拖动后数组顺序跟随变化；持久化与服务端排序需另外处理。

## 注意事项与相关项目
list 会用 splice 更新原数组，value/v-model 路径采用不同更新方式，二者不应同时使用。默认 clone 复用原 view model，需要深复制时应提供自己的 clone 函数。版本 2.19 起 Sortable 选项可作为 props，但 on 开头回调用 Vue 事件表达；Vue 3 项目不要直接照抄此版本。
