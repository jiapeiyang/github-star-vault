## 它是什么
ElemeFE 的 node-interview 是源自 2016 年招聘经验的 Node 服务端知识大纲。中文入口把语言、模块、事件异步、进程、I/O、网络、存储、安全、测试等拆成覆盖点、常见问题和延伸阅读。它更关注有一定经验的后端基础，而非只把 Node 当作前端构建工具。

## 适合什么场景
适合已有 JavaScript/Node 基础、希望按系统主题查资料的读者，也能为技术讨论寻找有实际后果的问题。README 的岗位和招聘背景属于历史信息，不能据此判断当前团队招聘要求。

## 如何开始
从 sections/zh-cn/README.md 进入，先看各类覆盖点，再根据问题跳到专章。异步问题可看 event-async.md，文件与背压看 I/O，进程生命周期另看 process。英文版本在 README 中明确提醒翻译尚不完整，中文是更直接的原始入口。

## 一个使用示例
官方异步示例改写，未执行：创建 Promise 时在执行器中打印 hello，再在 then 中打印 over，观察构造时执行与后续回调的区别。文章还进一步追问延后挂 then 是否会延后 hello。预期区分 Promise 执行器与回调调度，本站没有运行这些代码。

## 注意事项与相关项目
作者说明大纲不全面、许多讨论点到为止，不能把它当作严谨的运行时规范。文中“硬异步/软异步”等是作者组织解释的术语，现代 Node 的事件循环细节须查匹配版本。阻塞循环示例用于展示后果，不是服务端实现等待的推荐方法。
