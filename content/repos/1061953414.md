## 它是什么
这是 Anthropic 提供的 Skills 示例与参考实现仓库。一个 Skill 是包含说明、脚本和资源的目录，核心入口通常为 `SKILL.md`。宿主在需要某项专门能力时加载相应内容，把重复任务的执行方法组织成可复用资料。

理解它时要区分三层：Agent Skills 标准描述通用约定；此仓库提供 Anthropic 的实现与示例；Claude Code、Claude 网页端和 API 则各有加载和使用方式。下载一个目录并不自动让所有智能体产品都具备相同能力。

## 适合什么场景
- 为编码助手整理文档处理、网站测试、品牌规范等专门工作流。
- 参考 `SKILL.md` 如何描述触发条件、操作步骤和所需资源。
- 比较简单说明型 Skill 与带脚本、资源文件的复杂 Skill。

这是能力包和示例目录，不是独立运行的聊天客户端，也不是模型本身。

## 如何开始
1. 从 README 的 Skill Sets 进入 `skills`、`spec` 或 `template`，先判断自己需要实例、标准还是模板。
2. 阅读具体 Skill 的说明和依赖，确认它适配的宿主与任务。
3. 如果使用 Claude Code，可按官方 README 注册 marketplace，再安装需要的插件集合。
4. 安装后通过明确的任务请求调用 Skill，并检查实际产物。

```text
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
```

以上是 Claude Code 内的命令，不是普通 shell 命令；其他客户端需要遵循各自的导入方式。

## 一个使用示例
官方 README 给出的思路是安装文档集合后请求使用 PDF Skill 提取表单字段。例如向宿主提出：

```text
使用 PDF skill，读取我提供的表单 PDF，列出可填写字段及字段类型。
```

输入应是一份真实可访问的 PDF；预期结果是字段信息或相关处理产物。是否支持某个 PDF、是否需要额外依赖，应以具体 Skill 的实现和执行结果判断。这里是官方示例的中文改写，本站未执行，也没有安装插件。

## 注意事项与相关项目
仓库明确说明示例不保证与 Claude 产品内行为完全相同。许多 Skills 使用 Apache 2.0，但 docx、pdf、pptx、xlsx 等文档目录被单独说明为 source-available，不能把整个仓库一概当成同一开放许可。涉及本地文件、脚本或账号的 Skill，使用前应阅读其实际操作范围。
