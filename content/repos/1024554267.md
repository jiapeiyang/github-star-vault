## 它是什么
Hermes Agent 是 Nous Research 维护的代理系统，提供终端 TUI、消息 gateway、工具配置、跨会话检索及技能管理。模型负责推理，运行时提供终端、搜索等动作接口，也能把复杂任务中的方法保存为技能。可选择多个模型提供方与本地、容器、SSH 等执行后端。

## 适合什么场景
适合需要在终端持续工作，或从聊天渠道访问自己的代理环境的人。定时任务和持久信息能减少重复输入，但也扩大了运行状态与权限范围；想先试效果可从本地交互和少量工具开始。

## 如何开始
按 README 选择系统安装路线，完成后运行 `hermes setup` 配置环境，`hermes model` 选择可用模型，`hermes tools` 决定启用工具，再运行 `hermes` 开始会话。消息渠道需要另做 gateway setup 和用户访问配置。已有 OpenClaw 数据可先预览迁移，不必直接覆盖。

## 注意事项与相关项目
“自我改进”指技能、记忆等运行资料变化，不代表本机自动重训模型。不同 terminal backend 的隔离与成本不同，本地执行也仍可能把上下文发给模型提供方。迁移包括凭据等敏感项目时先用 dry-run 查看范围；本次未安装、迁移或启用外部消息渠道。
