## 它是什么
这是李笑来《定投改变命运》及英文 On Regular Investing 的书稿仓库，围绕长期、定期投入固定金额的投资方式展开作者观点。README 说明自身正文属于第一版，另有出版用第二版及 docs 中的第三版，同时提供 PDF、EPUB、MOBI 和音频入口。它是书籍内容，不是自动交易程序或收益计算器。

## 适合什么场景
适合了解作者如何解释定投、比较不同版本的论述，或在电子阅读器离线阅读。书中讨论投资对象和心理因素，不代表本站推荐其中某项资产，也不能把阅读资料当作具体投资操作依据。

## 如何开始
先确定要读哪个版本：想读第三版可进入 README 指出的在线站点或下载相应语言的电子书；需要了解早期论述则使用根目录章节。阅读时区分概念定义、作者价值判断、具体产品描述和可查证事实。获取文档无需交易账户。

## 一个使用示例
说明性阅读示例，未执行：想知道作者怎样定义定投，可先读开头关于时间、频率、金额、投资对象四个要素，再定位心理建设章节，对照策略定义与执行困难。预期理解作者的论证结构，不涉及开户、购入 BOX 或其他资产，也没有计算和验证投资收益。

## 注意事项与相关项目
README 保留 2019 年及具体产品推广语，其中“唯一”“只涨”等强表述属于作者主张，不能视为事实保证。定期投入本身不会消除标的下跌或永久损失风险。版权标示为 CC-BY-NC-ND；本条只概括结构，原文与译本的进一步使用应遵循各自许可。
