## 它是什么

Komari 是自托管服务器监控应用：Agent 负责采集指标，Web 面板负责展示。README 说明支持按秒更新、主题与插件扩展；这里的“轻量”是项目定位，本文没有测量资源占用。

## 适合什么场景

- 想集中查看少量或多台自有服务器的运行指标。
- 希望自己部署监控面板，并调整展示主题。
- 需要在现有服务器管理方式之外增加持续观察入口。

## 如何开始

1. 从 README 进入安装指南，在 Docker、二进制或源码方式中选择适合当前系统的一种。
2. 先部署测试面板，确认管理访问方式和持久化数据位置。
3. 再接入一台获授权的测试机器，核对指标更新；主题和插件应在基本采集链路正常后添加。

## 注意事项与相关项目

README 将项目称为监控与控制应用，部署和授权需覆盖其实际管理能力。自托管并不自动保证访问安全或数据备份。文档中的云商按钮属于部署选项，价格和服务能力须另查。哪吒监控可作为面板与 Agent 方案的另一项对照。
