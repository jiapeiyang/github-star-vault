## 它是什么
koa-log4js 是 log4js-node 的 Koa 包装，为普通日志与 HTTP 请求日志提供接入方式。仓库名带 log4js，但实际 npm 包名是 koa-log4。默认分支 v2.x 面向 Koa 2，README 将 Koa 0/1 的用法放到另一版本。它负责日志输出和级别映射，不是日志采集平台。

## 适合什么场景
适合已有 Koa 2 服务希望统一请求日志，或希望用同一 log4js 配置记录业务与 HTTP 信息。日志最终写到哪里、如何轮转与保存，需由 log4js 配置和运行环境决定。

## 如何开始
Koa 2 可按上游安装 koa-log4@2，require('koa-log4') 后先配置 log4js，再用 getLogger 创建分类 logger。HTTP 记录通过 koaLogger 接到 app.use；普通业务记录则调用 logger.info 等方法。

## 一个使用示例
官方示例节选，未执行：
```js
const log4js = require('koa-log4');
app.use(log4js.koaLogger(log4js.getLogger('http'), { level: 'auto' }));
```
前提是已有 Koa app。文档默认把 200–299 映射 INFO、300–399 映射 WARN、400–599 映射 ERROR，预期请求按状态进入相应日志级别。

## 注意事项与相关项目
自动将所有重定向记为 WARN 是库的默认策略，未必符合业务告警含义；需要时可按文档配置 levelMapper。示例中的 levels 必须有有效定义，不能复制未引入变量的片段。请求日志也可能含敏感 URL 参数，应由应用决定记录范围。本文未运行中间件或验证文件输出与轮转。
