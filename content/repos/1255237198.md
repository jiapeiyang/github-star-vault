## 它是什么
Munder Difflin 是基于 Electron 的桌面应用，把现有编码 CLI 作为真实终端进程运行，并用办公室角色展示状态。用户可向调度角色 Michael 下达任务，由它在其他代理之间分配工作、传递消息和汇总结果。

终端层使用 PTY 与 xterm.js，协作层包含文件邮箱、共享记忆、任务记录和事件日志。角色动画是观察入口，实际能力仍来自配置的 CLI、模型、工具和工作目录。本次 README 标注 v0.4.6，仍属预发布软件。

## 适合什么场景
- 已经使用多个编码 CLI，希望集中查看终端、任务和进度。
- 有能拆分的项目工作，需要代理通过明确的消息和共享上下文协作。
- 希望在桌面中管理角色、工作目录和权限，并保留跨会话资料。

## 如何开始
普通使用者从上游 Releases 选择 macOS、Windows 或 Linux 安装包，打开应用后按向导配置。至少需要一个可用的代理 CLI 及相应账号、订阅或 API 配置；设置中的 Prerequisites 可检查依赖。下载应用不要求先克隆源码。

先用一个测试目录和少量代理验证流程：选择 CLI、工作目录、角色与自主程度，再交给调度角色一个范围清楚的任务。并行修改代码时可查看其可选 worktree 隔离能力。源码构建另需 Node.js/npm 与 `node-pty` 的原生编译工具链。
