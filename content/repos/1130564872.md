## 它是什么
World Monitor 结合新闻聚合、AI 简报、3D 地球与平面地图，展示地区、经济、灾害和基础设施等信号。多个 world、tech、finance、commodity、energy 等变体共享同一代码库，也提供 Tauri 桌面发行。

它把跨来源信息放到同一观察界面，部分指数和关联是项目自己的算法输出，不等于官方风险评级。

## 适合什么场景
回看一个地区近期事件与关联报道；同时观察市场和基础设施信号；研究多图层、数据源和仪表盘的组织方式。

## 如何开始
直接使用 README 的公开站或下载桌面版。源码可 `npm install` 后 `npm run dev`，默认端口 3000；不填环境变量也能启动，但特定来源仍需凭据。先选择少量图层并检查来源，再增加所需数据或本地 AI。

## 一个使用示例
说明性浏览路径，未查询实时态势：选择一个地区，查看相关新闻、地图层与时间信息，打开原始链接确认事件，再观察指数变化是否有对应证据。预期把信息串成可调查线索，而不是从地图颜色直接得出政策或投资结论。

## 注意事项与相关项目
不同来源的更新频率与覆盖范围不同，实时界面不表示每项都是实时数据。REST/MCP 调用另有鉴权，公开 tools/list 不代表业务调用免费。AI News Radar 更聚焦 AI 行业消息，World Monitor 范围更广。
