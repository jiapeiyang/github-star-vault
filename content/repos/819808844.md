## 它是什么
ECS 是“融合怪”服务器测评的 Go 版本，整合 CPU、内存、磁盘、媒体可用性、IP 质量、端口、三网路由、Ping 和测速等模块。预编译程序减少环境依赖；是否额外安装测试工具由所选模式决定。

## 适合什么场景
新 VPS 验收、比较不同出口或调查线路问题。适合按问题挑选检测项，而不是每次都运行全部高负载测试。上游列出的可编译平台与实际测试过的平台有区别。

## 如何开始
先读新用户说明和系统支持表，从 Releases 选择架构，或下载检查 `goecs.sh`。安装环境、更新包管理器和执行测试是不同动作；非 root 环境可按文档使用二进制，但部分检测能力会受权限限制。先查看程序帮助，再按需选择模块。

## 一个使用示例
README 流程整理，未执行：比较两台 VPS 的晚高峰网络，固定 IP 版本、节点与时段，仅选择网络相关项目，保留输出 `goecs.txt`。再次换时间测量，以区分持续问题与瞬时拥塞；不要把不同测试工具的 CPU 分数放在同一标尺上。

## 注意事项与相关项目
网络测试依赖公共节点、外部 IP 数据与平台探测规则，结果可能随时间改变。输出与分享链接可能含地址和机器信息，发布前应检查。YABS 更聚焦基础性能；NodeQuality 更聚焦测试环境和报告整理。本站不采纳上游“最快”等宣传为实测结论。
