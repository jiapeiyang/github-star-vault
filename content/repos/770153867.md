## 它是什么
MoneyPrinterTurbo 将短视频生产拆成文案、素材、语音、字幕、音乐和合成，提供 WebUI、API、CLI 与 Agent Skill 入口。素材可以来自本地图片视频、库存服务或配置的生成模型，每个环节也可使用自定义输入。

它更接近可配置的制作流水线，而不是单一文生视频模型；最终画面、配音和字幕的效果取决于各服务与素材匹配。

## 适合什么场景
为一段知识文案做配音字幕视频；把自有图片组合成竖屏介绍；批量生成多个主题的初稿，再人工检查和修改。

## 如何开始
Windows 可选择发行启动包；本地源码需 Python 3.11 以上，macOS/Linux 文档推荐 uv。Docker 方式使用 `docker-compose.release.yml` 的预构建镜像，并先准备挂载的 `config.toml`。WebUI 默认入口 `http://127.0.0.1:8501`，在基础设置中只填写实际需要的模型、素材和语音服务 Key。

## 注意事项与相关项目
云端模型与素材服务可能收费，广告套餐并非运行必要条件。自动发布需要独立账号授权，不应默认开启。下载素材的许可、人物肖像和生成内容均需按具体用途核对。OpenChatCut 更适合继续修改多轨工程。

Windows 一键启动应下载 Releases 的 Assets 中 `.7z` 包；GitHub 自动 Source code 压缩包不含 `start.bat`/`update.bat`。macOS/Linux 源码安装优先按锁文件执行 `uv sync --frozen`。

当前 VoxCPM 接入已支持参考音频复刻：需对应 API Key、模型，以及有权使用的参考音频和转写文本；也可通过 Whisper 辅助转写。上传限制与转换后的音频限制不同，应按界面和 README 核对。该能力来自上游说明，本站没有生成或试听音频。
