## 它是什么
ego lite 将浏览器本身设计为人与代理共用的工作空间。代理通过 `ego-browser` 读取快照与调用 JavaScript 能力，在自己的 Spaces 执行任务，用户继续使用原有标签页。

与单独驱动浏览器的自动化库相比，它把登录态、标签与自动化入口放在同一产品中。当前 README 表示 macOS 可用，Windows 和 Linux 仍在路线图。

## 适合什么场景
代理需要读取已登录的业务页面；多个浏览器任务并行但希望减少对用户标签页的干扰；偏好直接在日常浏览器中核查自动化结果。

## 如何开始
下载 macOS 应用或先安装 `ego-browser` 技能，再按其安装指引取得浏览器。首次启动可选择是否迁移 Chrome 数据，这会影响已有 cookies、书签和扩展是否可用。完成后给代理具体页面和明确操作范围，先用读取任务检查能否访问目标。

## 一个使用示例
说明性示例，未执行：要求代理在自己的 Space 打开一个已登录的项目列表，查找最近更新的条目并返回链接。预期用户仍能在自己的标签页浏览，代理读取的结果可在浏览器中回看；该例没有发送消息或修改业务数据。

## 注意事项与相关项目
共享真实登录态也意味着任务可能拥有真实账号权限，点击提交等动作应遵守授权范围。性能对比来自作者测量，不能直接推广到所有网站。agent-browser 是自动化工具，ego lite 则是承载这些任务的浏览器产品。
