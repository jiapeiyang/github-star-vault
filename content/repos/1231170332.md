## 它是什么
OpenSquilla 是 Python 代理运行时，将 CLI、Web UI 和聊天渠道接到同一个回合执行循环。它包含工具调度、持久资料、沙箱、搜索和本地嵌入，SquillaRouter 按任务选择模型。路由的目标是控制成本，但实际效果取决于模型配置和任务，不能直接套用上游宣传中的节省比例。

## 适合什么场景
适合希望统一多个代理入口、尝试多模型路由，或在本机管理工具执行与会话的人。它需要可用的模型提供方；本地路由器不等于所有推理都离线。只需单一聊天界面时，应先判断是否需要这些运行组件。

## 如何开始
当前 README 标记稳定版 0.5.4，macOS Apple Silicon 和 Windows x64 可选桌面安装包。终端路线使用 uv 管理 Python 3.12 环境；发布包已带 WebUI，无需另装 Node。首次运行 `opensquilla onboard` 配置提供方，再用 `opensquilla gateway run` 启动；只配置模型时可选择 onboard 的 minimal 路径。

## 一个使用示例
官方流程改写，未执行：先用 `opensquilla onboard status` 查看准备情况，配置一项已授权模型服务，启动 gateway，在 Web UI 发起一个整理公开文本的小任务。核对响应、执行记录和选中的模型。预期不同入口遵循同一运行逻辑；一次响应成功不证明路由比固定模型更便宜或更准确。

## 注意事项与相关项目
桌面数据目录与终端的 ~/.opensquilla 是不同 profile，升级或迁移前应明确使用哪一份。推荐安装会带本地路由模型和依赖；core 安装与运行时禁用 router 不是同一件事。README 说明默认有安装与用量汇总遥测，具体内容及关闭方法应阅读 PRIVACY.md。
