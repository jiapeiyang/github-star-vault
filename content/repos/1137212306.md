## 它是什么
Humanizer-zh 是以 Markdown 技能文件为核心的中文润色规则，翻译自 blader/humanizer，并结合 stop-slop 的检查清单。它让编码助手检查夸张表述、模糊归因、机械排比、填充词和聊天残留，再改写问题句。仓库本身不提供独立文字处理模型，也不是判断文章作者身份的检测器。

## 适合什么场景
适合修改产品说明、博客草稿和技术介绍，让一句话更直接、减少空洞评价；也可把 SKILL.md 当作人工编辑清单。对数据、引用和实验结论密集的文章，应先确定事实，再处理语言，避免把文风优化当作事实审核。

## 如何开始
已有支持 Skills 的助手时，可按 README 使用 `npx skills add https://github.com/op7418/Humanizer-zh.git`。Claude Code 也可将仓库放入 `~/.claude/skills/humanizer-zh`，确认其中有 SKILL.md，重新加载后调用 `/humanizer-zh`。先提交短段落，说明面向的读者、保留的术语及不能改变的数据，再检查改写前后差异。

## 注意事项与相关项目
README 的部分演示改写增加了原文没有的年限、地点细节或样本量；这些只能理解为文风演示，不能直接作为事实处理方式。中文版本与英文上游会独立变化，当前 README 列出 24 种模式，不能假定规则与英文最新版完全一致。相关项目 blader/humanizer 可用于查看英文原规则与更新。
