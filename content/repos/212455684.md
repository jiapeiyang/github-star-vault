## 它是什么
YABS 是把多种基准工具串起来的 Bash 脚本：fio 测磁盘，iperf3 测网络吞吐，Geekbench 测系统计算性能。它会下载所需的便携二进制；已有 fio、iperf3 时优先用本机版本，因此“免预装依赖”不等于完全离线运行。

## 适合什么场景
验收新 VPS，或在相同时间段、相同参数下比较几台机器。它给出一次运行时的表现，不能凭单次分数判断长期稳定性、国内晚高峰线路或服务商质量。

## 如何开始
先阅读 README 的 How to Run、Flags 和安全说明，再下载并检查脚本。选业务空闲时运行，确认流量与磁盘余量。默认网络测试会尽量打满端口；低流量套餐可用 `-r` 减少节点，或用 `-i` 跳过网络测试。

## 一个使用示例
官方参数整理，未执行：将审核过的脚本保存为 `yabs.sh` 后运行 `bash yabs.sh -i`。预期保留磁盘和 Geekbench 测试、跳过 iperf3；对比时记录工具版本、测试时间、虚拟化环境及是否用了本机依赖。

## 注意事项与相关项目
测速会消耗真实带宽与计算资源，外部二进制也需要信任判断。ARM 在 README 中仍标为实验性。NodeQuality 更偏向整合与整理报告，ECS 覆盖更多线路和 IP 检查；三者的测试项目与分数口径不能直接混用。
