## 它是什么
Egg 是面向 Node 应用的框架，提供进程管理、插件体系和定制框架能力。当前仓库采用 monorepo，主框架在 packages/egg，另有 CommonJS 与 TypeScript 示例及文档站点。它给服务端项目提供一套组织和扩展方式，与只提供中间件内核的 Koa 相比，涵盖更多应用层约定。

## 适合什么场景
适合希望以统一结构开发 Node 服务、让多个项目复用插件或内部框架的团队。只需要极小 HTTP 服务时，这些约定未必必要；选择前应看自己的部署与扩展需求。

## 如何开始
当前 README Quickstart 要求 Node >=22.18.0，并采用 utoo：先按文档启用工具，在空目录用 ut create egg@beta 创建项目，再 ut install、ut run dev。文档预期应用地址为 localhost:7001。这里的 beta 和 Node 下限应与所选版本一起理解，不要混用旧教程命令。
