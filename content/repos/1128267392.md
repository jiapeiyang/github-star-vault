## 它是什么
Huobao Drama 把文本改写、角色场景提取、分镜拆解、图片提示词和视频任务组织成短剧生产流程。当前 README 描述的是 TypeScript 全栈版本：前端 Nuxt/Vue，后端 Hono、Drizzle 与 Mastra，SQLite 保存结构化资料，生成文件保存到素材目录，并新增 Electron 桌面入口。

四类 Agent 各负责一个制作环节，因此可以回看角色与分镜再推进生成，而不是把全部任务混在一次聊天中。文本、图片和视频能力来自配置的模型服务。

## 适合什么场景
把已有小说片段改成短剧分镜；统一管理角色素材和批量视频任务；试验不同文本、生图与视频模型的组合。

## 如何开始
个人使用可从 Releases 选择 macOS 或 Windows 桌面包；当前说明这些安装包未签名。源码运行要求 Node.js 20 以上与 npm 9 以上，数据库已内置 SQLite，无需另装 MySQL；也可按新版 Docker 方案启动。开发模式分别安装前后端依赖，运行各自的 `npm run dev`，前端默认在 3013，后端在 5679。打开设置页配置实际使用的模型与连通性，再建立剧集。当前版本通过 npm 包带入 FFmpeg 二进制。

## 一个使用示例
官方流程改写，未执行：输入一段两个人物对话，让系统改写剧本并提取角色、场景；先检查角色图，再生成分镜和单镜头视频，最后通过 FFmpeg 拼接整集。预期获得可追踪的素材与视频任务，角色一致性和剪辑质量仍需人工检查。

## 注意事项与相关项目
模型 Key 存在应用数据库，数据库和素材都需按部署方案维护。公网参考素材地址要能被上游模型读取；本地路径不是可直接传给云模型的 URL。当前 README 已发生技术栈及数据库迁移，旧 Go 与 MySQL 部署教程不应直接套用。生成服务可能收费，广告套餐不是技术前提。

旧 MySQL 数据导入仅覆盖数据库行，历史图片和视频仍需另行迁移；显式配置 MySQL 且 SQLite 为空时可能触发启动导入。Docker Compose 新增 Watchtower 更新入口，使用前确认容器更新范围。桌面端引用本地素材生成 Seedance 视频仍受公网地址要求限制。项目采用 CC BY-NC-SA 4.0，商业用途需核对作者授权。
