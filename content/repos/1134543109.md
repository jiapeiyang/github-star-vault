## 它是什么
skills 是开放技能生态的 CLI，接受 GitHub 简写、Git URL、具体技能路径和本地目录，把选中的 `SKILL.md` 及配套文件放到对应宿主位置。它负责分发和发现，不直接提供每个技能的业务能力。

除了持久安装，`skills use` 可把技能放到临时目录并生成启动提示，或启动支持的代理。因此“试用一次”和“全局安装”有不同范围。

## 适合什么场景
同一套技能需要用于多个客户端；想先列出仓库内技能再挑选；测试一个技能但不想永久写入配置；维护私有团队技能仓库。

## 如何开始
通过 npx 调用，先用 `skills add` 的列表或选择界面核对内容，再确定宿主和项目/全局范围。私有仓库使用已经配置的 Git 或 gh 认证，不应把令牌写进命令 URL。安装后确认宿主发现了正确目录及配套 references。

## 一个使用示例
官方路径改写，未执行：使用 `npx skills add vercel-labs/agent-skills`，只选择 web-design-guidelines 安装到当前项目，再请求代理审查某个表单。预期 CLI 完成文件分发，实际审查仍由宿主加载技能后执行。

## 注意事项与相关项目
仓库入口可包含多个技能或嵌套目录，应核对选择结果，不能只看到安装成功就认定全部文件齐全。更新可能改变行为，第三方技能的命令与权限需阅读。vercel-labs/agent-skills 是具体内容库，本仓库是安装工具。
