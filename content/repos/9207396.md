## 它是什么
Node-Excel-Export 对应 npm 包 excel-export，用工作表配置和二维数组生成 XLSX。cols 描述表头、类型与可选宽度，rows 保存每行数据，execute 接受单个配置或配置数组以输出单表或多表。它适合把应用已经整理好的记录导出，不是一个完整 Excel 编辑器。

## 适合什么场景
适合旧 Node 报表接口生成简单表格，或研究如何把列定义与单元格转换分开。数据需要先明确类型和列顺序；若目标是读取已有文件、复杂图表或保留公式格式，应另查支持范围。

## 如何开始
以 require('excel-export') 获取模块，准备 name、cols 和 rows，每行长度应与列数一致。支持的列类型包括 string、date、bool、number。需要定制单元格值时使用 beforeCellWrite；样式不是自动推断的，需提供有效的 styles.xml 和对应索引。

## 一个使用示例
官方接口改写，未执行：
```js
const nodeExcel = require('excel-export');
const result = nodeExcel.execute({
  name: 'Report',
  cols: [{ caption: 'Name', type: 'string' }],
  rows: [['Alice'], ['Bob']]
});
```
预期 result 是可用于生成 XLSX 响应的二进制结果。完整下载接口还需按环境设置响应头并输出，本文未启动 Express 或写入文件。

## 注意事项与相关项目
README 的日期示例手动换算 Excel 日期序列，时区和空值必须按实际数据确认。beforeCellWrite 返回值决定写入内容，styleIndex 则必须匹配样式文件。原文使用较早 Express 响应写法，接入现代服务时需核对类型与编码；导出成功仍应回读验证行列和值。
