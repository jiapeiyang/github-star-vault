## 它是什么
WebCodex 连接支持 MCP 的助手与用户自己机器上的工程、Git 和命令工具，让仓库留在原来的开发环境。README 将 Desktop、CLI、Server 与 Runner 的安装和工作方式分开说明。

## 适合什么场景
需要助手使用本机真实工具链；工程不适合搬入托管工作区；希望观察长任务与 Git 差异，并明确允许访问的项目范围。

## 如何开始
先选单机或多机模式，再阅读统一安装与部署验收状态。当前 README 明确统一安装流程仍在开发，多平台原生安装、重启和升级尚未全部验收。临时单仓库试用另有 Quick Trial 文档，不能把源码预览当成正式发布包。

工具结果和所请求的文件内容可能返回 AI 客户端。只登记获授权的根目录，凭据不写入提示、日志或 Git。产品连接能力不等于额外模型额度或质量保证，多平台一致行为也没有在本站验证。
