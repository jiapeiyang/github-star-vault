## 它是什么
Yazi 是用 Rust 编写的终端文件管理器。它把目录浏览、文件预览、选择和复制等操作放在同一个终端界面中，并用异步 I/O 与任务调度减少长操作对界面的阻塞。对于经常在 shell 中工作的开发者，它能减少反复切换终端和图形文件管理器的次数。

除了普通目录，仓库还提供插件、主题、任务管理和多标签能力，并可集成 fd、ripgrep、fzf、zoxide 等工具。它不是一个新的 shell；退出 Yazi 后是否改变外层终端的工作目录，取决于你是否配置了官方推荐的 shell wrapper。

## 适合什么场景
- 在终端中快速浏览项目目录、预览文本和选取多个文件。
- 根据文件名或内容定位资料，再打开到外部编辑器。
- 需要可定制的键盘操作和预览方式，不希望每次都手工拼接 shell 命令。

图片、PDF 或视频预览涉及终端协议和可选依赖，不能仅凭主程序安装成功就推断所有格式都能预览。

## 如何开始
1. 从官方 Installation 页面选择系统对应的安装方式。例如 macOS 的 Homebrew 可安装 yazi，再按所需预览能力补充可选依赖。
2. 在终端运行下面的命令，进入当前目录的文件界面。
3. 用方向键或 h/j/k/l 浏览；按 F1 或 `~` 查看帮助，按 q 退出。
4. 只有希望退出后外层 shell 跟随目录变化时，再安装文档中与你的 shell 对应的 y wrapper。

```shell
yazi
```

## 一个使用示例
目标是在一个示例目录中找到文本文件，并复制到另一个子目录：

1. 用上下方向键选中文件，按 Enter 使用配置的打开方式查看内容。
2. 需要批量选择时按 Space；按 y 暂存要复制的文件。
3. 用左右方向键进入目标目录，按 p 粘贴。
4. 如果只想取得路径，可按 c 再按 c 复制当前文件路径。

这些按键已对照官方 26.9.1 Quick Start，本站未启动 Yazi 实测。不要混淆普通粘贴 p 与会覆盖目标的 P；首次尝试可使用演示文件。

## 注意事项与相关项目
README 将项目描述为持续开发的 Public beta，配置和插件可能发生不兼容变化。Windows 文档对 file.exe 的来源和 YAZI_FILE_ONE 有额外说明，应按当前安装文档配置。终端是否支持图像协议，也会改变图片预览效果。需要跨设备传文件时可查看 LocalSend；Yazi 的主要入口仍是终端中的文件操作。
