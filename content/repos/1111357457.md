## 它是什么
Netcatty 以 Electron、React 和 xterm.js 构建 SSH 工作空间，把远端终端、SFTP 文件浏览、主机资料和主题放在一起。内置 Catty Agent 可根据服务器上下文查询状态、读取日志或执行多主机任务。

手动终端和 AI 操作共用真实远端连接，因此它既是 SSH 客户端，也是运维代理入口；应用展示方便不等于命令没有服务器副作用。

## 适合什么场景
常在多台服务器之间切换；需要同时看终端与远端文件；希望用自然语言做有范围的状态诊断，再回看实际输出。

## 如何开始
从 Releases 下载 macOS、Windows 或 Linux 对应架构版本。添加自己有权访问的 SSH 主机，核对主机与认证后连接，先熟悉分屏和 SFTP。AI 功能另需按应用配置模型。Windows portable 的 `data` 目录可携带资料，但保存的密钥仍受创建它的 Windows 账号保护。

## 注意事项与相关项目
远端路径和批量主机选择应在操作前确认。便携目录迁移不保证密钥可在另一账号直接解密。Tailscale 可解决部分网络可达性，Netcatty 负责已经可达主机上的 SSH 与文件操作。
