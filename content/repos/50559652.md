## 它是什么
vue-progressbar 为 Vue 1.x 或 2.x 页面提供可控制的进度条，常用来提示路由切换或数据加载过程。插件暴露 this.$Progress 的 start、finish、fail、set 等方法，并允许颜色、位置、厚度与过渡配置。它显示的是应用通知的进度状态，不会自动测量所有网络请求的真实完成比例。

## 适合什么场景
适合旧 Vue 单页应用在导航或请求时给用户反馈，或者需要轻量页面顶部加载条的场景。若任务需要精确上传百分比，应从实际传输进度计算，再显式更新条值。

## 如何开始
先确认 Vue 版本，安装 vue-progressbar 并 Vue.use 注册配置，再在根组件放置 vue-progress-bar。根据 README，可在 router.beforeEach 调用 start，在 afterEach 调用 finish；独立异步任务则在成功和失败分支分别结束。

## 一个使用示例
官方 API 使用路径改写，未执行：用户请求一份列表时，先 this.$Progress.start()，请求成功后 finish()，失败后 fail()。预期加载条能区分等待和失败，不会因为请求异常永远停在途中；具体请求函数由应用实现，这里没有访问 README 中的旧示例 API。

## 注意事项与相关项目
路由完成不一定意味着所有页面数据加载完，应用应明确进度条代表哪件事。多个请求并发时，单个请求先结束可能使全局条过早结束，不能直接把每次响应都等同全部完成。README 的 Vue 1/2 与旧 vue-resource 示例不适用于 Vue 3 原样接入。
