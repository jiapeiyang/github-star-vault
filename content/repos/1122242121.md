## 它是什么
HAPI 为运行在工作机上的编码智能体会话提供远程控制入口。README 将它描述为本地优先的包装层：保留原来的 Claude Code、Codex 等客户端，在原生 iOS/Android 客户端、Web、PWA 或 Telegram Mini App 中查看和接续会话。

可以把它理解为“工作机上的会话 + 连接会话的 Hub + 远程界面”。真正的终端、文件和编码工具仍位于工作机上，手机只是控制入口。它是第三方项目，不是所列模型或编码工具厂商的官方远程客户端。

## 适合什么场景
离开电脑后希望查看任务进展，或在另一台设备上接续已经启动的编码会话时，可以考察这个项目。它也提供可选的工作区浏览功能，通过 runner 的 workspace-root 参数限定可浏览的目录。单纯跨设备复制文件则不需要这样一个远程终端系统。

## 如何开始
1. 先确认工作机已经具备需要运行的编码客户端及其正常使用条件。
2. 阅读上游 Installation、How it Works 和具体 Agent 说明，区分中继与自托管方式。
3. 根据 README 启动 Hub 与会话入口。
4. 在终端展示的 URL 或二维码处连接，确认控制的是预期工作机。

```shell
npx @twsxtd/hapi hub --relay
npx @twsxtd/hapi
```

## 一个使用示例
目标是在离开电脑后查看一个正在运行的编码任务：在工作机按官方流程启动服务和客户端，使用手机打开终端给出的连接地址，查看会话消息与待处理请求，再按实际需要回应。

预期远程界面继续控制工作机上的会话，而不是在手机上重新运行一份代码库。以上是 README 的使用流程说明，本站没有启动 Hub、建立远程连接或验证中继加密实现。

## 注意事项与相关项目
远程批准命令会影响工作机中的文件和进程，连接链接及二维码不应公开分享。README 对中继加密的说明属于上游声明，不能代替独立安全验证。当前 README 已列出原生 iOS/Android 客户端的聊天、批准、文件和推送等能力，并给出构建指南；这不等于本站核实了应用商店上架。原生配对使用 companion QR，与 Web 二维码区分。

当前不带参数的 `hapi` 会选择代理；脚本中应显式写 `hapi claude` 或 `hapi codex`。终端和手机共享 Codex 会话要求 Codex 0.154.0+，具体限制按上游专项指南核对。
