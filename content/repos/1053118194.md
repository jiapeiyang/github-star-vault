## 它是什么
《深入理解 AI Agent：设计原理与工程实践》以“LLM + 上下文 + 工具”为线索，将原理、交互、评估、后训练与工程实践串成十章，配有实验和外部复现入口。当前 README 标注书稿 2.0，部分章节已重组。

书籍、章节实验和外部研究仓库是不同层次：阅读不需要装完整环境，代码仓库存在也不代表所有实验已完成验证。

## 适合什么场景
按主题查上下文组织与工具调用原理；构建 Agent 前补齐评估方法；想找到一个可阅读的小实验对照书中概念。

## 如何开始
从在线站点全文搜索，或下载当前 PDF/EPUB；需要固定版本时使用 Releases。要运行实验，先看对应目录 README，再按章节选择依赖。第一章官方提供 `uv sync --locked --extra ch1`，模型凭据与额外系统依赖按实验分别配置。

## 一个使用示例
官方命令摘录，未执行：完成第一章依赖及其配置后，从仓库根目录运行 `uv run python chapter1/context/main.py`，结合章节观察上下文如何影响模型行为。预期获得该实验输出；具体效果由所用模型与配置决定，本站没有运行模型调用。

## 注意事项与相关项目
`all` extra 不包含所有训练和硬件路径；第八章部分组件要求更高 Python 版本。应同时看 `docs/EXPERIMENT_STATUS.md`，区分本地项目与外部复现轨道。hello-agents 也提供 Agent 教程，可按具体章节内容选择。
