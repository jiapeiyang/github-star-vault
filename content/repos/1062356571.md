## 它是什么
Mole 是 macOS 的终端维护工具，集中提供磁盘分析、缓存与残留清理、应用卸载、开发产物清理和系统状态查看。通过 `mo` 进入交互菜单，也可直接使用子命令处理某一类任务。

理解它时应区分“查看”和“修改”：`status` 展示资源状态，`analyze` 浏览磁盘占用；clean、uninstall、purge 等会针对不同目录或应用执行清理。README 另有原生 Mac 应用入口，商业应用与这个免费开源 CLI 的分发方式不同。

## 适合什么场景
Mac 磁盘空间不足、想知道大文件在哪里，或删除应用后希望查看残留时，可以从分析和预览入口开始。开发者可用 purge 查看项目构建产物，但不能把所有缓存、依赖和临时文件都视为可以无条件删除的数据。

## 如何开始
1. 在 macOS 上按 README 选择安装方式；已有 Homebrew 时可使用官方列出的包。
2. 运行 `mo` 查看菜单，或先使用 `mo status` 观察系统状态。
3. 需要清理时先使用相应的 `--dry-run` 预览，核对路径与跳过原因。
4. 有需要保留的缓存时，通过上游白名单入口配置，再决定实际执行范围。

```shell
brew install mole
mo clean --dry-run
```

## 一个使用示例
目标是弄清“清理将涉及哪些缓存”，而不是立即腾出空间：运行上面的预览命令，阅读候选目录、体积和跳过原因；对于仍被应用使用或需要保留的内容，先调整选择或白名单。

预期得到清理计划，预览本身不应被表述为已释放多少磁盘。命令来自 README，本站未安装、预览或删除任何文件，也未核验特定机器上的回收体积。

## 注意事项与相关项目
README 说明 `mo analyze` 的交互操作也可以在确认后将条目移到废纸篓，因此不能把整个磁盘浏览界面概括为永远只读。系统路径操作可能请求管理员权限。Windows 分支在所查资料中仍是实验性状态，不应套用 macOS 支持结论。awesome-mac 可用于查找其他磁盘分析工具，但其收录不代表功能和清理规则一致。
