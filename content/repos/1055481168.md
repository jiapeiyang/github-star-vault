## 它是什么
Aether 是面向个人和团队的 AI API 网关，提供 Claude、OpenAI、Gemini 等接口的统一接入、格式转换、负载分配、成本配额和健康监控。客户端连接网关入口，由网关按配置转发到模型提供方；管理后台负责服务配置与使用情况。它并不包含模型推理能力，仍需可用的上游服务。

## 适合什么场景
适合多个客户端共用模型入口、团队集中管理密钥与配额，或需要检查请求为什么失败的场景。只调用单一服务的短脚本未必需要增加这一层。代理、数据库和管理账号都成为需要维护的运行组成。

## 如何开始
当前 README 推荐 Docker Compose 预构建镜像。取得代码后复制 .env.example，限制 .env 权限，使用 generate_keys.sh 生成独立密钥并配置 ADMIN_PASSWORD，再按所选 Compose 文件启动。当前标准和 Single Node 都使用 PostgreSQL 与 Redis；旧教程中的本地数据库假设不再适用。先查看容器日志，再通过管理后台配置上游。

## 注意事项与相关项目
升级时必须保留 PostgreSQL 密码、JWT_SECRET_KEY 和 ENCRYPTION_KEY，README 明确不要重新生成整份 .env。Nightly 是预发布通道，不能当作正式版稳定性承诺。CLIProxyAPI 与 new-api 也是收藏中的网关类项目，比较时应看自己需要的协议、凭据方式与管理功能。
