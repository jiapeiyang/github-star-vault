## 它是什么
React Developer Roadmap 是面向 2019 年 React 生态的路线图与资源目录，README 明确写出年份。它从 HTML/CSS/JavaScript、HTTP、Git 和命令行等基础，延伸到 React、构建、样式、状态、类型、表单与路由。作用是展示周边领域及候选工具，帮助理解一个应用包含哪些方面。

## 适合什么场景
适合回顾 React 工程生态的组成、找回一个曾见过的库，或判断某工具属于状态管理还是表单、路由问题。它不要求把所有分支全部采用，也不适合作为今天逐项必学的清单。

## 如何开始
先看路线图建立大类，再沿 Resources 找对应官方链接。已经有具体项目问题时，只选择相关分支，例如表单或类型检查。比较工具前先确定功能需求、依赖约束和维护状态；README 自己也提醒流行并不等于适合。

## 注意事项与相关项目
目录包括旧 React 文档、Redux Form、Flow、Gulp 等历史生态选项，2019 年语境必须保留。图示没有覆盖此后 React 的所有能力演进，链接中的 API 也可能已更换。与 fks 相比，它聚焦 React 周边；与框架官方文档相比，它是二次组织的导航而非使用契约。
