## 它是什么
这是 soulmachine 整理的 LeetCode 题解书，提供在线阅读和 C++ PDF，也保留 Java 版本目录。仓库同时存放排版源码，可用 LaTeX 生成书籍。它的使用形态更接近一本可离线查阅的算法参考书，而不是自动提交题目或在线评测的工具。

## 适合什么场景
适合喜欢按书籍结构阅读题解、查找 C++ 实现，或想在离线环境浏览算法资料。对 Java 读者需留意 README 明确说该版本仍在编写，不能假定与 C++ 一样完整。

## 如何开始
直接阅读时优先打开 README 的在线阅读链接或 C++ PDF，无需安装 TeX。只有修改书稿并重新生成 PDF 才需要编译环境。上游给出 Docker 命令，也配置了 VS Code devcontainer：在容器重开仓库后，通过 Run Task 选择 leetcode-C++ 构建。

## 一个使用示例
官方流程改写，未执行：需要修正一处 C++ 题解排版时，先打开对应源文件修改，再在 devcontainer 中运行 leetcode-C++ 任务，打开生成的 PDF 对照代码换行与公式。预期得到修改后的书稿，不能把 PDF 构建通过当作题解算法已通过在线评测。

## 注意事项与相关项目
容器方案使用 Tex Live 2022 和所需字体，普通主机未装字体时直接编译可能出现排版差异。README 对模板及字体另有来源说明；本条没有下载字体或编译 PDF。与网页式题解仓库相比，它更重视连续阅读和印刷输出，当前题目接口仍需回到对应题目核对。
