## 它是什么
ivideo 是一个 Electron 视频客户端项目，用 React 和 Redux 组织界面，汇集多个视频站点入口，并提供播放接口选择。README 展示的是早期桌面应用的技术形态与操作截图，发行链接主要指向 1.1.4，Linux 链接更早。它不是各视频平台的官方客户端。

## 适合什么场景
适合回顾 Electron/React 时代的桌面应用组织、查看播放器壳如何管理状态，或研究多站点导航界面。内容可用性和平台授权由视频来源决定，不能因为客户端展示某个入口就推断有权播放或再分发。

## 如何开始
先阅读技术栈和仓库结构，再按历史版本理解构建。README 的开发路线为 yarn install、yarn start，打包命令包括 yarn package 与分平台命令，产物在 release。若研究源码，使用隔离目录和自己有权使用的本地或公开视频，不需要调用第三方解析线路。

## 注意事项与相关项目
README 的 VIP 播放宣传不能作为可用性或授权证明，旧线路很可能已经改变。Node 7.6 的要求是当时环境，不建议为日常使用安装过时运行时。相关 electron-react-boilerplate 是其脚手架基础，可用于比较现代桌面项目结构。
