## 它是什么

v2rayN 是桌面代理客户端，用图形界面组织连接配置，并调用 Xray、sing-box 等核心执行网络连接。客户端、核心和服务端配置是不同部分：安装客户端不会自动得到可用服务。

## 适合什么场景

- 已有合法可用的连接配置，希望在 Windows、Linux 或 macOS 上集中管理。
- 需要先按系统和 CPU 架构选择发行包，再按 Wiki 调整核心与配置。
- 希望通过界面观察连接，而不是直接管理核心的命令行参数。

## 如何开始

1. 从官方 Releases 进入发布文件介绍，核对系统版本、架构和所需运行时；不要只按下载次数选压缩包。
2. 下载对应发行包，按 README 的 GPG 校验说明核验来源。
3. 根据 Wiki 导入自己管理或获授权使用的配置，确认所选核心支持对应协议，再检查连接结果。

## 一个使用示例

官方流程归纳，未执行：目标是在 Windows 上使用已有 Xray 配置。先选择匹配架构的发行包，再按 Wiki 添加配置并选择对应核心；预期能在客户端中看到条目及连接状态。配置出现不等于远端握手成功，实际可用性还取决于服务端、网络和凭据。

## 注意事项与相关项目

README 当前列出 Windows、Linux、macOS；移动端另指向 v2rayNG。各系统支持的架构并不相同。订阅中可能含凭据，不应放进公开仓库；本条没有测试节点、连通性或各平台安装。Clash Verge Rev 可作为另一种配置体系的桌面入口。
