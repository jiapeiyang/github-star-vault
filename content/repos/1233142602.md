## 它是什么
PriceAI 是购买前的信息比较网站和开源工程，将官方订阅、卡网订阅、官方 API、中转 API 分开呈现，并提供接口检测入口。价格、库存、充值系数和模型倍率有不同含义，不能只把页面最低数字当作最终成本。

## 适合什么场景
了解不同购买方式、寻找公开报价的原始来源，或研究比价网站的实现。它不参与交易、不收款，也不担保渠道售后与持续可用性。

## 如何开始
只阅读资料可先看公开站点的分类与更新时间。开发者可克隆项目，按 README 执行 `npm install`、`npm run dev`，默认访问 `http://localhost:3000`。未配置 Supabase 时使用内置演示数据；完整部署还需逐项阅读环境配置。

## 一个使用示例
阅读场景示例，未执行：比较同一产品的官方订阅和第三方报价，分别记录账号归属、交付形式、地区、更新时间和原站链接。结果应是一张可核对的信息表，而不是自动生成购买或充值决定。

## 注意事项与相关项目
聚合报价不等于实时库存或供应商信誉证明，模型检测报告也不能保证服务始终使用同一上游。API 检测可能向第三方提交请求和临时凭据，使用前需核对接收方、费用及授权。本轮没有检查在线报价或调用检测服务。
