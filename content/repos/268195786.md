## 它是什么
just-react 对应《React 技术揭秘》，从设计理念讲到 Fiber，再进入 render、commit、Diff、状态更新、Hooks 和并发机制。它采用自顶向下的阅读顺序，帮助把日常 API 放回内部流程理解。README 主要是入口，详细章节保存在 docs。

## 适合什么场景
适合已经使用 React，想弄清渲染与提交各自做什么，或看源码时缺少整体路线的人。想亲手从零搭一个实现则可配合同作者 big-react；本仓库更侧重讲解与原始材料引用。

## 如何开始
打开 README 的在线阅读站，也可直接读 docs/index.md。先看 preparation 中的架构与文件结构，再选 process、renderer、diff 或 hooks 等目录。所查导言明确标注 React v17.0.0-alpha，因此遇到现代 React 的行为差异，应另查对应版本源码与文档。
