## 它是什么
Herdr 是面向编码代理的终端运行环境，以后台服务持有终端，前端负责重新连接、分屏和切换。Claude Code、Codex、OpenCode 等仍是原来的程序，Herdr 负责承载它们的终端，并显示 working、blocked、idle 等状态。

它提供 tmux 风格快捷键，也支持鼠标操作；CLI 和 socket API 让代理能够创建面板、发送任务并等待其他任务需要处理。项目采用 Rust 二进制形态，不要求 Electron 桌面壳。

## 适合什么场景
一个项目里同时运行实现、审查和日志终端；离开终端后重新接入原工作区；希望快速发现哪个代理在等待输入。已有代理订阅和配置仍由对应工具管理。

## 如何开始
按 README 选择发行二进制或包管理器，macOS 可使用 `brew install herdr`。进入项目目录运行 `herdr`，然后在面板里启动现有代理。先熟悉 Quick Start 的分屏和切换方式，再按需要接入代理技能或远程文档。无需一开始启用所有插件。

## 一个使用示例
官方流程改写，未执行：在仓库目录启动 Herdr，一个面板运行编码代理，另一个查看测试输出；用 `Ctrl+b q` 脱离，再运行 `herdr` 重新连接。预期回到已有会话和输出，而不是重新创建所有终端。

## 注意事项与相关项目
状态指示是调度线索，不能代替查看实际 diff 和测试结果。脱离客户端与关闭主机不是同一事件；重启后的恢复范围需查 session state 文档，不能推断进程跨关机持续计算。tmux 提供通用终端复用，Herdr 增加代理协作语义。
