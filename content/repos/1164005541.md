## 它是什么
VibeSkills 在大量本地技能中先做发现和候选筛选，再把选中的技能分配到具体任务与交付物。流程覆盖需求确认、计划、执行记录和最终验收，避免按几个关键词随意触发技能。

它提供 L 和 XL 两种工作粒度，并保存任务记录，使后续会话可以继续。发现技能只表示可供选择，不代表它已经执行或任务已经完成。

## 适合什么场景
安装很多技能却难以选择；一个任务跨数据、报告和演示多个领域；需要追踪哪些步骤完成、失败或缺少输入。

## 如何开始
从 README 的 Simple install 进入当前宿主安装说明，再通过技能入口以 `$vibe`、`/vibe` 或宿主支持语法调用。补充实际技能目录与任务目标，核对推荐的 L/XL、分工及预期输出后推进。额外目录可在 `skill-roots.json` 中配置，具体路径按项目或用户范围选择。
