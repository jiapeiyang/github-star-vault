## 它是什么
Grok Build 提供名为 grok 的全屏终端编码代理，也支持无头运行与 ACP 编辑器接入。仓库包含 TUI、代理运行时、工具与工作区管理的 Rust 源码，并用 SOURCE_REV 记录同步来源版本。

## 适合什么场景
在终端中查阅和修改代码；将代理放入脚本流程；研究编码代理的运行时、工具与界面分层。

## 如何开始
从 README 的发布二进制安装入口和 x.ai/cli 文档开始，先核对系统、发行版本与身份验证。源码构建另需 Rust、DotSlash 与 protoc；构建入口是 xai-grok-pager-bin，不能将发布包安装与源码构建的前提混为一谈。
