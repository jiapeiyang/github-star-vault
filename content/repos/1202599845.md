## 它是什么
Khazix Skills 汇集作者的独立技能，每个目录处理一种任务。leader 帮助把模糊意图写成目标任务书，aihot 查询集中资讯，storage-analyzer 分析磁盘占用，neat-freak 对齐工程文档，hv-analysis 生成横纵研究，khazix-writer 处理特定写作风格。

## 适合什么场景
适合按明确需求补充一项代理能力，例如想定义长任务的验收条件、查 AI 资讯，或弄清磁盘大目录是什么。各技能的数据来源和动作范围不同，不能只因同属一个仓库就赋予整机清理、记忆修改或外部发送权限。

## 如何开始
从 README 目录选择具体技能，进入对应 SKILL.md，核对引用文件与所需工具。README 支持把具体子目录链接交给兼容 Skills 的宿主安装；不支持自动发现时也可将文件作为当前任务参考。先提供要处理的项目或素材，再采用对应入口。

## 一个使用示例
官方 leader 流程归纳，未执行：提出“让代理完成一个导出功能”，先查真实代码和命令，再明确目的、完成态、证据、禁止取巧的路径、范围、取舍和未知项。预期产物是可直接交给执行代理的 Markdown 任务书，不能用“测试变绿”替代真实功能达成。

## 注意事项与相关项目
storage-analyzer 中扫描与删除是不同动作，清理前要读具体路径和影响；neat-freak 涉及文档与规则更新，也需保留已有约定。作者列出的模型选择、耗时与实测范围属于个人经验，不能作为所有环境的保证。
