## 它是什么
gsap-skills 是 GSAP 上游发布的代理技能与参考示例，分别组织核心 API、时间线、ScrollTrigger、插件、React 接入和性能等主题。技能提供使用指导，实际动画运行仍依赖项目中的 GSAP 库。

## 适合什么场景
让代理采用正确的动画 API；检查时间线或滚动触发逻辑；在组件卸载时处理动画清理。

## 如何开始
README 的技能安装入口为 npx skills add https://github.com/greensock/gsap-skills。确认宿主技能位置后，按任务读取对应主题；项目的 GSAP 依赖与插件注册仍需单独核对。Copilot 的仓库指令与普通 Skill 加载方式也不同。

## 一个使用示例
官方主题改写，未执行：在已有 React 页面中要求代理实现一个带作用域的动画，说明组件卸载时如何清理，再检查重复挂载和滚动刷新。预期得到实现与检查步骤；本文未安装技能或运行动画。

## 注意事项与相关项目
不要为了技能安装替换用户已选的动画库。README 的许可与免费使用描述仍需结合实际采用的库版本和条款，本文未独立验证全部插件。Canvas UI 提供视觉组件，本仓库主要组织动画实现知识。
