## 它是什么
DESIGN.md 是向编码代理描述视觉身份的文件格式：将机器可读的颜色、字体、间距等设计值与人能理解的设计理由放在同一份 Markdown 中。仓库还提供 CLI，用于校验引用、结构和对比度，比较两个设计文件及导出令牌。

## 适合什么场景
希望多次改版或多人协作时，代理仍遵循同一套视觉约定；也适合把散落的设计值整理为可检查的文件。它描述设计系统，不自动保证每一张页面都符合品牌要求。

## 如何开始
从 README 的格式样例开始，填入自己已确认的颜色、字号与设计理由，不要将示例品牌直接当成项目标准。使用 Node／npm 环境按文档安装 CLI，先校验一个小文件，再逐步补组件令牌。

## 一个使用示例
官方命令示例，未执行：运行 `npx @google/design.md lint DESIGN.md`，检查返回的结构化 findings，修正不存在的令牌引用或结构错误。再用 `diff` 比较修改前后，确认变更范围；通过校验仍需查看实际页面。

## 注意事项与相关项目
格式与 CLI 当前处于 alpha，字段和行为可能变化。Windows shell 对包名与 `.md` 后缀可能有特殊处理，按 README 的显式调用方式排查。diagram-design 用设计规范生成图示，与此格式有相近用途，但不能默认认为二者文件直接互通。
