## 它是什么
ELI5 是一个面向 Claude Code 的解释技能。名字来自“像对五岁孩子解释”，实际受众也包括学生、经理、工程师、设计师和家人。它从请求中识别解释对象，调整词汇、类比、语气、细节深度和叙述重点。

例如面向经理时更关注影响与风险，面向工程师时可保留架构和技术细节，面向儿童时用熟悉的生活类比。它提供解释方法与评估用例，事实准确性仍取决于原始材料和模型判断。

## 适合什么场景
- 把技术方案讲给没有相同技术背景的同事。
- 阅读代码或错误信息时，需要按自身基础拆解。
- 为同一个主题准备不同受众版本，比较哪些细节应保留。

## 如何开始
README 的安装方式是克隆仓库，再将 `ELI5/skills/eli5` 复制到 `~/.claude/skills/eli5`。准备已配置的 Claude Code；已有同名技能时应先核对版本，避免覆盖本地修改。

随后给出需要解释的代码、概念或错误，并明确对象，例如“向产品经理解释这次数据库索引调整”。上游还提供 `eli5-workspace/run-evals.py`，可对有技能和无技能两种输出进行评估；这会调用 Claude，不是纯离线测试。

## 一个使用示例
官方主题改写，未执行：输入“向五年级学生解释数据库索引，先用图书目录作类比，再说这个类比哪里不完全准确”。

预期输出能说明索引帮助定位内容，同时避免把索引描述成完全没有存储和维护成本。再把对象改成经理，检查说明是否转向查询速度、维护成本和使用条件。这里给出的是验收思路，不是模型的真实运行结果。
