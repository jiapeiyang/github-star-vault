## 它是什么
GuJumpgate 曾在 FlowPilot 基础上适配账号注册、OAuth 回调、邮箱助手和支付相关自动化。上游明确自 2026-07-11 停止维护，之后不再提供排错、兼容更新或安全修复。

这是一份历史代码资料。README 下方列出的流程、测试环境和安装步骤已被开头的停维说明限定，不能解读为今天仍然有效。

## 适合什么场景
回顾浏览器扩展如何组织多阶段任务；研究外部页面变化如何导致自动化失效；检查本地 helper 与扩展之间的交接方式。不适合继续投入真实账号或支付环境。

## 如何开始
先阅读停维公告与版权来源说明，再静态查看文件结构、消息边界和状态迁移。需要研究代码时使用隔离目录，不导入真实凭据，也不连接原支付链路；把历史测试记录和当前观察分开。

## 一个使用示例
资料阅读示例，未执行：沿 README 中“扩展侧边栏 → 本地助手 → JSON 导出”的描述定位相关模块，画出哪些步骤依赖第三方页面，记录失效风险。预期获得历史实现的结构理解，而不是尝试恢复注册或支付自动化。
