## 它是什么
oh-my-opencode-slim 由 Orchestrator 组织 Explorer、Oracle、Council、Librarian、Designer 和 Fixer 等角色，负责仓库探索、文档、设计和范围明确的实现。工作以后台任务分发，再由主控汇总结果。

它允许不同角色使用不同模型，并提供运行时 preset 切换、LSP/搜索工具和可选终端复用器展示。不是所有角色都必须在每次任务中运行。

## 适合什么场景
一个 OpenCode 任务需要代码探索与新文档查阅并行；希望比较多个模型对同一问题的意见；按角色控制速度与成本。

## 如何开始
按 README 使用 `npx oh-my-opencode-slim@latest install` 或 Bun 安装器，确认 OpenCode 配置和提供商登录。先检查预设中模型是否真实可用，再启动小任务；需要时通过 `/preset` 更换整组配置。

## 注意事项与相关项目
OpenCode v1/v2 的功能矩阵不同，复用器面板等能力并非都跨版本支持。并行调度不隔离外部服务，仍需明确文件范围与权限。完整 oh-my-openagent 提供更广编排，slim 更偏较小角色集合。

README 已转向 V3 Beta 展示并明确预设只是可能过期的指南；安装前核对实际发布版本、模型可用性和 v2.0.x 兼容基线，不照搬旧版固定模型配置。
