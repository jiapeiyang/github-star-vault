## 它是什么
public-apis 是社区维护的公共 API 分类目录。各分类的表格列出用途、认证方式、HTTPS 与 CORS 等信息，帮助开发者先发现候选服务，再进入服务自己的文档。README 还包含 APILayer 商业产品推广，这与广泛的社区 API 清单需要分别理解。

## 适合什么场景
适合做小型原型前寻找天气、动物、图书、地图等数据源，或者确认某类服务是否有公开接口。它本身不是一个统一代理网关，也不会给所有条目提供同一 API key。

## 如何开始
从 Index 选择领域，先看 Auth、HTTPS、CORS 列缩小候选；再打开目标服务的官方文档，核对请求地址、额度、使用条款和返回结构。浏览器端使用尤其要确认 CORS 是否仍被允许，不能仅凭目录的一次标记就直接集成。

## 注意事项与相关项目
“public”不等于免费无限调用，不同服务可能要求账号、付费或限制用途。CORS Unknown 表示目录没有确定信息；即使标 Yes，也需按当前响应复核。API 失效、额度变化与外站认证不由此仓库控制，历史收藏的价值主要在于找回入口。
