## 它是什么
GenericAgent 是一个面向本机操作的智能体框架。README 描述其由较小的 Agent Loop、基础工具与可积累的 Skill 组成，工具范围涵盖终端、文件、真实浏览器、键鼠、屏幕和 ADB。模型决定下一步调用，工具执行后把结果交回循环。

其“自进化”主要指把完成任务的路径整理成后续可复用的 Skill，不代表模型权重被自动训练。浏览器能力通过 TMWebdriver 等组件接入已有浏览器环境；终端界面、Web 界面和无界面调用是不同使用入口。

## 适合什么场景
想研究一个较精简的本机 Agent 如何连接工具、保存操作流程，或者需要把重复文件与浏览器任务交给同一套循环时，可以考察它。它能影响实际系统与登录会话，因此用于试验时应先界定可访问的目录和任务范围。

## 如何开始
1. 阅读 README 的 Quick Start 和中文安装指南。所查版本建议 Python 3.11 或 3.12，明确指出 Python 3.14 与部分界面依赖不兼容。
2. 克隆仓库，用 uv 创建隔离环境，按需要安装含界面的依赖。
3. 从 `mykey_template_en.py` 建立自己的 `mykey.py`，配置所选模型服务；真实密钥不应提交到仓库。
4. 启动终端界面后，先指定一个只读的小任务，检查实际调用和输出。

```shell
python frontends/tui_v3.py
```

这条启动命令要求前述环境与配置已经完成，不能单独替代安装步骤。

## 一个使用示例
准备一个只含测试文本的目录，要求 Agent 列出其中 Markdown 文件的标题并给出对应路径。观察它读取了哪些文件、工具是否报告错误，以及回答能否逐条对应原始内容。

预期得到可核对的文件索引，并看清模型决策与工具执行的边界。这个例子是基于 README 能力范围设计的说明性任务；本站没有启动框架或授权其控制电脑。

## 注意事项与相关项目
代码行数、上下文规模和任务演示属于上游描述，不能作为性能保证。真实浏览器复用登录状态会扩大操作影响，示例成功也不表示其他网站和账号环境同样可用。hello-agents 更适合系统了解 Agent 原理，firstmate 则关注多个编码任务的组织监督，两者与本项目的本机通用执行范围不同。
