## 它是什么
MengTo/Skills 收集设计与开发工作流，每个技能以 `SKILL.md` 和可选参考资料、脚本、资产组成。内容横跨网页设计、Three.js 游戏、UI 和媒体处理，其价值是把一次提示词背后的操作过程保存为可重复读取的文件。

README 重点介绍从录屏提取设计提示词、从 HTML 拆解局部交互、拼接整页截图和每日设计参考收集。它不是单一应用，也不意味着安装后所有模型都具备相同浏览器或图像能力。

## 适合什么场景
已有一段页面录屏，想拆成布局、动画和交互要求；已有 HTML，想只提取一个按钮或 WebGL 效果的实现描述；制作游戏时需要相应玩法与验证清单。按任务挑一个技能，比把整个资料库塞进上下文更容易控制输出。

## 如何开始
从 README 的 Current library 找任务分类，再打开相应 `SKILL.md` 阅读输入要求。以网页流程为例，先准备录屏或页面参考，再选择 `video-to-superprompt` 或 `html-to-interaction-prompts`。按 Codex、Claude 或 Cursor 的目录约定提供完整技能文件夹；仓库 `DEMOS.md` 可用来核对演示与复刻提示词。

## 一个使用示例
官方工作流改写，未执行：把一段产品页滚动录屏交给 Video to Super Prompt，要求记录各区块顺序、排版、滚动触发动画和缺失参考。预期输出是供后续实现使用的详细提示词，随后再由实际开发工具生成 HTML。仅有录屏时不应声称恢复了源站内部实现。

## 注意事项与相关项目
不同技能可能需要浏览器、视频或图像工具，Markdown 文件本身不提供这些能力。应核对素材使用权和交付边界。与 website-rebuild-skill 相比，这里主要帮助提炼设计和复用工作流，后者强调源站代码与行为的取证比对。
