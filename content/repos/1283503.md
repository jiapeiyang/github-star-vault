## 它是什么
Request 是曾广泛使用的 Node HTTP 客户端，以 request(url, callback) 简化请求，并支持 HTTPS、重定向、表单、认证、代理和流式传输。README 首部明确说明从 2020-02-11 起完全弃用，不再预期有新变更。它现在主要用于理解和维护遗留调用，不能当作新项目默认推荐的网络库。

## 适合什么场景
适合排查旧 Node 项目的回调式 HTTP 请求、文件流或代理配置，也适合制定迁移清单。更换客户端前需逐项确认旧代码依赖的行为，尤其是重定向、Cookie、认证和错误返回。

## 如何开始
先在项目中定位 require('request') 与锁定版本，再从 README 对应章节核对 options。普通调用的回调参数为 error、response、body；流式调用需处理 error 事件。Request 本身不是 Promise API，README 对 Promise/async-await 另列包装方案。

## 一个使用示例
官方接口改写，未执行：
```js
const request = require('request');
request('https://example.com', (error, response, body) => {
  if (error) return console.error(error);
  console.log(response.statusCode, body);
});
```
目标是读取响应状态与正文。没有传输错误不代表业务成功，应用仍须按 statusCode 判断；本站未发送该请求。

## 注意事项与相关项目
废弃库不会因旧代码还能运行就恢复维护，底层依赖与服务端协议变化仍可能带来问题。将外部输入直接作为请求目标还涉及地址访问边界，迁移也不能只替换函数名。本文未验证旧依赖的安全性、网络可达性或迁移后的行为等价。
