## 它是什么
Bettbox 是使用 Mihomo 内核的多平台网络工具，重点在客户端体验、分流与 DNS 调试。上游提供 Windows、Linux、macOS、Android 和 Android TV 安装入口；鸿蒙 NEXT 的说明是通过兼容环境使用，并非原生鸿蒙版本。

## 适合什么场景
需要在电脑、手机或电视上管理已有代理配置，或希望用可视界面查看网络行为。它不随软件赠送可用节点，也不证明 README 中推荐的第三方服务可靠。

## 如何开始
前往官方 Releases，核对操作系统最低要求和芯片架构。当前 README 列出 macOS 12+、Android 8+ 等要求；社区 Linux 包应另外核对维护者。安装后先导入自己的配置，在最小范围内确认分流，再决定是否启用系统级代理。

## 一个使用示例
场景示例，未执行：在 Android TV 上选择对应架构安装包，导入自己授权的配置，检查遥控器操作与目标应用的连接结果。先确认设备系统确为 Android，再评估是否使用电视版，不能套用到 webOS 或 Tizen。

## 注意事项与相关项目
数字签名、低资源占用与隐私等说法来自维护方，本站没有独立审计。订阅、日志和连接记录可能包含敏感信息。FlClash 同样围绕 Mihomo，可按实际设备、功能和更新状况选择；这里不提供速度或稳定性排名。
