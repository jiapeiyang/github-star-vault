## 它是什么
MOSS-VL 是以统一 cross-attention 架构组织的 11B 视频语言模型系列。Realtime 接收持续到来的带时间戳画面，允许观察过程中插入问题；Instruct 面向离线长视频对话；Base 提供继续训练的基础模型。

实时版本将感知和文本生成并行处理，还尝试在信息不足时继续观察、画面变化后修正回答。它是模型与推理代码，不是装好就能覆盖所有摄像头场景的桌面应用。

## 适合什么场景
研究连续视频问答、让系统边看演示边回答、比较离线完整视频与实时流推理。普通图片描述也有批处理入口，但部署成本应按实际模型与硬件评估。

## 如何开始
先使用 README 链接的 Hugging Face Space 了解交互。准备本地复现时，官方环境示例使用 Python 3.12 并安装 `requirements.txt`，再取得对应权重。实时推理从 `realtime_inference/run_online_inference.py` 开始，输入视频、采样帧率和播放速度；完整参数在该目录 README。

## 一个使用示例
官方命令改写，未执行：用 `--source video --video path/to/example.mp4 --sample-fps 1 --playback-speed 1 --max-frames 256` 向实时模型按原时间线喂入本地视频。目标是观察连续画面与问答随时间推进，而不是先读取全部视频。预期输出为逐步生成的文本；本站未下载权重或测量延迟。

## 注意事项与相关项目
README 示例使用 CUDA 与特定张量类型，不能据此认定普通笔记本可以流畅运行。加载远端模型代码前应核对具体来源。模型对事件、时间与人物的描述仍可能错误，实时响应不等于事实验证。
