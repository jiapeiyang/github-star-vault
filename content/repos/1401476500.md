## 它是什么

Answer me with HTML 是面向编码代理的解释技能。代理负责组织 Markdown 内容，内置 CLI 处理版式和图形布局，产出可离线打开的单页 HTML。它适合解释一组概念或决策，也提供按需生成讲解视频的路径。

## 适合什么场景

- 用时序图和状态图理解协议或跨模块调用。
- 将多个方案的前提与差异放在同一页比较。
- 阅读长回答时，需要在文字、代码、图表之间建立对应关系。

## 如何开始

1. 核对 Node.js 20+ 要求，阅读仓库安装说明并选择当前宿主的安装方式。
2. 官方通用入口是 `npx skills add QingYunA/answer-me-with-html`；安装后先提出一个范围明确的问题，并说明希望得到 HTML。
3. 打开生成页面，检查文字、图和代码是否一致。页面默认保存在 `~/.answer-me-with-html/pages/`；自动打开和主题等行为可配置。

## 一个使用示例

说明性示例，未执行：输入“解释浏览器发出请求后，DNS、TLS 和 HTTP 各做什么，用一页 HTML 分开表示”。预期输出是带说明、流程图和关键名词的页面；图形布局正确不等于技术解释准确，仍需对照来源。简单的一行命令无需强制生成页面。

## 注意事项与相关项目

README 中速度、token 和费用比较来自作者的特定样本，本文未复现。始终生成页面的模式默认关闭，启用会修改宿主规则；不要把安装技能视为已同意开启该模式。视频导出路径的环境要求与普通 HTML 不同。Archify 更适合独立架构图，本项目更侧重整页解释。
