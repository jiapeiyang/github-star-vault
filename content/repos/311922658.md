## 它是什么
Xray-install 是 Project X 的 Bash 安装工具，主流程面向 systemd Linux；Alpine、Gentoo 的 OpenRC 使用独立说明。它安排核心二进制、服务文件、配置目录和 GeoIP／GeoSite 数据，不代替业务配置设计。

## 适合什么场景
希望按上游目录约定部署或升级 Xray-core，也适合使用本地发行压缩包进行可控安装。已经由面板或包管理器管理的实例，应先确认归属，避免互相覆盖。

## 如何开始
检查 init 系统、架构及当前服务，下载阅读 `install-release.sh`。默认路径包括 `/usr/local/bin/xray` 和 `/usr/local/etc/xray/`。选择稳定版或固定版本，备份现有配置，再按 README 执行安装。程序默认不会自动写入 `/var/log/xray/*.log`，日志需要显式配置。

## 一个使用示例
官方本地安装示例，未执行：准备匹配 x86_64 的发行包，在目标服务器以所需权限运行 `bash install-release.sh install --local ./Xray-linux-64.zip`。预期安装核心及服务文件；还应单独检查配置和连接，不把脚本成功视为代理可用。

## 注意事项与相关项目
`remove` 保留 JSON 和日志，`remove --purge` 会清理它们，两者后果不同。升级、规则数据更新和多实例也应分别核对。它关联 Xray-core，但没有替用户设置可直接工作的 REALITY 或 VLESS 节点。
