## 它是什么
github-rank 通过 GitHub 数据生成用户关注者榜、仓库 Star 榜与趋势页面，并将部分数据发布为 npm 包。它是公共排行榜的展示与数据生产项目，和自己的收藏历史不同：榜单强调某次抓取的公共指标，不能说明用户为何收藏某仓库。

## 适合什么场景
适合浏览开源社区中的项目与作者、给静态页面引入榜单数据，或参考定时生成网页的流程。若要判断项目适不适合具体业务，仍应进入源码和文档，不能仅按排名做决定。

## 如何开始
只读查看可打开 README 的排行榜预览，选择全球用户、中国用户、仓库或趋势。程序使用可按上游安装 @wcj/github-rank，并按需要导入 users 或 dist 下的 repos.json、trending-weekly.json 等文件。先看包版本和数据日期，再决定展示更新时间。

## 一个使用示例

预期得到该包发布时的仓库榜单数据，随后由自己的界面渲染；这段导入不会现场向 GitHub 请求最新名次。

## 注意事项与相关项目
README 目前既留有“每天自动更新”的旧描述，也明确警告因额度与费用改为每 7 天运行，因此不能按日更新作保证。用户榜依据关注者，仓库榜依据 Stars，趋势也有不同时间窗；这些指标不等于质量评级。自己运行抓取还涉及 GitHub API 额度，单纯浏览生成页面无需这些配置。
