## 它是什么
Daily-Interview-Question 把前端问题按编号发布，每题链接到 GitHub issue 讨论和解析，README 展示近期题目与部分输入代码。它覆盖 JavaScript 行为、手写函数、异步控制、Flex 布局与网络缓存，可作为按问题找资料的索引。

## 适合什么场景
适合遇到不理解的输出顺序、布局尺寸或数组操作，想比较不同解法的人。题目中的范围通常很小，实际业务使用需要补充输入规模、错误处理与版本前提。

## 如何开始
从 README 或在线阅读版找题号，先读题干中的限制，再进入解析。对代码题先列出预期与理由，再在隔离环境验证；不要把评论中简短答案直接复制到线上。查看相关评论修订有助于发现题目隐含条件。

## 一个使用示例
官方第 160 题阅读示例，未执行：它在 forEach 回调中使用 async/await 调用延迟一秒的 square，要求解释输出时机并改成间隔输出。先判断 forEach 是否等待异步回调，再阅读 issue #389 中的串行方案。预期理解“回调内部等待”与“外层遍历等待”的区别，而非只背一个替代写法。

## 注意事项与相关项目
标题中的“每日”是项目组织方式，不能据此承诺今天仍更新。题目常省略生产级边界，像重试与并发控制仍需明确取消、顺序和失败语义。本次只核查题干与阅读入口，未运行题目中的代码。
