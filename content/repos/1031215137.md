## 它是什么
xiaohongshu-mcp 将小红书操作封装为 MCP 工具，提供登录状态检查、搜索、内容读取与发布等能力。主体是需要部署的 Go 服务和浏览器自动化流程；README 推荐的浏览器插件及相关 Skills 是另外的项目。

## 适合什么场景
让助手检索自己获授权访问的内容，或在明确确认后协助管理自己的创作账号。它不是小红书官方 API，也不证明自动化操作不会触发平台限制。

## 如何开始
从 Releases 选择对应平台的服务与登录工具，先完成登录，再启动 MCP 服务。按客户端支持的 HTTP MCP 方式接入 `http://localhost:18060/mcp`，从检查登录状态开始。若将服务提供给其他设备，需配置访问鉴权；README 默认关闭鉴权。

## 一个使用示例
使用思路示例，未执行：让助手搜索一个明确关键词，只返回标题、作者和原帖入口，随后人工选定一条再读详情。先用读取操作确认连接，发布、评论或其他账号写入应另行明确授权，不能把接入成功当成发布许可。

## 注意事项与相关项目
登录 Cookie、图片路径和账号资料属于敏感数据。网页变化、验证码和会话失效都可能影响运行。yichen-skills 也包含平台资料整理能力，但宿主、依赖和授权边界各不相同；不要混用登录状态或把上游宣传当成稳定性实测。
