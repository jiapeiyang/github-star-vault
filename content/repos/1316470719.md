## 它是什么
Hypit 是面向编码代理的视频制作工具及 Skill，组织脚本、人物、配音、字幕、生成素材与合成步骤。仓库提供 SVML 源文件和对应视频案例。
Skill、可执行工具与模型服务是不同环节；安装 Skill 不代表已具备所有生成和渲染条件。

## 适合什么场景
根据授权参考素材重组视频；保留形式而更换语言、人物或产品；让代理组织制作流程，同时保留可检查的源文件。

## 如何开始
README 的入口为 `npx skills add hypit-ai/hypit -g`。先阅读 Quickstart，确认宿主与执行环境；首次使用检查 Hypit 可执行工具，再按所选服务准备凭据。编码代理和模型服务的账号与费用单独确认。
