## 它是什么
Hello-Agents 是 Datawhale 的中文智能体构建教程，提供在线章节、配套代码与综合案例。内容从智能体和语言模型基础开始，覆盖 ReAct、Plan-and-Solve、Reflection、框架开发、记忆与检索、上下文工程、通信协议、模型训练和性能评估。

这个仓库的主体是教材与示例集合。README 还连接独立维护的 HelloAgents 框架，两者需要区分：阅读教材不要求先安装那个框架，运行具体案例则要遵循相应章节和代码目录的要求。

## 适合什么场景
想从原理了解工具调用与规划循环，或希望通过一个完整案例理解多智能体如何协作时，可按主题选择章节。需要找旅行助手、深度研究或赛博小镇的示例入口，也可以直接使用 README 的内容导航，无需将整本教程当成待完成任务。

## 如何开始
1. 通过 README 提供的在线阅读入口打开教程，浏览目录确定问题对应章节。
2. 原理问题可从第四章经典范式开始；检索与上下文问题分别查看第八、九章。
3. 需要运行时再打开章节对应代码与环境说明，确认 Python、模型服务和依赖版本。
4. 涉及外部模型或工具的案例应先验证最小输入，保留真实输出与错误信息供排查。

在线入口为 [Hello-Agents](https://datawhalechina.github.io/hello-agents/)，README 也提供国内镜像与 PDF 下载入口。

## 一个使用示例
目标是理解一个深度研究助手如何从问题生成报告：先通过目录打开第十四章“自动化深度研究智能体”，阅读它如何组织研究步骤，再对照相关代码寻找输入、任务拆分和输出的位置。若发现检索概念不清楚，可回到第八章补充相关背景。

预期得到具体案例的工作流程与实现入口，而不是仅知道“它能做研究”。这是依据章节目录设计的阅读路径；本站没有运行研究服务或核验生成报告的引用质量。

## 注意事项与相关项目
不同章节涉及的框架、模型和训练条件并不统一，不应套用一条安装命令运行所有案例。模型训练部分的资源门槛也不同于普通 API 示例。Agent-Learning-Hub 可用于跨项目发现资料，本仓库适合沿连续章节理解同一套概念；第三方扩展章与正文仍需分别核对出处和版本。
